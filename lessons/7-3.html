Put it in Git

Git records snapshots. Commit small, working changes so you can return to a good state instead of guessing which edit broke the layout.

Run git status before every commit, add a .gitignore for .DS_Store, node_modules/, and local environment files, and never commit secrets. A public repository is public forever.

Publish with GitHub Pages

  1. Create a public repository named portfolio and push your main branch.
  2. Open Settings → Pages, choose Deploy from a branch, then main and / (root). Save.
  3. Wait for the deployment, open https://YOUR-NAME.github.io/portfolio/, and test every link in incognito and on a phone.
Custom domain

You do not need one for this course. If you add one later, create a CNAME file with the domain, point a DNS CNAME record at YOUR-NAME.github.io, and enable HTTPS in Pages settings. Confirm the free Pages URL works first.

Portfolio v2 and the README

The final site has three pages and one job each. It must work on a small screen, pass the accessibility pass, and include one interactive feature that does something useful.

  • Three pages: Home, About, and Projects, all linked and usable at 320px.
  • Accessible: keyboard access, visible focus, labels, alt text, contrast.
  • Interactive: a filter, theme switch, or other feature with state.
  • Documented and deployed: a README plus a public URL with no console errors.

Build the home page

The starter has the shell and navigation. Add an h1, an intro, three project article cards, and a button that filters to web projects. The button must update its label and aria-pressed state. Test with Tab and Enter before revealing the reference.

Check yourself

Why does the GitHub Pages URL include the repository name?

A project site is served from https://YOUR-NAME.github.io/repository-name/. That is why relative paths matter: a leading slash points at the domain root, not your project folder.

What should I check first when the deployed site returns 404?

Confirm the repository is public, Pages is set to the correct branch and root folder, index.html exists at that root, and the deployment has finished. Then retry in a private window.
