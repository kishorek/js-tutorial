Module 01 · HTML: the skeleton

Links, images, and lists

A page becomes a website when it can point somewhere. Learn to connect pages, show images without excluding people, and structure lists that make sense.

Lesson 1.2 60–75 min Beginner

By the end, you can

  • Write relative and absolute links that work.
  • Add an image with useful alternative text.
  • Choose between unordered and ordered lists.

You need

  • Your About Me page from Lesson 1.1.
  • Any image file on your computer.
  • A second HTML file to link to.

Links connect pages

The anchor element turns text or an image into a link. The href attribute says where the link goes.

  • Relative link: about-me.html looks for a file in the same folder.
  • Parent folder: ../index.html goes up one folder.
  • Absolute link: a full URL, including https://.
  • Page anchor: #recipe jumps to the element with id="recipe".

Use descriptive link text. "Read the recipe" is useful. "Click here" tells the reader nothing, especially if they are using a screen reader to scan a list of links.

External links

When a link opens a new tab with target="_blank", add rel="noopener". It protects your page from the new tab gaining access to it.

Images need alternative text

The image element is a void element. It has no closing tag. The src attribute points to the file; alt describes what the image communicates.

  • If the image conveys information, describe that information.
  • If the image is purely decorative, use alt="" so screen readers skip it.
  • Do not start with "image of" or "picture of"; screen readers already announce that.
  • Set width and height when you can. They reserve space and reduce layout shift while the image loads.
Common mistake

A missing alt attribute is not the same as an empty one. A missing value makes the browser guess; alt="" explicitly tells assistive technology that the image adds no information.

Lists organize information

Use <ul> when order does not matter, and <ol> when it does. Every item goes inside an <li>.

Lists can nest. Put the nested list inside the <li> it belongs to, not between items.

Exercise · 20 minutes

Build a recipe index

Create a page with a header, a navigation link back to your About Me page, an h1, a figure with an image and caption, an unordered ingredients list, and an ordered method list. Give the method a heading with id="method" and add a "Jump to method" link at the top.

Make an attempt first. Then the model answer unlocks.

Check yourself

Why is alt="image of pasta" a weak description?

Screen readers already announce that the element is an image. The description should communicate the content, not repeat the format. "Lemon pasta in a white bowl" is more useful.

What is the difference between about.html and https://example.com/about.html?

The first is a relative path resolved from the current page. The second is an absolute URL with a protocol and domain.

Key things to remember

  • Links are anchors. The href decides the destination; the text should describe it.
  • Images need alt text. Describe information; use alt="" for decoration.
  • Lists carry meaning. Unordered for groups, ordered for sequence.
