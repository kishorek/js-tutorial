Three languages, one page

Think about a house. The frame, walls, and room labels decide what exists and where it goes. The paint and furniture decide how it looks. The wiring decides what responds when you flip a switch.

A webpage has the same three layers:

LanguageIts jobWithout it
HTMLStructure and meaning: what each piece of content is.A wall of unstyled text with no hierarchy.
CSSPresentation: color, type, spacing, layout, animation.Readable, but it looks like a document from 1995.
JavaScriptBehavior: respond to clicks, validate input, fetch data, update the page.Readable and attractive, but static.

We start with HTML on purpose. A beautiful house on a rotten frame is still a rotten house. Once the structure is correct, CSS is straightforward and JavaScript has something solid to change.

Semantic HTML

Choose elements for their meaning, not their default appearance. A heading is a heading because it starts a section, not because it is big. Screen readers, search engines, and future you all depend on that meaning.

The skeleton every page needs

Every HTML5 page starts with the same outer shell. Type this until it becomes muscle memory.

PartWhat it doesWhy it matters
<!DOCTYPE html>Tells the browser to use modern standards mode.Without it, browsers may render the page as if it were 1999.
<html lang="en">The root element and page language.Screen readers pronounce content correctly.
<head>Information about the page.Nothing in the head is visible in the page body.
<meta charset="UTF-8">Character encoding.Prevents accents and symbols from turning into garbage.
<meta name="viewport" …>Mobile page scaling.Without it, the page looks tiny on phones.
<title>Browser tab text.Used by tabs, bookmarks, and search results.
<body>Everything the visitor can see.Headings, images, buttons, and footers live here.
Memory hook

Head = backstage. Body = the stage. If you want a visitor to see it, it goes in the body. If it is information for the browser, it goes in the head.

Tags, elements, attributes

Most elements have three parts: an opening tag, content, and a closing tag.

  • Opening tag: <p class="intro"> starts the element.
  • Attribute: class="intro" configures it from inside the opening tag.
  • Content: Hello, world! is what the paragraph contains.
  • Closing tag: </p> ends the element.

Close tags inside-out. The last tag opened must be the first one closed. <p><strong>Hi</strong></p> is correct. <p><strong>Hi</p></strong> is not.

A few elements have no content and no closing tag: <meta>, <img>, and <br>. They are called void elements.

Headings and paragraphs

Headings are an outline, not a font-size menu. Use <h1> once for the page's main topic, <h2> for major sections, and <h3> for subsections.

<strong> marks importance. <em> marks emphasis, like a stressed word when speaking. Both change appearance by default, but their real value is meaning. Do not use them just to make text bold or italic; CSS does that job.

Common mistake

Browsers are forgiving, up to a point. A missing closing tag can make half the page disappear or nest inside the wrong element. The browser will guess, and its guess is often not what you meant.

Check yourself

Why does the title go in the head instead of the body?

The title describes the whole page to the browser, bookmarks, and search results. It is metadata, not visible page content. Visible content belongs in the body.

What is the difference between an element and a tag?

A tag is one label in angle brackets. An element is the complete unit: opening tag, content, and closing tag. Attributes are settings inside the opening tag.

Key things to remember

  • HTML is structure and meaning. CSS is presentation. JavaScript is behavior.
  • The skeleton: doctype → html → head + body.
  • Close tags inside-out. Last opened, first closed.
  • One h1 per page. Headings are an outline; CSS is for visual size.
  • Head is backstage, body is the stage.
