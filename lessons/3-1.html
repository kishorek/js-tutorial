CSS Grid

Flexbox distributes items along one line. Grid controls rows and columns at the same time, which makes galleries, dashboards, and whole page layouts predictable instead of accidental.

Lesson 3.1 60–75 min Beginner

By the end, you can

  • Create columns and rows with fr and repeat().
  • Build tracks that resize with minmax() and auto-fit.
  • Lay out a page with named grid areas.

You need

  • Module 2: the box model and Flexbox.
  • A page with a few cards or sections.
  • DevTools open so you can inspect the grid.

Grid works in two dimensions

Turn an element into a grid container with display: grid. Its direct children become grid items. The gap property spaces them without margins.

  • Container: the element with display: grid.
  • Item: every direct child of that container.
  • Track: one column or one row.
  • Cell: the space where a row and column meet.

Grid and Flexbox are partners, not rivals. Use Grid when you know the shape of the layout in both directions. Use Flexbox when items should flow along a single axis.

Fractions, repeat, and minmax

The fr unit shares the space that is left after fixed sizes and gaps. Three 1fr columns are equal. A 2fr column gets twice the free space of a 1fr column.

  • repeat(3, 1fr) is shorthand for 1fr 1fr 1fr.
  • minmax(0, 1fr) lets a track shrink below its content width, which prevents long words from breaking the layout.
  • grid-column: 1 / -1 spans from the first line to the last, making an item full width.
  • grid-auto-rows sizes rows you did not declare.

For a gallery that responds without a media query, replace the fixed count with auto-fit. The browser fits as many 220px tracks as it can, then stretches them to fill the row.

auto-fit vs auto-fill

auto-fit collapses empty tracks, so existing cards stretch to fill the row. auto-fill keeps the empty tracks, so cards stay at their minimum size and leave a gap. Choose based on whether you want the cards to grow.

Rows and alignment

Declare rows when the vertical structure matters, such as a page that must fill the viewport with a footer at the bottom.

  • justify-items aligns items inside their column; justify-content aligns the whole grid inside the container.
  • align-items and align-content do the same on the vertical axis.
  • place-items: center sets both alignment properties at once.
  • An auto row grows to fit its content; a 1fr row absorbs the remaining space.

Named areas describe the page

grid-template-areas draws the layout as text. Every named cell must form a rectangle, and every item claims its area with grid-area.

The named areas become documentation. A teammate can read the layout in five lines. On a narrow screen, only the column count and the area map change; the item rules stay put.

Common mistake

Do not put a hole in the middle of an area. If one row says "header header" and the next says "main sidebar", the shape is still valid. But "header ." creates an unnamed cell and will surprise you later. Use a period only when you truly want empty space.

Check yourself

When should you reach for Grid instead of Flexbox?

When the layout needs to line up in both rows and columns, such as a gallery or a page skeleton. Flexbox is simpler when items only need to flow or distribute along one axis.

Why write minmax(0, 1fr) instead of just 1fr?

A plain 1fr track has an automatic minimum based on its content. A long unbroken word can force the column wider than the screen. minmax(0, 1fr) sets that minimum to zero so the track can shrink.

Key things to remember

  • Grid is two-dimensional. Define columns and rows on the container.
  • fr shares free space. Pair it with minmax(0, 1fr) for safe flexible tracks.
  • Named areas make layout readable. Change the map at a breakpoint instead of rewriting every item.
