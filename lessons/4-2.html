Making decisions with if

An if statement runs a block only when its condition is true. JavaScript checks the branches from top to bottom and runs the first one that matches.

Only one branch runs. Once a condition is true, the rest are skipped, even if they would also be true. That is why order matters: put the most specific case first.

Comparison operators

Conditions are built from comparisons. Each one produces a boolean: true or false.

OperatorMeansExample
===Equal value and type5 === 5 is true
!==Not equal value or type5 !== "5" is true
>Greater than9 > 4 is true
<Less than2 < 1 is false
>=Greater than or equal4 >= 4 is true
<=Less than or equal3 <= 5 is true

Comparisons work on strings too, but they compare character codes rather than meaning. "apple" < "banana" is true because of alphabetical order, while "10" < "9" is true because the character "1" comes before "9". Convert to numbers when you mean numbers.

Combining conditions

Three logical operators let you join or reverse conditions.

  • && (AND) is true only when both sides are true.
  • || (OR) is true when at least one side is true.
  • ! (NOT) reverses a boolean.

Both sides of an AND must be true, so JavaScript stops checking as soon as it finds a false value. With OR, it stops as soon as it finds a true value. This is called short-circuit evaluation. It is useful, but do not hide side effects inside conditions.

Assignment is not comparison

A single = stores a value. A triple === compares two values. Writing if (score = 10) assigns 10 and the condition is always true. Most editors warn about this; take the warning seriously.

Truthiness

Conditions do not require a boolean. JavaScript converts any value to true or false. The falsy values are few, and worth memorising.

An empty string is falsy, but the string "0" is truthy. An empty array is also truthy, which surprises many beginners. Use explicit comparisons when the difference matters.

Ternary and switch

When you need to choose one of two values, a ternary expression is compact. Read it as "condition ? value when true : value when false".

Use a ternary for a single choice between two values. If you need several branches, or the expressions become long, use if or switch instead.

switch compares with strict equality. Each case falls through to the next unless you add break. Grouping "Sat" and "Sun" works because the first case has no statement before the second one.

Check yourself

Why does if ("0") run even though the string looks like zero?

Truthiness is about the value, not the text. The only falsy string is the empty string "". A string containing a zero character is non-empty, so it is truthy. Compare explicitly when zero must be treated as empty.

When should I use switch instead of if?

Use switch when one value is compared against several exact possibilities and each branch is short. Use if when conditions involve ranges, multiple variables, or logical operators.

Key things to remember

  • Branches run in order. The first true condition wins, so put specific cases first.
  • Use === and explicit checks. Truthiness is handy, but zero and empty values can mislead.
  • Match the syntax to the job. Ternary for one choice, if for logic, switch for exact matches.
