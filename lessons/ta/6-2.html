fetch, JSON, and API keys

உங்க page வேற ஒரு computer-கிட்ட data கேட்கலாம். request/response cycle, fetch மற்றும் JSON எப்படி சேர்ந்து work ஆகுது, secret keys ஏன் ஒருநாளும் browser code-ல ship பண்ணக்கூடாது — அதைப் பாருங்க.

A request goes out, a response comes back

API-னா ஒரு contract: நீங்க ஒரு URL-க்கு HTTP request அனுப்புவீங்க, server ஒரு response அனுப்பும். Request-க்கு ஒரு method இருக்கும்; உதாரணமா data read பண்ண GET, அனுப்ப POST. Response-க்கு status code, headers, பொதுவா ஒரு body இருக்கும்.

StatusMeaningWhat to do
200SuccessBody-ஐ read பண்ணுங்கள்.
400Bad requestURL இல்ல parameters-ஐ fix பண்ணுங்கள்.
401Not authorizedServer-ல valid credentials add பண்ணுங்கள்.
404Not foundPath இல்ல search term-ஐ check பண்ணுங்கள்.
429Too many requestsSlow down பண்ணுங்கள் இல்ல results-ஐ cache பண்ணுங்கள்.
500Server errorஅப்புறம் retry பண்ணுங்கள்; இது உங்க URL-ன் problem இல்ல.

நிறைய modern APIs JSON-ஐ அனுப்பும்: JavaScript objects மற்றும் arrays மாதிரி தெரியுற text. ஒரு weather response-ல temperature-ம் weather code-ம் இருக்குற nested current object இருக்கலாம்.

fetch returns a promise

fetch() ஒரு request-ஐ start பண்ணி promise-ஐ return பண்ணும். 404-க்கும், response headers வந்ததுமே promise resolve ஆகும். அதனாலதான் body-ஐ read பண்றதுக்கு முன்னாடி response.ok-ஐ check பண்ணணும்.

response.json()-ம் asynchronous. அது body-ஐ read பண்ணி JSON text-ஐ JavaScript values-ஆ parse பண்ணும், அதனால அதுக்கும் await வேணும். Body valid JSON இல்லைனா, அது reject ஆகும்.

fetch does not reject on 404

Network failure promise-ஐ reject பண்ணும். 404 இல்ல 500 மாதிரி HTTP error-க்கு அது fulfill ஆகும். எப்பவும் response.ok-ஐ check பண்ணுங்கள், இல்லைனா error page-ஐ data-ஆ parse பண்ண try பண்ணுவீங்க.

Build the URL with query parameters

Query parameters-னா ?-க்குப் பிறகு வர key=value pairs. அவை search-ஐ filter பண்ணும், fields-ஐ choose பண்ணும், இல்ல options set பண்ணும். அவற்றை &-ஓட separate பண்ணி, user input-ஐ encodeURIComponent()-ஓட encode பண்ணுங்கள்.

Open-Meteo-க்கு ரெண்டு steps வேணும். முதல்ல geocoding ஒரு city name-ஐ coordinates-ஆ மாத்தும். பிறகு forecast endpoint அந்த coordinates-ஐ use பண்ணும். ரெண்டும் free, key தேவையில்ல.

CORS-னா cross-origin requests-க்கான browser-ன் rule. API சரியான Access-Control-Allow-Origin header-ஐ அனுப்பலனா, response-ஐ read பண்ணுற உங்க code-ஐ browser block பண்ணும். Client JavaScript-ல இதை fix பண்ண முடியாது; API உங்க origin-ஐ allow பண்ணணும், இல்லைனா server proxy வேணும்.

Reading a CORS error

Network panel-ல request response-ஓட தெரியலாம், ஆனா console CORS failure-ஐ காட்டும். Browser data-ஐ வாங்கிட்டது, ஆனா உங்க page-க்கு அதை expose பண்ண முடியாதுன்னு மறுத்துட்டது.

API keys stay on the server

சில APIs caller-ஐ identify பண்ணவும் bill பண்ணவும் ஒரு key use பண்ணும். Public key தெரியுற மாதிரியே design பண்ணப்பட்டு domain-ஆ restrict பண்ணப்படும். Secret key அப்படி இல்ல. HTML, CSS, இல்ல client JavaScript-ல இருக்குற எதையும் ஒவ்வொரு visitor-ம் read பண்ணலாம்.

Key-ஐ ஒரு variable-ல, comment-ல, இல்ல obfuscated file-ல hide பண்றது security இல்ல. Browser key-ஐ request-ஓட அனுப்பணும், அதனால அது DevTools-ல தெரியும். Client code-ல இருக்குற secret key-ஐ copy பண்ணி உங்க account-க்கு எதிரா use பண்ணலாம்.

Key வேணும்னா, அதை ஒரு சின்ன server இல்ல serverless function-ல வையுங்கள். Key server-ல environment variable-ஆ இருக்கும். உங்க browser உங்க endpoint-ஐ call பண்ணும்; உங்க endpoint API-ஐ call பண்ணி page-க்கு வேணுமான data-ஐ மட்டும் return பண்ணும்.

Never commit a key

Secrets-ஐ public repository-ல, screenshot-ல, இல்ல shared chat-ல வைக்காதீங்க. Secret key leak ஆனா, அதை revoke பண்ணி புதுசா ஒண்ணு create பண்ணுங்கள். Open-Meteo-க்கு key தேவையில்ல, அதனால practice பண்ண இது safe place.

Check yourself

Why does a 404 response not throw by itself?

Request முழுசா முடியாதப்போ மட்டும்தான் — உதாரணமா network failure — fetch promise reject ஆகும். HTTP 404-ம் ஒரு completed response, அதனால promise fulfill ஆகும். response.ok-ஐ check பண்ணி, அது false-ஆ இருக்கும்போது உங்க சொந்த error-ஐ throw பண்ணுங்கள்.

If a key is hidden in a JavaScript variable, is it safe?

இல்ல. Browser key-ஐ API-க்கு அனுப்பணும், அதனால அது DevTools-ல, source files-ல, இல்ல Network panel-ல தெரியும். Secret keys server-ல, environment variables-லேர்ந்து read பண்ணி, உங்க page call பண்ணக்கூடிய endpoint-க்குப் பின்னாடி இருக்கணும்.

Key things to remember

  • fetch asynchronous. Response-க்காக await பண்ணி, response.ok-ஐ check பண்ணி, அப்புறம் response.json()-க்காக await பண்ணுங்கள்.
  • URLs-தான் request-ஐ எடுத்துச் செல்லும். User input-ஐ encode பண்ணி, search terms-க்கும் options-க்கும் query parameters use பண்ணுங்கள்.
  • CORS-ம் keys-ம் server-ன் விஷயம். Block ஆன response-க்கு உங்க origin-ஐ allow பண்ணுற API இல்ல proxy வேணும்; secrets ஒருநாளும் browser-ல இருக்கக்கூடாது.
