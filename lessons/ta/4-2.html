Making decisions with if

if statement அதன் condition true-ஆ இருந்தா மட்டும் ஒரு block-ஐ run பண்ணும். JavaScript branches-ஐ மேலிருந்து கீழ check பண்ணி, முதல்ல match ஆகிறதை run பண்ணும்.

ஒரு branch மட்டும்தான் run ஆகும். ஒரு condition true ஆனதும் மற்றவை skip ஆகும், அவையும் true-ஆ இருந்தாலும். அதனால order முக்கியம்: most specific case-ஐ முதல்ல வைங்க.

Comparison operators

Conditions comparisons-லிருந்து build ஆகின்றன. ஒவ்வொன்றும் ஒரு boolean-ஐ produce பண்ணும்: true அல்லது false.

Comparisons strings-லயும் வேலை செய்யும், ஆனா meaning-ஐ விட character codes-ஐ compare பண்ணும். "apple" < "banana" true, alphabetical order-னால; "10" < "9" true, ஏனெனில் character "1" "9"-க்கு முன்னாடி வருது. Numbers-ஐக் கருதினா numbers-ஆ convert பண்ணுங்க.

Combining conditions

மூன்று logical operators conditions-ஐ join அல்லது reverse பண்ண உதவும்.

  • && (AND) இரண்டு பக்கமும் true-ஆ இருந்தா மட்டும் true.
  • || (OR) குறைந்தது ஒரு பக்கம் true-ஆ இருந்தா true.
  • ! (NOT) ஒரு boolean-ஐ reverse பண்ணும்.

AND-ல இரண்டு பக்கமும் true ஆகணும், அதனால JavaScript false value கிடைத்தவுடன் check பண்ணுவதை நிறுத்தும். OR-ல true value கிடைத்தவுடன் நிறுத்தும். இதை short-circuit evaluation என்கிறாங்க. இது useful, ஆனா conditions-க்கு உள்ளே side effects-ஐ hide பண்ணாதீங்க.

Assignment is not comparison

ஒரு = ஒரு value-ஐ store பண்ணும். மூன்று === இரண்டு values-ஐ compare பண்ணும். if (score = 10) எழுதினா 10 assign ஆகி condition எப்பவும் true. பெரும்பாலான editors இதை warn பண்ணும்; warning-ஐ seriously எடுத்துக்கோங்க.

Truthiness

Conditions-க்கு boolean கட்டாயம் இல்ல. JavaScript எந்த value-ஐயும் true அல்லது false-ஆ convert பண்ணும். Falsy values கொஞ்சம்தான், நினைவில் வைக்க தகுந்தவை.

Empty string falsy, ஆனா "0" string truthy. Empty array-ம் truthy, இது பல beginners-க்கு ஆச்சரியம். Difference முக்கியமா இருக்கும்போது explicit comparisons use பண்ணுங்க.

Ternary and switch

இரண்டு values-ல ஒன்றை choose பண்ண வேண்டியிருக்கும்போது ternary expression compact. இதை "condition ? value when true : value when false" என்று read பண்ணுங்க.

இரண்டு values-க்கு நடுவுல ஒரே choice-க்கு ternary use பண்ணுங்க. பல branches தேவைப்பட்டா, அல்லது expressions நீளமா ஆனா, if அல்லது switch use பண்ணுங்க.

switch strict equality-ஓட compare பண்ணும். break add பண்ணாத வரை ஒவ்வொரு case-ம் அடுத்ததுக்கு fall through ஆகும். "Sat" மற்றும் "Sun" group பண்ணுவது வேலை செய்யும், ஏனெனில் முதல் case-ல இரண்டாவதுக்கு முன்னாடி statement இல்ல.

Check yourself

Why does if ("0") run even though the string looks like zero?

Truthiness value-ஐப் பத்தி, text-ஐப் பத்தி இல்ல. Falsy string ஒரே ஒண்ணுதான்: empty string "". Zero character இருக்கிற string non-empty, அதனால truthy. Zero-ஐ empty-ஆ treat பண்ண வேண்டியிருக்கும்போது explicit-ஆ compare பண்ணுங்க.

When should I use switch instead of if?

ஒரு value-ஐ பல exact possibilities-ஓட compare பண்ணி, ஒவ்வொரு branch-ம் சின்னதா இருந்தா switch use பண்ணுங்க. Conditions-ல ranges, பல variables அல்லது logical operators இருந்தா if use பண்ணுங்க.

Key things to remember

  • Branches order-ல run ஆகும். முதல் true condition வெல்லும், அதனால specific cases-ஐ முதல்ல வைங்க.
  • === மற்றும் explicit checks use பண்ணுங்க. Truthiness handy, ஆனா zero மற்றும் empty values தவறாக வழி நடத்தலாம்.
  • Syntax-ஐ வேலைக்கு match பண்ணுங்க. ஒரு choice-க்கு ternary, logic-க்கு if, exact matches-க்கு switch.
