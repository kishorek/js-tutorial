தொகுதி 04 · JavaScript அடிப்படைகள்

நிபந்தனைகள் மற்றும் தர்க்கம்

நிரல்கள் தேர்வு செய்ய வேண்டும். JavaScript ஒப்பீடுகளை எப்படி முடிவுகளாக மாற்றுகிறது, truthiness ஒவ்வொரு நிபந்தனையையும் எப்படி அமைதியாக வடிவமைக்கிறது, எப்போது ternary அல்லது switch ஒரு if குவியலைவிட code-ஐத் தெளிவாக வைக்கிறது என்பதைக் கற்றுக்கொள்ளுங்கள்.

பாடம் 4.2 60–75 நிமிடங்கள் தொடக்கநிலை

இறுதியில் நீங்கள் செய்யக்கூடியவை

  • if, else if மற்றும் else branches எழுத முடியும்.
  • சரியான operator கொண்டு மதிப்புகளை ஒப்பிட முடியும்.
  • &&, || மற்றும் ! கொண்டு நிபந்தனைகளை இணைக்க முடியும்.
  • Ternary-க்கும் switch-க்கும் இடையே தேர்ந்தெடுக்க முடியும்.

உங்களுக்குத் தேவையானவை

  • பாடம் 4.1-இன் மாறிகள் மற்றும் வகைகள்.
  • நீங்கள் தட்டச்சு செய்யக்கூடிய console.
  • சோதிக்கச் சில மதிப்புகள்.

if கொண்டு முடிவெடுத்தல்

if statement அதன் நிபந்தனை true ஆக இருக்கும்போது மட்டும் ஒரு block-ஐ இயக்கும். JavaScript branches-ஐ மேலிருந்து கீழாகச் சரிபார்த்து, முதலில் பொருந்துவதை இயக்கும்.

ஒரே ஒரு branch மட்டும் இயங்கும். ஒரு நிபந்தனை true ஆனதும் மீதமுள்ளவை தவிர்க்கப்படும்; அவையும் true ஆக இருந்தாலும். அதனால்தான் வரிசை முக்கியம்: மிகக் குறிப்பிட்ட நிலையை முதலில் வையுங்கள்.

ஒப்பீட்டு operators

நிபந்தனைகள் ஒப்பீடுகளால் உருவாகின்றன. ஒவ்வொன்றும் ஒரு boolean-ஐத் தரும்: true அல்லது false.

Operatorபொருள்எடுத்துக்காட்டு
===மதிப்பும் வகையும் சமம்5 === 5 என்பது true
!==மதிப்பும் வகையும் சமமில்லை5 !== "5" என்பது true
>பெரியது9 > 4 என்பது true
<சிறியது2 < 1 என்பது false
>=பெரியது அல்லது சமம்4 >= 4 என்பது true
<=சிறியது அல்லது சமம்3 <= 5 என்பது true

ஒப்பீடுகள் strings-லும் வேலை செய்கின்றன; ஆனால் அவை பொருளை அல்ல, character codes-ஐ ஒப்பிடுகின்றன. "apple" < "banana" அகரவரிசையால் true; ஆனால் "10" < "9" true, ஏனெனில் "1" என்ற எழுத்து "9"-க்கு முன் வருகிறது. எண்களைக் குறிக்கும்போது numbers ஆக மாற்றுங்கள்.

நிபந்தனைகளை இணைத்தல்

மூன்று logical operators நிபந்தனைகளை இணைக்க அல்லது மாற்ற உதவுகின்றன.

  • && (AND) இரு பக்கமும் true ஆக இருந்தால் மட்டும் true.
  • || (OR) குறைந்தது ஒரு பக்கம் true ஆக இருந்தால் true.
  • ! (NOT) ஒரு boolean-ஐத் தலைகீழாக்கும்.

AND-ன் இரு பக்கமும் true ஆக இருக்க வேண்டும்; எனவே false மதிப்பு கிடைத்தவுடன் JavaScript சரிபார்ப்பதை நிறுத்தும். OR-ல் true மதிப்பு கிடைத்தவுடன் நிறுத்தும். இதை short-circuit evaluation என்கிறார்கள். இது பயனுள்ளது; ஆனால் side effects-ஐ நிபந்தனைகளுக்குள் மறைக்க வேண்டாம்.

Assignment ஒப்பீடு அல்ல

ஒரு = ஒரு மதிப்பைச் சேமிக்கிறது. மூன்று === இரு மதிப்புகளை ஒப்பிடுகிறது. if (score = 10) என்று எழுதினால் 10 ஒப்படைக்கப்படும்; நிபந்தனை எப்போதும் true. பெரும்பாலான எடிட்டர்கள் இதைப் பற்றி எச்சரிக்கும்; அந்த எச்சரிக்கையைக் கவனத்தில் கொள்ளுங்கள்.

Truthiness

நிபந்தனைகளுக்கு boolean கட்டாயம் இல்லை. JavaScript எந்த மதிப்பையும் true அல்லது false ஆக மாற்றும். Falsy மதிப்புகள் சில மட்டுமே; அவற்றை நினைவில் வைத்துக்கொள்வது மதிப்புள்ளது.

காலி string falsy; ஆனால் "0" என்ற string truthy. காலி array-யும் truthy; இது பல தொடக்கநிலையாளர்களை ஆச்சரியப்படுத்தும். வித்தியாசம் முக்கியமானபோது வெளிப்படையான ஒப்பீடுகளைப் பயன்படுத்துங்கள்.

Ternary மற்றும் switch

இரு மதிப்புகளில் ஒன்றைத் தேர்ந்தெடுக்க வேண்டியபோது ternary expression சுருக்கமாக இருக்கும். இதை "condition ? true ஆகும்போது மதிப்பு : false ஆகும்போது மதிப்பு" என்று படியுங்கள்.

இரு மதிப்புகளுக்கு இடையே ஒரே தேர்வுக்கு ternary பயன்படுத்துங்கள். பல branches தேவைப்பட்டால் அல்லது expressions நீளமானால், அதற்குப் பதிலாக if அல்லது switch பயன்படுத்துங்கள்.

switch strict equality கொண்டு ஒப்பிடுகிறது. break சேர்க்காத வரை ஒவ்வொரு case-ம் அடுத்ததற்குத் தொடரும். "Sat" மற்றும் "Sun" ஆகியவற்றைச் சேர்ப்பது வேலை செய்கிறது, ஏனெனில் முதல் case-ல் இரண்டாவதற்கு முன் statement எதுவும் இல்லை.

சினிமா டிக்கெட்டுக்கு விலை வையுங்கள்

வயதையும் membership boolean-ஐயும் அறிவிக்கவும். if/else if/else கொண்டு டிக்கெட் விலையை அமைக்கவும்: 13-க்குக் கீழ் $5, 18-க்குக் கீழ் $8, மற்ற அனைவரும் $12. Members-க்கு $2 தள்ளுபடி. Customer வகையையும் இறுதி விலையையும் குறிப்பிடும் ஒரு வாக்கியத்தை template literal கொண்டு log செய்யுங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

String பூஜ்ஜியம் போலத் தெரிந்தாலும் if ("0") ஏன் இயங்குகிறது?

Truthiness மதிப்பைப் பற்றியது, உரையைப் பற்றியது அல்ல. Falsy ஆக இருக்கும் ஒரே string காலி string "" மட்டுமே. பூஜ்ஜிய எழுத்து உள்ள string காலியானது அல்ல; எனவே அது truthy. பூஜ்ஜியத்தைக் காலியாகக் கருத வேண்டியபோது வெளிப்படையாக ஒப்பிடுங்கள்.

எப்போது if-க்குப் பதிலாக switch பயன்படுத்த வேண்டும்?

ஒரு மதிப்பைப் பல சரியான சாத்தியங்களுடன் ஒப்பிடும்போது, ஒவ்வொரு branch-ம் சுருக்கமாக இருந்தால் switch பயன்படுத்துங்கள். நிபந்தனைகளில் ranges, பல மாறிகள் அல்லது logical operators இருந்தால் if பயன்படுத்துங்கள்.

நினைவில் கொள்ள வேண்டிய முக்கிய விஷயங்கள்

  • Branches வரிசையாக இயங்கும். முதல் true நிபந்தனையே வெல்லும்; எனவே குறிப்பிட்ட நிலைகளை முதலில் வையுங்கள்.
  • === மற்றும் வெளிப்படையான சரிபார்ப்புகளைப் பயன்படுத்துங்கள். Truthiness வசதியானது; ஆனால் பூஜ்ஜியமும் காலி மதிப்புகளும் தவறாக வழிநடத்தலாம்.
  • வேலைக்கு ஏற்ற syntax-ஐத் தேர்ந்தெடுங்கள். ஒரு தேர்வுக்கு ternary, தர்க்கத்திற்கு if, சரியான பொருத்தங்களுக்கு switch.
