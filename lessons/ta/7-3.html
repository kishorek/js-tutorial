Deliverables

  • GitHub Pages-ல live-ஆ இருக்கிற மூன்று page portfolio.

Exit check

  • ஒவ்வொரு page-உம் 320px-லயும் keyboard-உடனும் வேலை செய்யும்.
  • ஒரு interactive feature வேலை செய்யும், ஒரு stranger-உம் site-ஐ புரிஞ்சுப்பார்.

Put it in Git

Git snapshots-ஐ record பண்ணும். சின்ன, வேலை செய்யிற changes-ஐ commit பண்ணுங்கள்; அப்போ எந்த edit layout-ஐ உடைச்சது-னு யூகிக்காம நல்ல state-க்கு திரும்பலாம்.

ஒவ்வொரு commit-க்கும் முன்னாடி git status run பண்ணுங்கள், .DS_Store, node_modules/, local environment files-க்கு .gitignore add பண்ணுங்கள், secrets-ஐ எப்பவும் commit பண்ணாதீர்கள். Public repository எப்பவும் public.

Publish with GitHub Pages

  1. portfolio என்கிற பேர்ல public repository create பண்ணி, உங்கள் main branch-ஐ push பண்ணுங்கள்.
  2. Settings → Pages open பண்ணி, Deploy from a branch choose பண்ணி, அப்புறம் main-ஐயும் / (root)-ஐயும் தேர்ந்தெடுங்கள். Save பண்ணுங்கள்.
  3. Deployment முடியுற வரை wait பண்ணுங்கள், https://YOUR-NAME.github.io/portfolio/ open பண்ணி, incognito-லயும் phone-லயும் ஒவ்வொரு link-ஐயும் test பண்ணுங்கள்.
Custom domain

இந்த course-க்கு அது தேவையில்லை. பிறகு add பண்ணினா, domain-ஓட CNAME file create பண்ணி, DNS CNAME record-ஐ YOUR-NAME.github.io-க்கு point பண்ணி, Pages settings-ல HTTPS enable பண்ணுங்கள். முதல்ல free Pages URL வேலை செய்யுதா-னு confirm பண்ணுங்கள்.

Portfolio v2 and the README

Final site-ல மூன்று pages, ஒவ்வொன்றுக்கும் ஒரு job. சின்ன screen-ல வேலை செய்யணும், accessibility pass-ஐ clear பண்ணணும், useful-ஆ ஏதோ ஒண்ணு செய்யிற ஒரு interactive feature இருக்கணும்.

  • மூன்று pages: Home, About, Projects; எல்லாமே linked, 320px-ல usable.
  • Accessible: keyboard access, visible focus, labels, alt text, contrast.
  • Interactive: filter, theme switch, இல்ல state உள்ள வேற feature.
  • Documented, deployed: README-உம் console errors இல்லாத public URL-உம்.

Build the home page

Starter-ல shell-உம் navigation-உம் இருக்கு. ஒரு h1, ஒரு intro, மூன்று project article cards, web projects-க்கு filter பண்ணும் ஒரு button add பண்ணுங்கள். Button தன் label-ஐயும் aria-pressed state-ஐயும் update பண்ணணும். Reference-ஐ reveal பண்ணுறதுக்கு முன்னாடி Tab-உம் Enter-உம் போட்டு test பண்ணுங்கள்.

Ship it checklist

  • Repository public; main current; history-ல secrets இல்ல.
  • Pages main, / (root)-ல இருந்து deploy ஆகுது; live URL HTTPS-ல load ஆகுது.
  • மூன்று pages-உம் load ஆகுது, navigation current, எந்த link-உம் image-உம் broken இல்ல.
  • Keyboard pass complete; focus visible; site 320px-ல வேலை செய்யுது.
  • README-ல live URL-உம் local steps-உம் இருக்கு; ஒருவர் site-ஐ use பண்றதை நீங்கள் பார்த்தீர்கள்.

Check yourself

Why does the GitHub Pages URL include the repository name?

Project site https://YOUR-NAME.github.io/repository-name/-ல இருந்து serve ஆகும். அதனால தான் relative paths முக்கியம்: leading slash domain root-ஐ சுட்டுது, உங்கள் project folder-ஐ இல்ல.

What should I check first when the deployed site returns 404?

Repository public-ஆ, Pages சரியான branch-க்கும் root folder-க்கும் set ஆகியிருக்கா, அந்த root-ல index.html இருக்கா, deployment முடிஞ்சிருக்கா-னு confirm பண்ணுங்கள். அப்புறம் private window-ல retry பண்ணுங்கள்.
