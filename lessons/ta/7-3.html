Git, deploy, மற்றும் portfolio v2

இறுதி project உங்கள் laptop-ஐ விட்டு வெளியேறும். வேலையை version control-ல் வையுங்கள், GitHub Pages-ல் வெளியிடுங்கள், ஆவணப்படுத்துங்கள், முகப்புப் பக்கத்தை ஒரு அந்நியருக்கு அனுப்பும் அளவுக்கு நல்லதாக்குங்கள்.

பாடம் 7.3 · Project 3–4 மணி நேரம் இறுதி project

வழங்க வேண்டியவை

  • README மற்றும் சுத்தமான history உள்ள public GitHub repository.
  • GitHub Pages-ல் live-ஆக இருக்கும் மூன்று பக்க portfolio.

வெளியேறும் சரிபார்ப்பு

  • ஒவ்வொரு பக்கமும் 320px-ல், keyboard-உடன் வேலை செய்கிறது.
  • ஒரு interactive feature வேலை செய்கிறது; ஒரு அந்நியரும் தளத்தைப் புரிந்துகொள்ள முடியும்.

Git-ல் வையுங்கள்

Git snapshot-களைப் பதிவு செய்கிறது. சிறிய, வேலை செய்யும் மாற்றங்களை commit செய்யுங்கள்; அப்போது எந்த edit layout-ஐ உடைத்தது என்று யூகிப்பதற்குப் பதிலாக நல்ல நிலைக்குத் திரும்பலாம்.

ஒவ்வொரு commit-க்கும் முன் git status இயக்குங்கள், .DS_Store, node_modules/, local environment files-க்கு .gitignore சேர்க்கவும், secrets-ஐ ஒருபோதும் commit செய்யாதீர்கள். Public repository எப்போதும் public.

GitHub Pages-ல் வெளியிடுங்கள்

  1. portfolio என்ற பெயரில் public repository உருவாக்கி, உங்கள் main branch-ஐ push செய்யுங்கள்.
  2. Settings → Pages திறந்து, Deploy from a branch தேர்ந்தெடுத்து, பிறகு main மற்றும் / (root) தேர்ந்தெடுக்கவும். Save செய்யுங்கள்.
  3. Deployment முடியும் வரை காத்திருங்கள், https://YOUR-NAME.github.io/portfolio/ திறந்து, incognito-விலும் phone-லும் ஒவ்வொரு இணைப்பையும் சோதியுங்கள்.
Custom domain

இந்தப் பாடத்திட்டத்திற்கு அது தேவையில்லை. பின்னர் சேர்த்தால், domain-உடன் CNAME கோப்பு உருவாக்கி, DNS CNAME record-ஐ YOUR-NAME.github.io-க்கு சுட்டி, Pages settings-ல் HTTPS இயக்குங்கள். முதலில் இலவச Pages URL வேலை செய்கிறதா என்று உறுதிப்படுத்துங்கள்.

Portfolio v2 மற்றும் README

இறுதி தளத்தில் மூன்று பக்கங்கள், ஒவ்வொன்றுக்கும் ஒரு வேலை. சிறிய திரையில் வேலை செய்ய வேண்டும், அணுகல்தன்மை pass-ஐ கடக்க வேண்டும், பயனுள்ள ஏதாவது செய்யும் ஒரு interactive feature இருக்க வேண்டும்.

  • மூன்று பக்கங்கள்: Home, About, Projects; அனைத்தும் இணைக்கப்பட்டு 320px-ல் பயன்படுத்தக்கூடியதாக.
  • அணுகக்கூடியது: keyboard access, தெரியும் focus, labels, alt உரை, contrast.
  • Interactive: filter, theme switch, அல்லது state உள்ள வேறு feature.
  • ஆவணப்படுத்தப்பட்டு deploy செய்யப்பட்டது: README மற்றும் console errors இல்லாத public URL.

முகப்புப் பக்கத்தை உருவாக்குங்கள்

Starter-ல் shell-உம் navigation-உம் உள்ளன. ஒரு h1, அறிமுகம், மூன்று project article cards, மற்றும் web projects-க்கு filter செய்யும் button சேர்க்கவும். Button தன் label-ஐயும் aria-pressed நிலையையும் புதுப்பிக்க வேண்டும். Reference-ஐக் காட்டும் முன் Tab, Enter-உடன் சோதியுங்கள்.

வெளியிடும் checklist

  • Repository public; main தற்போதையது; history-ல் secrets இல்லை.
  • Pages main, / (root)-இலிருந்து deploy ஆகிறது; live URL HTTPS-ல் load ஆகிறது.
  • மூன்று பக்கங்களும் load ஆகின்றன, navigation தற்போதையது, எந்த இணைப்பும் படமும் உடையவில்லை.
  • Keyboard pass முடிந்தது; focus தெரிகிறது; தளம் 320px-ல் வேலை செய்கிறது.
  • README-ல் live URL, local steps உள்ளன; ஒருவர் தளத்தைப் பயன்படுத்துவதை நீங்கள் பார்த்தீர்கள்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

GitHub Pages URL-ல் repository பெயர் ஏன் வருகிறது?

Project தளம் https://YOUR-NAME.github.io/repository-name/-இலிருந்து வழங்கப்படுகிறது. அதனால்தான் சார்புப் பாதைகள் முக்கியம்: முன்னால் வரும் slash domain root-ஐ சுட்டுகிறது, உங்கள் project folder-ஐ அல்ல.

Deploy செய்த தளம் 404 திரும்பினால் முதலில் என்ன சரிபார்க்க வேண்டும்?

Repository public-ஆ, Pages சரியான branch, root folder-க்கு அமைக்கப்பட்டதா, அந்த root-ல் index.html இருக்கிறதா, deployment முடிந்ததா என்பதை உறுதிப்படுத்துங்கள். பிறகு private window-ல் மீண்டும் முயற்சியுங்கள்.

பாடத்திட்டம் முடிந்தது

  • ஒரு தளத்தை உருவாக்கி விளக்க முடியும். HTML structure, CSS layout, JavaScript behavior, மற்றும் உண்மையான deployment.
  • உங்கள் வேலையை நீங்களே தணிக்கை செய்ய முடியும். Keyboard, focus, contrast, images, performance ஆகியவை வெளியிடுவதின் பகுதி.
  • நீங்கள் அதை வெளியிட்டீர்கள். மூன்று பக்கங்கள், ஒரு interactive feature, README, பகிரக்கூடிய URL உள்ள live portfolio v2.
