Check yourself

Why should the About Me page link back to the recipe page?

Website-னா connect ஆன pages-ஓட ஒரு set. Navigation reader-க்கு திரும்பி வர வழி கொடுக்கும்; உங்கள் relative paths இரண்டு பக்கமும் work ஆகுது என்பதையும் prove பண்ணும்.

What should you check first if a relative link opens a 404 page?

Filename, extension, folder relationship-ஐ முதல்ல check பண்ணுங்கள். recipe.html-க்கான link, இரண்டு files-உம் same folder-ல இருந்தா தான் work ஆகும்.
