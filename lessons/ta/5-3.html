தொகுதி 05 · DOM & நிகழ்வுகள்

State மற்றும் list-களை render செய்வது

ஒவ்வொரு click-um பக்கத்தை நேரடியாகத் திருத்தினால் list-கள் குழப்பமாகும். உண்மையான தரவை ஒரு சிறிய state array-ல் வைத்திருங்கள், ஒரே render function எழுதுங்கள், ஒவ்வொரு செயலும் அதே வழியாகச் செல்லட்டும்.

பாடம் 5.3 60–75 நிமிடம் தொடக்கநிலை

பாடத்தின் முடிவில், உங்களால் முடியும்

  • List data-ஐ objects கொண்ட state array-ல் சேமிக்கலாம்.
  • அந்த array-ஐ ஒரே function மூலம் render செய்யலாம்.
  • Items-ஐப் பாதுகாப்பாகச் சேர்க்க, toggle செய்ய, நீக்க மற்றும் filter செய்யலாம்.

உங்களுக்குத் தேவை

  • பாடங்கள் 5.1 மற்றும் 5.2 முடிக்கப்பட்டிருக்க வேண்டும்.
  • map மற்றும் filter-ல் பழக்கம்.
  • ஒரு list, ஒரு form மற்றும் காலியான container கொண்ட பக்கம்.

முதலில் state, பிறகு render

State என்பது திரை சார்ந்திருக்கும் data. ஒரு list-க்கு அது objects கொண்ட array. தெரியும் list items-ஐ உண்மையின் மூலமாகக் கருத வேண்டாம்; அவை array-இன் ஒரு rendering மட்டுமே.

ஒவ்வொரு மாற்றமும் அதே மூன்று படிகளைப் பின்பற்றுகிறது: state-ஐப் புதுப்பிக்கவும், render-ஐ அழைக்கவும், திரை அதற்கு ஈடுகொடுக்கட்டும். Render function எதை உண்மை என்பதை முடிவு செய்யாது; தற்போதைய array-ஐ மட்டும் விவரிக்கும்.

ஏன் மீண்டும் தொடங்குகிறோம்

சிறிய list-ஐ அழித்து மீண்டும் கட்டுவது வேகமானது, முன்னறிவிக்கக்கூடியது. ஒரு row புதுப்பிக்கப்பட்டு மற்றொன்று பழையதாக இருப்பது போன்ற பிழைகளின் ஒரு முழு வகையையே இது நீக்குகிறது. மிகப் பெரிய list-களுக்கு, பிறகு தனிப்பட்ட nodes-ஐப் புதுப்பியுங்கள்.

சேர்த்தல், toggle செய்தல் மற்றும் நீக்குதல்

ஒரு id, DOM-ல் உள்ள button-ஐ state-ல் உள்ள ஒரு object-உடன் இணைக்கிறது. அதை data-id attribute-ல் வைத்து dataset.id மூலம் படியுங்கள். Attribute values strings ஆகவே வரும் என்பதை நினைவில் வையுங்கள். Render ஆகும் ஒவ்வொரு row-க்கும், data-action toggle அல்லது remove என அமைக்கப்பட்ட button தேவை; பயிற்சியில் அந்த முழு row-ஐ உருவாக்குவீர்கள்.

list-ல் உள்ள ஒரே listener, ஒவ்வொரு render-க்குப் பிறகும் வேலை செய்கிறது; ஏனெனில் அது buttons-ல் அல்ல, parent-ல் கேட்கிறது. filter நீக்கப்பட்ட item இல்லாத புதிய array-ஐ உருவாக்குகிறது; map ஒரு object மாற்றப்பட்ட புதிய array-ஐ உருவாக்குகிறது. இரண்டும் அடுத்த render-க்குத் தரவை அளிக்கின்றன.

பயனரின் உரை textContent மூலமே DOM-க்குச் செல்ல வேண்டும்; ஒருபோதும் HTML string மூலம் அல்ல. ஒரு item-இன் உரையில் <b> இருந்தால், பார்வையாளர் bold உரையாக அல்ல, அந்த எழுத்துகளையே பார்க்க வேண்டும்.

காலி நிலைகள் மற்றும் filters

Filter-um ஒரு state தான். தற்போதைய தேர்வை ஒரு variable-ல் சேமித்து, தெரிய வேண்டிய subset-ஐ உருவாக்கி, அந்த subset-ஐ render செய்யுங்கள். காலியான முடிவுக்கு வெற்றுப் பெட்டிக்குப் பதிலாக ஒரு செய்தி இருக்க வேண்டும்.

Filter button மாறும்போது, variable-ஐ அமைத்து render function-ஐ மீண்டும் அழையுங்கள். Layout தனி element-க்குத் தாவாமல் இருக்க, காலி செய்தியை அதே list-ல் வைத்திருங்கள்.

பயிற்சி · 30 நிமிடம்

ஒரு list-ஐ render செய்து, சேர்த்து, toggle செய்யுங்கள்

பக்கத்தில் <ul id="list">, <form id="add-form"> மற்றும் <input id="new-item"> உள்ளது என வைத்துக்கொள்ளுங்கள். இரண்டு objects கொண்ட array-ல் தொடங்குங்கள். ஒவ்வொரு item-ஐயும் ஒரு text span மற்றும் toggle button-உடன் render செய்யுங்கள்; array காலியாக இருக்கும்போது காலி செய்தியைக் காட்டுங்கள்; submit-ல் trim செய்த item-ஐச் சேர்க்கவும்; ஒரே delegated click listener மூலம் done-ஐ toggle செய்யவும்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சரிபார்க்கவும்

ஒரு row-ஐ மாற்றுவதற்குப் பதிலாக முழு list-ஐயும் ஏன் மீண்டும் கட்ட வேண்டும்?

முழு render எப்போதும் state array-க்கு ஒத்ததாகவே இருக்கும்; அதனால் filters, எண்ணிக்கைகள் மற்றும் காலி செய்திகள் ஒத்திசைவு இழக்காது. சிறிய list-களுக்கு பராமரிக்க வேண்டிய code-ம் குறைவு.

Item-இன் இடத்திற்குப் பதிலாக id-ஐ ஏன் பயன்படுத்த வேண்டும்?

ஒரு item நீக்கப்படும்போது அல்லது filter செய்யப்படும்போது இடங்கள் மாறும். நிலையான id, array மீண்டும் கட்டப்பட்ட பிறகும் சரியான object-ஐச் சுட்டும்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • State தான் உண்மையின் மூலம். DOM என்பது array-இன் projection; array அல்ல.
  • State-ஐ மாற்றி, பிறகு render செய்யுங்கள். Add, toggle, remove மற்றும் filter-க்கு ஒரே வழி இருந்தால் நடத்தை முன்னறிவிக்கக்கூடியதாக இருக்கும்.
  • ids மற்றும் textContent-ஐப் பயன்படுத்துங்கள். Data attributes controls-ஐ items-உடன் இணைக்கின்றன; plain text பயனர் உள்ளீட்டைப் பாதுகாப்பாக வைக்கிறது.
