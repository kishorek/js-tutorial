Module 03 · Layout & responsive design

Accessibility + landing page

Accessibility என்பது இறுதியில் செய்யும் ஒரு pass அல்ல. Keyboard, screen reader, அல்லது பிரகாசமான வெயிலில் சிறிய screen பயன்படுத்துபவரின் பார்வையில் அதே structure மற்றும் layout முடிவுகளைச் சரிபார்ப்பதுதான்.

  • Live editor-ல் ஒரு responsive landing page.

Landmarks page-க்கு ஒரு map கொடுக்கின்றன

Semantic elements, assistive technology பட்டியலிட்டு jump செய்யக்கூடிய regions உருவாக்குகின்றன. Keyboard பயனர் மீண்டும் மீண்டும் வரும் navigation-ஐ தவிர்க்க skip link முதலில் வருகிறது.

  • ஒரு h1, பிறகு sections-க்கு h2 மற்றும் அவற்றுக்குள் h3; visual அளவுக்காக levels-ஐ தவிர்க்க வேண்டாம்.
  • ஒரு main முதன்மை content-ஐ வைத்திருக்கிறது; header, nav, footer அதைச் சுற்றி அமைகின்றன.
  • Skip link focus-ல் தோன்ற வேண்டும்; display: none அதை keyboard-ல் இருந்து நீக்கிவிடும்.

Names, alternatives மற்றும் focus

பெயர் இல்லாத control ஒரு புதிர். ஒவ்வொரு input-க்கும் for அதன் id-உடன் பொருந்தும் label தேவை. அர்த்தமுள்ள ஒவ்வொரு image-க்கும் alt text தேவை; decoration-க்கு alt="" பயன்படுத்துங்கள்.

outline: none-ஐ மாற்றீடு இல்லாமல் ஒருபோதும் எழுத வேண்டாம். Body text-க்கு 4.5:1, பெரிய text, icons, focus rings-க்கு 3:1 contrast-ஐ இலக்காக வையுங்கள்.

Contrast ஒரு style விருப்பம் அல்ல

வெள்ளைப் பின்னணியில் வெளிர் சாம்பல் text mockup-ல் நேர்த்தியாகத் தெரியும், வெயிலில் மறைந்துவிடும். Screenshot-ஐ அல்ல, color values-ஐ சரிபாருங்கள்.

Keyboard access மற்றும் motion

Page வழியாக Tab செய்யுங்கள். Focus order reading order-க்கு பொருந்த வேண்டும். Clickable div-கள் அல்ல, உண்மையான a மற்றும் button elements பயன்படுத்துங்கள்.

இந்த query content-ஐ நீக்காமல் operating-system விருப்பத்தை மதிக்கிறது. Motion-க்குப் பின்னால் முக்கியமான தகவலை மறைக்க வேண்டாம்.

Landing page-ஐ உருவாக்குங்கள்

தேவைகள். ஒரு skip link, labeled nav உள்ள header, ஒரு h1 மற்றும் call-to-action link உள்ள hero, மூன்று feature cards, இறுதி call to action, ஒரு footer ஆகியவற்றை உருவாக்குங்கள். Grid அல்லது Flexbox மற்றும் ஒரு min-width media query பயன்படுத்துங்கள். 320px, 768px, 1440px-ல் test செய்து, ஒவ்வொரு control வழியாகவும் tab செய்யுங்கள்.

Module 3 முடிந்தது

  • Grid structure-ஐ உருவாக்குகிறது. Named areas மற்றும் minmax(0, 1fr) layouts-ஐ முன்கூட்டியே தெரியும் வகையில் ஆக்குகின்றன.
  • சிறியதாகத் தொடங்கி இடத்தைச் சேருங்கள். Viewport meta மற்றும் min-width queries ஒரே layout எல்லா இடத்திலும் வேலை செய்ய உதவுகின்றன.
  • Accessibility-ஐ test செய்யலாம். Keyboard, focus, names, contrast, reflow ஆகிய ஒவ்வொன்றையும் சரிபார்க்கலாம்.
