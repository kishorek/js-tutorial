Landmarks give the page a map

Semantic elements, assistive technology list பண்ணி jump பண்ணக்கூடிய regions-ஐ build பண்ணும். Keyboard user repeat ஆகுற navigation-ஐ skip பண்ண skip link முதல்ல வரணும்.

  • ஒரு h1; அப்புறம் sections-க்கு h2, அவற்றுக்குள்ள h3; visual size-க்காக levels-ஐ skip பண்ணாதீங்க.
  • ஒரு main primary content-ஐ வைத்திருக்கும்; header, nav, footer அதை சுற்றி இருக்கும்.
  • Skip link focus-ல தோன்றணும்; display: none அதை keyboard-ல இருந்து நீக்கிடும்.

Names, alternatives, and focus

பேர் இல்லாத control ஒரு புதிர். ஒவ்வொரு input-க்கும், அதன் id-உடன் for பொருந்தும் label வேணும். அர்த்தமுள்ள ஒவ்வொரு image-க்கும் alt text வேணும்; decoration-க்கு alt="" use பண்ணுங்கள்.

outline: none-ஐ replace பண்ணாம எப்பவும் எழுதாதீங்க. Body text-க்கு 4.5:1, பெரிய text, icons, focus rings-க்கு 3:1 contrast-ஐ target பண்ணுங்கள்.

Contrast is not a style preference

வெள்ளை background-ல light gray text mockup-ல நல்லா தெரியும், வெயில்ல மறைஞ்சிடும். Screenshot-ஐ அல்ல, color values-ஐ check பண்ணுங்கள்.

Keyboard access and motion

Page-ல Tab பண்ணுங்கள். Focus order reading order-க்கு பொருந்தணும். Clickable div-கள் அல்ல, உண்மையான a மற்றும் button elements use பண்ணுங்கள்.

இந்த query content-ஐ நீக்காம operating-system preference-ஐ respect பண்ணும். Motion-க்கு பின்னாடி முக்கியமான தகவலை மறைக்காதீங்க.

Check yourself

Why must a skip link become visible on focus?

Enter அழுத்துறதுக்கு முன்னாடி focus எங்க இருக்கு-னு keyboard user பார்க்கணும். நிரந்தரமா மறைச்சா அது use பண்ண முடியாததாகிடும்.

When is alt="" correct?

Image decorative-ஆ இருந்து, சுற்றி இருக்குற text-க்கு மேல கூடுதல் தகவல் சேர்க்காதப்போ.
