Module 05 · DOM & events

Selecting and changing the DOM

JavaScript-ஐ use பண்ணி உங்கள் முன்னாடி இருக்கும் page-ஐ read பண்ணி change பண்ண முடிஞ்சா தான் அது useful. DOM-ன்னா அந்த page-ஐ objects-ஓட tree ஆகப் பார்க்கிறது. ஒரு node-ஐ select பண்ண, அதை change பண்ண, புதுசா ஒன்னு create பண்ண, மத்ததை break பண்ணாம remove பண்ண கத்துக்கலாம்.

The document is a tree

Browser உங்கள் HTML-ஐ DOMன்னு சொல்லப்படும் objects-ஓட tree ஆக change பண்ணும். Global document object தான் entry point. Stylesheet-ல நீங்கள் already use பண்ணும் அதே CSS selectors-ஐ use பண்ணி அதுல search பண்ணலாம்.

  • document.querySelector("h1") முதல் match-ஐ return பண்ணும்; எதுவும் இல்லைன்னா null.
  • document.querySelectorAll(".card") ஒவ்வொரு match-ஐயும் NodeList ஆக return பண்ணும்.
  • IDs, classes, attributes, descendant selectors எல்லாம் வேலை செய்யும்: #app, .card, [data-open], nav a.

querySelectorAll-ல இருந்து வரும் NodeList-ல forEach வேலை செய்யும். map அல்லது filter வேணும்னா, முதல்ல Array.from(buttons) use பண்ணி அதை array ஆக convert பண்ணுங்கள்.

Guard the null

எதுவும் match ஆகலைன்னா querySelector null-ஐ return பண்ணும். textContent-ஐ read பண்ணும் முன்னாடி அதை check பண்ணுங்கள்; இல்லைன்னா Cannot read properties of null error வரும்.

Change text without breaking the page

textContent plain text-ஐ read பண்ணும், write-ம் பண்ணும். இது HTML-ஐ parse பண்ணாது; அதனால angle brackets characters-ஆவே தெரியும், elements ஆக change ஆகாது.

innerHTML ஒரு string-ஐ markup ஆக parse பண்ணும். அந்த string உங்களோடது என்றால் அது useful. ஆனா visitor type பண்ணின ஏதாவது string-ல இருந்தா அது dangerous.

Safety rule

Text ஒரு மனுஷங்கிட்ட இருந்து வந்தா, அதை textContent அல்லது text node மூலமா add பண்ணுங்கள். innerHTML-க்கு pass பண்ணும் string-ல elements-ம் event handlers-ம் இருக்கலாம்; அதனால அது code-ஐ run பண்ணிட முடியும்.

Classes, styles, and attributes

பெரும்பாலான visual changes CSS-ல தான் இருக்கணும். JavaScript ஒரு class-ஐ add, remove, toggle பண்ணணும்; ஏராளமான styles-ஐ hard-code பண்ணக்கூடாது.

String-ல CSS property பேர்கள் kebab-case-ல இருக்கும்; style object-ல அவை camelCase-ல இருக்கும். Custom properties-க்கு setProperty("--name", value) வேணும். aria-expanded போன்ற accessibility attributes-ஐ setAttribute-ல தான் வைக்கணும்.

Create, append, and remove

document.createElement மூலமா புது element-ஐ build பண்ணி, அதை fill பண்ணி, பிறகு attach பண்ணுங்கள். Document-ல already இருக்கிற ஏதாவது ஒன்னுல add பண்ணும் வரை புது node கண்ணுக்குத் தெரியாது.

append கடைசில add பண்ணும், prepend ஆரம்பத்தில add பண்ணும், replaceChildren(...) எல்லா children-ஐயும் ஒரே நேரத்தில change பண்ணும். remove() மூலமா node-ஐ remove பண்ணா அது page-ல இருந்து போயிடும்; ஆனா உங்கள் variable இன்னும் அதையே point பண்ணும்.

Check yourself

Why does querySelector sometimes return null?

Selector-க்கு எந்த element-ம் match ஆகல, அல்லது element create ஆகும் முன்னாடியே script run ஆகிடுச்சு. DevTools-ல selector-ஐ check பண்ணுங்கள்; script-ஐ markup-க்கு அப்புறம் வையுங்கள் அல்லது defer attribute-ஐ add பண்ணுங்கள்.

When is innerHTML acceptable?

நீங்களே write பண்ணி control பண்ணும் fixed markup string-ஆ இருந்தா. பேர்கள், comments, search terms, இன்னும் ஒரு மனுஷன் கொடுத்த எதுக்கும் textContent-ஐ use பண்ணுங்கள்.

Key things to remember

  • CSS-ல select பண்ணுங்கள். querySelector ஒரு node-ஐ தரும்; querySelectorAll ஒரு list-ஐ தரும்.
  • Text-ம் markup-ம் ஒன்னு இல்ல. Visitor type பண்ணக்கூடிய எதுக்கும் textContent-ஐ use பண்ணுங்கள்.
  • Build பண்ணி, பிறகு attach பண்ணுங்கள். Element-ஐ create பண்ணி, fill பண்ணி, append பண்ணி, தேவை இல்லாதபோது remove பண்ணுங்கள்.
