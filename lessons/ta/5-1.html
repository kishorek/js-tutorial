தொகுதி 05 · DOM & நிகழ்வுகள்

DOM-ஐத் தேர்ந்தெடுத்து மாற்றுவது

உங்கள் முன் இருக்கும் பக்கத்தைப் படிக்கவும் மாற்றவும் முடியும்போதுதான் JavaScript பயனுள்ளதாகிறது. DOM என்பது அந்தப் பக்கத்தைப் பொருள்களின் மரமாகக் காண்பது: ஒரு node-ஐத் தேர்ந்தெடுப்பது, அதை மாற்றுவது, புதிதாக ஒன்றை உருவாக்குவது, மீதமுள்ளவற்றைப் பாதிக்காமல் அதை நீக்குவது ஆகியவற்றைக் கற்றுக்கொள்ளுங்கள்.

பாடம் 5.1 60–75 நிமிடம் தொடக்கநிலை

பாடத்தின் முடிவில், உங்களால் முடியும்

  • CSS selectors மூலம் ஒரு element-ஐ அல்லது பல element-களைத் தேர்ந்தெடுக்கலாம்.
  • உரை, classes, styles மற்றும் attributes-ஐப் பாதுகாப்பாக மாற்றலாம்.
  • Elements-ஐ உருவாக்கி, append செய்து, நீக்கலாம்.

  • தொகுதி 4: functions மற்றும் arrays.
  • DevTools திறந்திருக்கும் browser.

document என்பது ஒரு மரம்

உங்கள் HTML-ஐ browser, DOM எனப்படும் பொருள்களின் மரமாக மாற்றுகிறது. உலகளாவிய document object தான் நுழைவாயில். நீங்கள் ஏற்கனவே stylesheet-ல் பயன்படுத்தும் அதே CSS selectors மூலம் அதைத் தேடலாம்.

  • document.querySelector("h1") முதல் பொருத்தத்தைத் திருப்பித் தரும்; இல்லையென்றால் null.
  • document.querySelectorAll(".card") ஒவ்வொரு பொருத்தத்தையும் NodeList ஆகத் திருப்பித் தரும்.
  • IDs, classes, attributes மற்றும் descendant selectors எல்லாமே வேலை செய்யும்: #app, .card, [data-open], nav a.

ஒரு NodeList, querySelectorAll-ல் இருந்து கிடைக்கிறது; அது forEach-ஐ ஆதரிக்கிறது. map அல்லது filter தேவைப்பட்டால், முதலில் Array.from(buttons) மூலம் அதை array ஆக மாற்றுங்கள்.

null-ஐச் சரிபார்க்கவும்

எதுவும் பொருந்தாதபோது querySelector null-ஐத் திருப்பித் தரும். textContent-ஐப் படிப்பதற்கு முன் அதைச் சரிபார்க்கவும்; இல்லையென்றால் Cannot read properties of null என்ற error வரும்.

பக்கத்தை உடைக்காமல் உரையை மாற்றுவது

textContent வெறும் உரையைப் படிக்கிறது அல்லது எழுதுகிறது. இது HTML-ஐ ஒருபோதும் parse செய்யாது; அதனால் கோண அடைப்புக்குறிகள் elements ஆகாமல் எழுத்துகளாகவே தெரியும்.

innerHTML ஒரு string-ஐ markup ஆக parse செய்கிறது. string உங்களுடையது என்றால் அது பயனுள்ளது. ஒரு பார்வையாளர் தட்டச்சு செய்த ஏதாவது string-ல் இருந்தால் அது ஆபத்தானது.

பாதுகாப்பு விதி

உரை ஒரு நபரிடமிருந்து வந்திருந்தால், அதை textContent அல்லது ஒரு text node மூலம் சேர்க்கவும். innerHTML-க்கு அனுப்பப்படும் string-ல் elements மற்றும் event handlers இருக்கலாம்; அதாவது அது code-ஐ இயக்க முடியும்.

Classes, styles மற்றும் attributes

பெரும்பாலான காட்சி மாற்றங்கள் CSS-ல் இருக்க வேண்டும். JavaScript ஒரு class-ஐச் சேர்க்க, நீக்க அல்லது toggle செய்ய வேண்டும்; ஏராளமான styles-ஐ hard-code செய்யக்கூடாது.

String-ல் CSS property பெயர்கள் kebab-case-ல் இருக்கும்; style object-ல் அவை camelCase-ல் இருக்கும். Custom properties-க்கு setProperty("--name", value) தேவை. aria-expanded போன்ற accessibility attributes-ஐ setAttribute மூலம் அமைக்க வேண்டும்.

உருவாக்குதல், append செய்தல் மற்றும் நீக்குதல்

document.createElement மூலம் புதிய element-ஐ உருவாக்கி, அதை நிரப்பி, பிறகு இணைக்கவும். document-ல் ஏற்கனவே இருக்கும் ஏதாவது ஒன்றில் சேர்க்கப்படும் வரை புதிய node கண்ணுக்குத் தெரியாது.

append இறுதியில் சேர்க்கும், prepend தொடக்கத்தில் சேர்க்கும், replaceChildren(...) அனைத்து children-ஐயும் ஒரே நேரத்தில் மாற்றும். remove() மூலம் node-ஐ நீக்கினால் அது பக்கத்திலிருந்து விலகும்; ஆனால் உங்கள் variable இன்னும் அதையே குறிக்கும்.

பயிற்சி · 25 நிமிடம்

தலைப்பை highlight செய்து, ஒரு வரிசையைச் சேர்க்கவும்

பக்கத்தில் <h1 id="title">, <ul id="list"> மற்றும் class="old" கொண்ட ஒரு element உள்ளது என வைத்துக்கொள்ளுங்கள். தலைப்பில் is-highlighted என்ற class-ஐ toggle செய்து, அதன் உரையை மாற்றி, உரையுடன் புதிய li ஒன்றை உருவாக்கி, அதை list-ல் append செய்து, பழைய element-ஐ நீக்கி, எத்தனை items மீதமுள்ளன என்பதை log செய்யும் JavaScript எழுதுங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சரிபார்க்கவும்

querySelector சில நேரங்களில் ஏன் null திருப்பித் தருகிறது?

selector-க்கு எந்த element-ம் பொருந்தவில்லை, அல்லது element உருவாகும் முன்பே script இயங்கிவிட்டது. DevTools-ல் selector-ஐச் சரிபார்த்து, markup-க்குப் பிறகு script-ஐ வைக்கவும் அல்லது defer attribute-ஐச் சேர்க்கவும்.

innerHTML எப்போது ஏற்றுக்கொள்ளத்தக்கது?

நீங்கள் எழுதி கட்டுப்படுத்தும் நிலையான markup string ஆக இருந்தால். பெயர்கள், கருத்துகள், தேடல் சொற்கள் மற்றும் ஒரு நபர் வழங்கிய வேறு எதற்கும் textContent-ஐப் பயன்படுத்துங்கள்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • CSS மூலம் தேர்ந்தெடுங்கள். querySelector ஒரு node-ஐத் தரும்; querySelectorAll ஒரு பட்டியலைத் தரும்.
  • உரை markup அல்ல. பார்வையாளர் தட்டச்சு செய்யக்கூடிய எதற்கும் textContent-ஐப் பயன்படுத்துங்கள்.
  • உருவாக்கி, பிறகு இணையுங்கள். Element-ஐ உருவாக்கி, நிரப்பி, append செய்து, தேவை இல்லாதபோது நீக்குங்கள்.
