Storage + weather app

Module project-ஐ build பண்ணுங்கள்: ஒரு city-ஐ search பண்ணி, current conditions-ஐ காட்டி, refresh-ஐயும் survive பண்ணி, user-ஐ blank screen-ல விடாம இருக்குற சின்ன weather app.

Lesson 6.4 · Project2–3 hoursModule milestone

Deliverables

  • Open-Meteo geocoding-ஓட city search.
  • Current temperature மற்றும் weather description.
  • Loading, empty, error, மற்றும் success states.
  • கடைசி city localStorage-ல save ஆகும்.

Exit check

  • Console-ல unhandled errors இல்ல.
  • ஒவ்வொரு state-ம் reachable-ஆவும் visible-ஆவும் இருக்கு.
  • Reload பண்ணா கடைசி successful city restore ஆகும்.
  • Page-ல எங்கயும் secret keys இல்ல.

The brief

Search form, status line, result area — இப்படி ஒரு page build பண்ணுங்கள். Free Open-Meteo APIs-ஐ use பண்ணுங்கள்: geocoding city name-ஐ coordinates-ஆ மாத்தும், பிறகு forecast endpoint current temperature-ஐயும் weather code-ஐயும் return பண்ணும். Key தேவையில்ல.

Requirements

  • Label இருக்குற city input-ம் keyboard-ல work ஆகுற submit button-ம்.
  • count=1-ஓட geocode பண்ணுங்கள்; காலியான results array-ஐ handle பண்ணுங்கள்.
  • முதல் match-க்கு temperature_2m மற்றும் weather_code-ஐ fetch பண்ணுங்கள்.
  • ஒரே state function-லேர்ந்து loading, empty, error, success-ஐ render பண்ணுங்கள்.
  • Successful city-ஐ save பண்ணி அடுத்த visit-ல restore பண்ணுங்கள்.
  • Status-க்கு aria-live="polite", API text-க்கு textContent use பண்ணுங்கள்.

State checklist

  • Idle: முதல் search-க்கு முன்னாடி சின்ன instruction.
  • Loading: ஏதாவது ஒரு request run ஆகும்போது message; பழைய results-ஐ hide பண்ணுங்கள்.
  • Empty: geocoding எந்த match-ம் return பண்ணல; வேற spelling suggest பண்ணுங்கள்.
  • Error: network இல்ல HTTP failure; explain பண்ணி form-ஐ retry-ஆ offer பண்ணுங்கள்.
  • Success: place, rounded temperature, படிக்கக்கூடிய description.
  • Storage: success-க்குப் பிறகு மட்டும் save; blocked storage app-ஐ break பண்ணக்கூடாது.

Save a city and a unit

localStorage tab close ஆன பிறகும் data-ஐ வைக்கும். sessionStorage current tab-க்கு மட்டும் வைக்கும். ரெண்டும் strings-ஐ மட்டும் store பண்ணும், அதனால objects-ஐ JSON.stringify()-ஓட convert பண்ணி, JSON.parse()-ஓட மறுபடி read பண்ணுங்கள்.

Storage calls-ஐ try/catch-ல wrap பண்ணுங்கள். Private modes-லயும் sandboxed previews-லயும் browser storage-ஐ block பண்ணலாம், quota full ஆனா setItem() throw பண்ணும். Editor preview-ல storage block ஆகலாம், அதனால warning path-ம் exercise-ன் ஒரு பாகம்.

Privacy and limits

Storage உங்க origin-க்குச் சொந்தம், அந்த page-ல இருக்குற எந்த script-ம் read பண்ணலாம். Tokens, passwords, இல்ல personal data-ஐ store பண்ணாதீங்க. சில megabytes மட்டும்தான் expect பண்ணுங்கள், saved settings-ஐ clear பண்ண ஒரு வழியும் கொடுங்கள்.

Check yourself

Why save the city instead of the temperature?

Weather எப்பவும் மாறும். Save பண்ணின city ஒரு stable preference; save பண்ணின temperature page reload ஆனதுமே stale ஆகிடும். Choice-ஐ store பண்ணி, fresh data-ஐ fetch பண்ணுங்கள்.

Why wrap localStorage calls in try/catch?

Storage private modes-லயும் sandboxed previews-லயும் block ஆகலாம், quota full ஆனா setItem() fail ஆகலாம். Error-ஐ catch பண்ணா, saving work ஆகலனாலும் weather app use பண்ணக்கூடியதா இருக்கும்.
