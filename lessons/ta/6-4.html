Storage + வானிலை app

Module project-ஐ உருவாக்குங்கள்: ஒரு city-ஐத் தேடி, தற்போதைய நிலையைக் காட்டி, refresh ஆனாலும் தகவலைத் தக்கவைத்து, user-ஐ ஒருபோதும் blank screen-ஐப் பார்க்க வைக்காத சிறிய வானிலை app.

பாடம் 6.4 · Project2–3 மணி நேரம்தொகுதி மைல்கல்

வழங்க வேண்டியவை

  • Open-Meteo geocoding உடன் city search.
  • தற்போதைய temperature மற்றும் வானிலை விவரம்.
  • Loading, empty, error, மற்றும் success நிலைகள்.
  • கடைசி city localStorage-ல் சேமிக்கப்படும்.

முடிவுச் சரிபார்ப்பு

  • Console-ல் கையாளப்படாத errors இல்லை.
  • ஒவ்வொரு நிலையும் அடையக்கூடியதாகவும் தெரியக்கூடியதாகவும் உள்ளது.
  • Reload செய்தால் கடைசி வெற்றிகரமான city மீட்கப்படும்.
  • Page-ல் எங்கும் secret keys இல்லை.

சுருக்கமான விவரம்

Search form, status line, மற்றும் result area உள்ள ஒரு page உருவாக்குங்கள். இலவச Open-Meteo APIs-ஐப் பயன்படுத்துங்கள்: geocoding city name-ஐ coordinates ஆக மாற்றும்; பிறகு forecast endpoint தற்போதைய temperature மற்றும் weather code-ஐத் திருப்பித் தரும். Key தேவையில்லை.

தேவைகள்

  • Label உள்ள city input மற்றும் keyboard-ல் வேலை செய்யும் submit button.
  • count=1 உடன் geocode செய்யுங்கள்; காலியான results array-ஐக் கையாளுங்கள்.
  • முதல் match-க்கு temperature_2m மற்றும் weather_code-ஐ fetch செய்யுங்கள்.
  • ஒரே state function-ல் இருந்து loading, empty, error, success-ஐ render செய்யுங்கள்.
  • வெற்றிகரமான city-ஐச் சேமித்து, அடுத்த visit-ல் மீட்டெடுங்கள்.
  • Status-க்கு aria-live="polite", API text-க்கு textContent பயன்படுத்துங்கள்.

State சரிபார்ப்பு பட்டியல்

  • Idle: முதல் search-க்கு முன் சிறிய instruction.
  • Loading: ஏதேனும் request இயங்கும்போது message; பழைய முடிவுகளை மறைக்கவும்.
  • Empty: geocoding பொருந்தியதைத் திருப்பித் தரவில்லை; வேறு எழுத்துவடிவைப் பரிந்துரைக்கவும்.
  • Error: network அல்லது HTTP தோல்வி; விளக்கி, form-ஐ retry ஆக வழங்குங்கள்.
  • Success: இடம், rounded temperature, மற்றும் படிக்கக்கூடிய விவரம்.
  • Storage: வெற்றிக்குப் பிறகு மட்டும் சேமிக்கவும்; தடுக்கப்பட்ட storage app-ஐ உடைக்கக்கூடாது.

ஒரு city-ஐயும் unit-ஐயும் சேமிக்கவும்

localStorage tab மூடிய பிறகும் data-வை வைத்திருக்கும். sessionStorage தற்போதைய tab-க்கு மட்டுமே வைத்திருக்கும். இரண்டும் strings-ஐ மட்டும் சேமிக்கும், எனவே objects-ஐ JSON.stringify() கொண்டு மாற்றி, JSON.parse() கொண்டு திரும்பப் படியுங்கள்.

Storage calls-ஐ try/catch-ல் வையுங்கள். Private modes அல்லது sandboxed previews-ல் browser storage-ஐத் தடுக்கலாம்; quota நிரம்பியிருக்கும்போது setItem() error throw செய்யும். Editor preview-ல் storage தடுக்கப்படலாம், எனவே warning path-ம் இந்தப் பயிற்சியின் ஒரு பகுதி.

Privacy மற்றும் வரம்புகள்

Storage உங்கள் origin-க்குச் சொந்தமானது; அந்த page-ல் உள்ள எந்த script-ம் அதைப் படிக்கலாம். Tokens, passwords, அல்லது personal data சேமிக்க வேண்டாம். சில megabytes மட்டுமே எதிர்பாருங்கள்; சேமித்த settings-ஐ clear செய்ய வழி வையுங்கள்.

உங்களைச் சரிபாருங்கள்

Temperature-க்குப் பதிலாக city-ஐ ஏன் சேமிக்க வேண்டும்?

வானிலை தொடர்ந்து மாறும். சேமித்த city ஒரு நிலையான விருப்பம்; சேமித்த temperature page reload ஆனவுடன் பழையதாகிவிடும். தேர்வைச் சேமித்து, பிறகு புதிய data-ஐ fetch செய்யுங்கள்.

localStorage calls-ஐ try/catch-ல் ஏன் வைக்க வேண்டும்?

Private modes மற்றும் sandboxed previews-ல் storage தடுக்கப்படலாம்; quota நிரம்பியிருக்கும்போது setItem() தோல்வியடையலாம். Error-ஐப் பிடிப்பது, சேமிக்க முடியாதபோதும் வானிலை app-ஐ பயன்படுத்தக்கூடியதாக வைத்திருக்கும்.

தொகுதி 6 நிறைவு

  • Async code என்பது நிலைகளின் வரிசை. Promises மற்றும் async/await அந்த வரிசையைத் தெளிவாக எழுத உதவுகின்றன.
  • ஒவ்வொரு request-ம் தோல்வியடையலாம் அல்லது எதையும் கண்டுபிடிக்காமல் இருக்கலாம். Loading, empty, error, success-ஐ தேவைப்படும் முன்பே வடிவமைத்து வையுங்கள்.
  • இழக்கத் தயாராக இருக்கும் data-வை மட்டும் சேமிக்கவும். Storage-ஐ wrap செய்யுங்கள், secrets-ஐ server-ல் வையுங்கள், கடைசி பயனுள்ள தேர்வை மீட்டெடுங்கள்.
