Loops மற்றும் collections

உண்மையான நிரல்கள் ஒன்றுக்கு மேற்பட்ட மதிப்புகளுடன் வேலை செய்கின்றன. பட்டியல்களை arrays-ல் சேமிக்க, loop கொண்டு ஒவ்வொரு item-ஐயும் பார்க்க, அதே loop-ஐ மீண்டும் மீண்டும் எழுதுவதற்குப் பதிலாக map, filter, reduce கொண்டு தரவை மாற்றக் கற்றுக்கொள்ளுங்கள்.

பாடம் 4.3 60–75 நிமிடங்கள் தொடக்கநிலை

இறுதியில் நீங்கள் செய்யக்கூடியவை

  • Arrays உருவாக்கி, அவற்றின் items-ஐப் படிக்கவும் மாற்றவும் முடியும்.
  • for, while மற்றும் for...of கொண்டு வேலையை மீண்டும் செய்ய முடியும்.
  • map, filter மற்றும் reduce கொண்டு பட்டியல்களை மாற்ற முடியும்.
  • வேலைக்குப் பொருந்தும் loop-ஐத் தேர்ந்தெடுக்க முடியும்.

உங்களுக்குத் தேவையானவை

  • பாடம் 4.2-இன் நிபந்தனைகள் மற்றும் truthiness.
  • விரைவான சோதனைகளுக்கான console.
  • Off-by-one பிழைகளுக்குப் பொறுமை.

Arrays வரிசைப்படுத்தப்பட்ட பட்டியல்களை வைத்திருக்கின்றன

Array பல மதிப்புகளை வரிசையாகச் சேமிக்கிறது. Square brackets ஒன்றை உருவாக்கும்; ஒவ்வொரு item-க்கும் ஒரு index உண்டு. Indexes பூஜ்ஜியத்தில் தொடங்கும்; எனவே முதல் item 1-ல் அல்ல, 0-ல் இருக்கும்.

  • push(item) இறுதியில் சேர்க்கும்; புதிய length-ஐத் திருப்பித் தரும்.
  • pop() கடைசி item-ஐ நீக்கி அதைத் திருப்பித் தரும்.
  • shift() மற்றும் unshift() தொடக்கத்தில் வேலை செய்கின்றன; ஆனால் பெரிய arrays-ல் மெதுவாக இருக்கும்.
  • முடிவுக்கு அப்பால் படித்தால் undefined கிடைக்கும்; error வீசாது.

Arrays எந்த வகையையும் வைத்திருக்கலாம்; மற்ற arrays-ஐயும் வைத்திருக்கலாம். தொடக்கநிலையில் ஒரு array-க்கு ஒரு வகை மதிப்பை மட்டும் வைத்தால் code-ஐப் புரிந்துகொள்வது எளிதாகும்.

for loops வேலையை மீண்டும் செய்கின்றன

for loop-க்கு மூன்று பகுதிகள் உண்டு: தொடக்கப் புள்ளி, அது தொடர்ந்து இயங்க நிபந்தனை, ஒவ்வொரு சுற்றுக்குப் பிறகு update. ஒவ்வொரு iteration-க்கும் முன் நடுப்பகுதி சரிபார்க்கப்படும்.

Indexes கொண்டு array மீது loop செய்யும்போது 0-ல் தொடங்கி, index array.length-ஐவிடச் சிறியதாக இருக்கும் வரை தொடருங்கள். <= பயன்படுத்தினால் முடிவுக்கு அப்பால் ஒரு item படிக்கப்பட்டு undefined கிடைக்கும்.

while loop ஒரு நிபந்தனை true ஆக இருக்கும் வரை மீண்டும் இயங்கும். எத்தனை சுற்றுகள் என்று முன்கூட்டியே தெரியாதபோது இதைப் பயன்படுத்துங்கள்; ஆனால் loop-க்குள் ஏதாவது மாறுகிறது என்பதை உறுதிசெய்யுங்கள்.

முடிவில்லா loop-ஐத் தவிர்க்கவும்

நிபந்தனை ஒருபோதும் false ஆகவில்லை என்றால் பக்கம் முடங்கும். Loop body நிபந்தனையில் பயன்படுத்தப்படும் மதிப்பை update செய்கிறதா என்று பாருங்கள். Browser-ல் tab-ஐ மூட வேண்டியிருக்கலாம்.

for...of மதிப்புகளை நேரடியாகப் படிக்கிறது

ஒவ்வொரு மதிப்பு மட்டும் தேவைப்பட்டால், index loop-ஐவிட for...of சுருக்கமானது, தவறு செய்வதும் கடினம். இது மதிப்புகளை வரிசையாகப் பார்க்கும்.

மதிப்புடன் index-ம் தேவைப்பட்டால், அல்லது சில items-ஐத் தவிர்க்க வேண்டுமானால் classic for loop பயன்படுத்துங்கள். ஒவ்வொரு item-ஐ மட்டும் விரும்பினால் for...of பயன்படுத்துங்கள்.

map, filter மற்றும் reduce கொண்டு மாற்றுங்கள்

பல loops இதே மூன்று முறைகளைப் பின்பற்றுகின்றன: ஒவ்வொரு item-ஐயும் மாற்றுவது, சில items-ஐ வைத்திருப்பது, அல்லது பட்டியலை ஒரே மதிப்பாகச் சுருக்குவது. JavaScript ஒவ்வொன்றுக்கும் ஒரு method தருகிறது.

Methodவேலைதிருப்பித் தருவது
mapஒவ்வொரு item-ஐயும் மாற்றுஅதே length உள்ள புதிய array
filterசோதனையில் தேர்ச்சி பெறும் items-ஐ வைத்திருபுதிய, பொதுவாகச் சிறிய array
reduceஎல்லா items-ஐயும் ஒரே மதிப்பாக இணைஒரே மதிப்பு

map-க்கு நீங்கள் அளிக்கும் callback ஒவ்வொரு item-க்கும் ஒருமுறை இயங்கி, அதற்குப் பதிலாக வைக்க வேண்டிய மதிப்பைத் திருப்பித் தரும். filter-ன் callback ஒரு item-ஐ வைத்திருக்க true, நீக்க false திருப்பித் தரும். reduce-ன் callback தற்போதைய மொத்த முடிவையும் தற்போதைய item-ஐயும் பெறும்; reduce-க்கு அளிக்கும் இரண்டாவது argument தொடக்க மதிப்பு.

அசலை வைத்திருங்கள்

map, filter மற்றும் reduce அசல் array-ஐ மாற்றுவதில்லை. அவை புதிய மதிப்பைத் திருப்பித் தருகின்றன. அதனால் அவற்றைப் பாதுகாப்பாக chain செய்யலாம், சோதிக்கவும் எளிது.

அவற்றை chain செய்யலாம். இந்த எடுத்துக்காட்டு 10-க்கு மேற்பட்ட விலைகளை வைத்து, அவற்றை இரட்டிப்பாக்கி, முடிவைக் கூட்டுகிறது:

இரட்டை எண்களைக் கூட்டி, பிறகு மாற்றுங்கள்

எண்களின் array-யுடன் தொடங்குங்கள். இரட்டை எண்களை மட்டும் கூட்டி மொத்தத்தை log செய்ய for...of loop பயன்படுத்துங்கள். பிறகு ஒவ்வொரு எண்ணையும் இரட்டிப்பாக்க map-ஐயும், 10-ஐவிடப் பெரிய எண்களை வைத்திருக்க filter-ஐயும் பயன்படுத்துங்கள். இரண்டு புதிய arrays-ஐயும் log செய்யுங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

array[array.length] ஏன் undefined திருப்பித் தருகிறது?

Indexes 0 முதல் length - 1 வரை இருக்கும். Length-க்குச் சமமான index கேட்டால், கடைசி item-க்கு அப்பால் ஒரு நிலையைக் குறிக்கும். கடைசி item-க்கு array[array.length - 1] பயன்படுத்துங்கள்.

எப்போது loop-க்குப் பதிலாக reduce பயன்படுத்த வேண்டும்?

ஒவ்வொரு item-லிருந்தும் கட்டப்படும் ஒரே மதிப்பு முடிவாக இருக்கும்போது reduce பயன்படுத்துங்கள்; எடுத்துக்காட்டாக ஒரு sum, ஒரு count அல்லது ஒரு lookup object. Side effects அல்லது இடையிலேயே வெளியேற வேண்டுமானால் சாதாரண loop பொதுவாகத் தெளிவாக இருக்கும்.

நினைவில் கொள்ள வேண்டிய முக்கிய விஷயங்கள்

  • Arrays பூஜ்ஜியத்தில் தொடங்கும். length கடைசி index-ஐவிட ஒன்று அதிகம்.
  • வேலைக்கு ஏற்ற loop-ஐத் தேர்ந்தெடுங்கள். நிலைகளுக்கு index loop, மதிப்புகளுக்கு for...of, தெரியாத எண்ணிக்கைக்கு while.
  • map, filter மற்றும் reduce மீண்டும் மீண்டும் வரும் loop முறைகளுக்குப் பதிலாகின்றன. அவை புதிய மதிப்புகளைத் திருப்பித் தருகின்றன; அசல் array-ஐத் தொடுவதில்லை.
