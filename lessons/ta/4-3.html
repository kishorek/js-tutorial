Arrays hold ordered lists

Array பல values-ஐ order-ல store பண்ணும். Square brackets ஒன்றை உருவாக்கும், ஒவ்வொரு item-க்கும் ஒரு index உண்டு. Indexes zero-ல start ஆகும், அதனால முதல் item 0-ல, 1-ல இல்ல.

  • push(item) end-ல add பண்ணி புது length-ஐ return பண்ணும்.
  • pop() கடைசி item-ஐ remove பண்ணி அதை return பண்ணும்.
  • shift() மற்றும் unshift() start-ல வேலை செய்யும், ஆனா பெரிய arrays-ல slow.
  • End-க்கு மேல read பண்ணினா undefined கிடைக்கும்; error throw ஆகாது.

Arrays எந்த type-ஐயும் hold பண்ணும், மற்ற arrays உட்பட. Beginners-க்கு, ஒரு array-ல ஒரே வகை value வைத்திருந்தா code-ஐ reason பண்ண எளிது.

for loops repeat work

for loop-க்கு மூன்று parts: ஒரு starting point, அது ஓடிக்கொண்டிருக்க ஒரு condition, ஒவ்வொரு pass-க்குப் பிறகு ஒரு update. நடுப் part ஒவ்வொரு iteration-க்கும் முன்னாடி check ஆகும்.

Indexes கொண்டு array-ஐ loop பண்ணும்போது 0-ல start பண்ணி, index array.length-ஐ விட குறைவா இருக்கும்போது நிறுத்துங்க. <= use பண்ணினா end-க்கு ஒரு item extra read ஆகி undefined கிடைக்கும்.

while loop ஒரு condition true-ஆ இருக்கும் வரை repeat ஆகும். Passes எண்ணிக்கை முன்கூட்டியே தெரியாதபோது use பண்ணுங்க, ஆனா loop-க்கு உள்ளே ஏதாவது மாற்றம் நடக்கிறதா என்று பாருங்க.

Avoid the infinite loop

Condition எப்பவும் false ஆகலைனா page freeze ஆகும். Loop body, condition-ல use ஆகிற value-ஐ update பண்ணுதா என்று check பண்ணுங்க. Browser-ல tab-ஐ close பண்ண வேண்டியிருக்கலாம்.

for...of reads values directly

ஒவ்வொரு value மட்டும் தேவைப்பட்டா, for...of index loop-ஐ விட சின்னதும் தவறு ஆவதும் கஷ்டமானதும். அது values-ஐ order-ல visit பண்ணும்.

Index-ஐயும் value-ஐயும் சேர்த்து தேவைப்பட்டா, அல்லது items-ஐ skip பண்ண வேண்டியிருந்தா classic for loop use பண்ணுங்க. ஒவ்வொரு item மட்டும் வேண்டும்னா for...of use பண்ணுங்க.

Transform with map, filter, and reduce

பல loops ஒரே மூன்று patterns-ஐ follow பண்ணும்: ஒவ்வொரு item-ஐயும் change பண்ணு, சில items-ஐ வைத்துக்கொள், அல்லது list-ஐ ஒரே value-ஆ சுருக்கு. JavaScript ஒவ்வொன்றுக்கும் ஒரு method தருகிறது.

Keep the original

map, filter, reduce original array-ஐ change பண்ணாது. புது value-ஐ return பண்ணும். அதனால chain பண்ண safe, test பண்ண எளிது.

Check yourself

Why does array[array.length] return undefined?

Indexes 0-லிருந்து length - 1 வரை. Length-க்கு சமமான index கேட்டா கடைசி item-க்கு ஒரு position அப்பால் point ஆகும். கடைசி item-க்கு array[array.length - 1] use பண்ணுங்க.

When should I use reduce instead of a loop?

Result ஒவ்வொரு item-லிருந்தும் build ஆகிற ஒரே value-ஆ இருந்தா reduce use பண்ணுங்க; sum, count அல்லது lookup object போல. Side effects அல்லது early exit-க்கு plain loop பொதுவா clear.

Key things to remember

  • Arrays zero-ல start ஆகும். length கடைசி index-ஐ விட ஒண்ணு அதிகம்.
  • வேலைக்கு loop-ஐ choose பண்ணுங்க. Positions-க்கு index loop, values-க்கு for...of, தெரியாத count-க்கு while.
  • map, filter, reduce repeated loop patterns-ஐ replace பண்ணும். அவை புது values return பண்ணி original array-ஐ அப்படியே விட்டுவிடும்.
