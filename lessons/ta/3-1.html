CSS Grid

Flexbox items-ஐ ஒரு line-ல distribute பண்ணும். Grid-ல rows-ஐயும் columns-ஐயும் ஒரே நேரத்தில் control பண்ணலாம். அதனால galleries, dashboards, முழு page layouts-ஐ தற்செயலா அல்லாமல் நினைத்தபடி predictable-ஆ build பண்ண முடியும்.

Grid works in two dimensions

display: grid வைத்து ஒரு element-ஐ grid container ஆக்குங்கள். அதன் direct children grid items ஆகும். gap property margins இல்லாமல் அவற்றுக்கு நடுவே space விடும்.

  • Container: display: grid உள்ள element.
  • Item: அந்த container-இன் ஒவ்வொரு direct child.
  • Track: ஒரு column அல்லது ஒரு row.
  • Cell: ஒரு row-ஐயும் column-ஐயும் சந்திக்கும் இடம்.

Grid-உம் Flexbox-உம் போட்டியா இல்ல, சேர்ந்து வேலை பண்றவை. Layout-இன் shape இரு direction-லயும் தெரிஞ்சா Grid use பண்ணுங்கள். Items ஒரே axis-ல flow ஆகணும்னா Flexbox use பண்ணுங்கள்.

Fractions, repeat, and minmax

Fixed sizes-க்கும் gaps-க்கும் அப்புறம் மீதி இருக்கும் space-ஐ fr unit share பண்ணும். மூன்று 1fr columns சமம். 2fr column, 1fr column-க்கு கிடைக்கும் free space-ஐ விட இரண்டு மடங்கு எடுக்கும்.

  • repeat(3, 1fr) என்பது 1fr 1fr 1fr-க்கு short form.
  • minmax(0, 1fr) ஒரு track-ஐ அதன் content width-க்குக் கீழேயும் shrink ஆக விடும். அதனால நீளமான words layout-ஐ break பண்ணாது.
  • grid-column: 1 / -1 முதல் line-ல இருந்து கடைசி line வரை span பண்ணி, item-ஐ full width ஆக்கும்.
  • grid-auto-rows நீங்கள் declare பண்ணாத rows-க்கு size கொடுக்கும்.

Media query இல்லாமல் respond ஆகும் gallery-க்கு, fixed count-க்கு பதிலா auto-fit use பண்ணுங்கள். Browser முடிந்த அளவு 220px tracks-ஐ fit பண்ணி, அப்புறம் row-ஐ fill பண்ண stretch பண்ணும்.

auto-fit vs auto-fill

auto-fit காலியான tracks-ஐ collapse பண்ணும்; அதனால இருக்குற cards row-ஐ fill பண்ண stretch ஆகும். auto-fill காலியான tracks-ஐ வைத்துக்கொள்ளும்; அதனால cards minimum size-லயே நின்று gap விடும். Cards grow ஆகணுமா என்பதை பார்த்து choose பண்ணுங்கள்.

Rows and alignment

Vertical structure முக்கியமான போது rows-ஐ declare பண்ணுங்கள். உதாரணமா, footer கீழே இருக்கணும், page முழு viewport-ஐ fill பண்ணணும்-னு இருக்கும்போது.

  • justify-items items-ஐ அவங்க column-க்குள்ள align பண்ணும்; justify-content முழு grid-ஐயும் container-க்குள்ள align பண்ணும்.
  • align-items மற்றும் align-content vertical axis-ல அதே வேலையை பண்ணும்.
  • place-items: center இரண்டு alignment properties-ஐயும் ஒரே நேரத்தில் set பண்ணும்.
  • auto row content-க்கு ஏத்தபடி grow ஆகும்; 1fr row மீதி space-ஐ எடுத்துக்கும்.

Named areas describe the page

grid-template-areas layout-ஐ text-ஆ draw பண்ணும். பேர் வைத்த ஒவ்வொரு cell-உம் ஒரு rectangle ஆக இருக்கணும்; ஒவ்வொரு item-உம் grid-area வைத்து தன் area-ஐ claim பண்ணணும்.

Named areas ஒரு documentation ஆகிடும். Teammate ஒருவர் ஐந்து lines-ல layout-ஐ read பண்ணலாம். சிறிய screen-ல column count-உம் area map-உம் மட்டும் மாறும்; item rules அப்படியே இருக்கும்.

Common mistake

Area நடுவில hole வைக்காதீங்க. ஒரு row "header header", அடுத்த row "main sidebar"னா shape இன்னும் சரியா இருக்கும். ஆனா "header ." பேர் இல்லாத cell-ஐ build பண்ணி, அப்புறம் உங்களை குழப்பும். உண்மையா காலி இடம் வேணும்னா மட்டும் period use பண்ணுங்கள்.

Check yourself

When should you reach for Grid instead of Flexbox?

Layout rows-லயும் columns-லயும் ஒரே நேரத்தில் align ஆகணும்னா, gallery அல்லது page skeleton மாதிரி. Items ஒரே axis-ல flow அல்லது distribute ஆனா மட்டும் போதும்னா Flexbox simpler.

Why write minmax(0, 1fr) instead of just 1fr?

சாதாரண 1fr track-க்கு அதன் content-ஐ base-ஆ வைத்து automatic minimum இருக்கும். நீளமான, உடையாத word column-ஐ screen-ஐ விட அகலமாக்கும். minmax(0, 1fr) அந்த minimum-ஐ zero ஆக்கும்; அதனால track shrink ஆக முடியும்.

Key things to remember

  • Grid is two-dimensional. Container-ல columns-ஐயும் rows-ஐயும் define பண்ணுங்கள்.
  • fr shares free space. Safe flexible tracks-க்கு minmax(0, 1fr) உடன் சேருங்கள்.
  • Named areas make layout readable. ஒவ்வொரு item-ஐயும் மறுபடி எழுதாம, breakpoint-ல map-ஐ மாற்றுங்கள்.
