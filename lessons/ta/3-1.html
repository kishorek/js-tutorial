Module 03 · Layout & responsive design

CSS Grid

Flexbox ஒரு வரிசையில் items-ஐ பரப்புகிறது. Grid ஒரே நேரத்தில் rows மற்றும் columns-ஐ கட்டுப்படுத்துகிறது; அதனால் galleries, dashboards, முழு page layouts தற்செயலாக அல்லாமல் முன்கூட்டியே திட்டமிட்டபடி அமையும்.

பாடம் 3.1 60–75 நிமிடங்கள் தொடக்கநிலை

இதன் முடிவில், உங்களால் முடியும்

  • fr மற்றும் repeat() கொண்டு columns மற்றும் rows உருவாக்குவது.
  • minmax() மற்றும் auto-fit கொண்டு அளவு மாறும் tracks கட்டுவது.
  • Named grid areas கொண்டு ஒரு page-ஐ அமைப்பது.

உங்களுக்குத் தேவை

  • Module 2: box model மற்றும் Flexbox.
  • சில cards அல்லது sections உள்ள ஒரு page.
  • Grid-ஐ inspect செய்ய DevTools திறந்திருப்பது.

Grid இரு பரிமாணங்களில் வேலை செய்கிறது

display: grid கொண்டு ஒரு element-ஐ grid container ஆக்குங்கள். அதன் நேரடி children grid items ஆகும். gap property margins இல்லாமல் அவற்றுக்கு இடையே இடைவெளி வைக்கிறது.

  • Container: display: grid உள்ள element.
  • Item: அந்த container-இன் ஒவ்வொரு நேரடி child.
  • Track: ஒரு column அல்லது ஒரு row.
  • Cell: ஒரு row-ஐயும் column-ஐயும் சந்திக்கும் இடம்.

Grid-உம் Flexbox-உம் போட்டியாளர்கள் அல்ல, கூட்டாளிகள். Layout-இன் வடிவம் இரு திசைகளிலும் தெரிந்திருந்தால் Grid-ஐ பயன்படுத்துங்கள். Items ஒரே axis-ல் ஓட வேண்டுமானால் Flexbox-ஐ பயன்படுத்துங்கள்.

Fractions, repeat, minmax

நிலையான அளவுகளுக்கும் gaps-க்கும் பிறகு மீதமுள்ள இடத்தை fr unit பங்கிடுகிறது. மூன்று 1fr columns சமமானவை. 2fr column, 1fr column-க்கு கிடைக்கும் free space-ஐ விட இரண்டு மடங்கு பெறும்.

  • repeat(3, 1fr) என்பது 1fr 1fr 1fr-க்கான சுருக்கம்.
  • minmax(0, 1fr) ஒரு track தன் content width-க்குக் கீழே சுருங்க அனுமதிக்கிறது; இது நீளமான words layout-ஐ உடைப்பதைத் தடுக்கும்.
  • grid-column: 1 / -1 முதல் line முதல் கடைசி line வரை பரவி, item-ஐ முழு width ஆக்குகிறது.
  • grid-auto-rows நீங்கள் declare செய்யாத rows-க்கு அளவு வழங்குகிறது.

Media query இல்லாமல் respond செய்யும் gallery-க்கு, நிலையான எண்ணிக்கைக்குப் பதிலாக auto-fit பயன்படுத்துங்கள். Browser முடிந்த அளவுக்கு 220px tracks-ஐ பொருத்தி, பிறகு row-ஐ நிரப்ப அவற்றை stretch செய்யும்.

auto-fit vs auto-fill

auto-fit காலியான tracks-ஐ சுருக்கிவிடும்; அதனால் இருக்கும் cards row-ஐ நிரப்ப stretch ஆகும். auto-fill காலியான tracks-ஐ வைத்துக்கொள்ளும்; அதனால் cards தங்கள் குறைந்தபட்ச அளவிலேயே நின்று இடைவெளி விடும். Cards வளர வேண்டுமா என்பதைப் பொறுத்து தேர்ந்தெடுங்கள்.

Rows மற்றும் alignment

Vertical structure முக்கியமானபோது rows-ஐ declare செய்யுங்கள்; உதாரணமாக, footer கீழே இருக்கும்படி page முழு viewport-ஐ நிரப்ப வேண்டியிருக்கும்போது.

  • justify-items items-ஐ அவற்றின் column-க்குள் align செய்கிறது; justify-content முழு grid-ஐயும் container-க்குள் align செய்கிறது.
  • align-items மற்றும் align-content vertical axis-ல் அதையே செய்கின்றன.
  • place-items: center இரண்டு alignment properties-ஐயும் ஒரே நேரத்தில் அமைக்கிறது.
  • ஒரு auto row தன் content-க்கு ஏற்ப வளரும்; ஒரு 1fr row மீதமுள்ள இடத்தை எடுத்துக்கொள்ளும்.

Named areas page-ஐ விவரிக்கின்றன

grid-template-areas layout-ஐ text ஆக வரைகிறது. பெயரிடப்பட்ட ஒவ்வொரு cell-um ஒரு rectangle ஆக இருக்க வேண்டும்; ஒவ்வொரு item-um grid-area மூலம் தன் area-ஐ கோர வேண்டும்.

Named areas ஒரு documentation ஆக மாறும். Teammate ஒருவர் ஐந்து வரிகளில் layout-ஐ படிக்கலாம். குறுகிய screen-ல் column எண்ணிக்கையும் area map-ம் மட்டுமே மாறும்; item rules அப்படியே இருக்கும்.

பொதுவான தவறு

Area-வின் நடுவில் ஒரு hole வைக்க வேண்டாம். ஒரு row "header header" என்றும் அடுத்த row "main sidebar" என்றும் இருந்தால் வடிவம் இன்னும் சரியாகவே இருக்கும். ஆனால் "header ." பெயரிடாத cell-ஐ உருவாக்கி பிறகு உங்களை குழப்பும். உண்மையிலேயே காலி இடம் வேண்டும்போது மட்டும் period பயன்படுத்துங்கள்.

Responsive card gallery

ஆறு cards உள்ள gallery-க்கு CSS எழுதுங்கள். அகலமான screens-ல் மூன்று சமமான columns காட்ட வேண்டும். 760px-க்குக் கீழே ஒரு column ஆக வேண்டும். repeat(), minmax(0, 1fr), gap பயன்படுத்துங்கள். auto-fit இப்போது பயன்படுத்த வேண்டாம்; இந்தப் பயிற்சி வெளிப்படையான breakpoint பற்றியது.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சரிபாருங்கள்

Flexbox-க்குப் பதிலாக எப்போது Grid-ஐப் பயன்படுத்த வேண்டும்?

Layout rows மற்றும் columns இரண்டிலும் align ஆக வேண்டியிருக்கும்போது; உதாரணமாக gallery அல்லது page skeleton. Items ஒரே axis-ல் மட்டும் flow ஆக வேண்டுமானால் Flexbox எளிமையானது.

வெறும் 1fr-க்குப் பதிலாக ஏன் minmax(0, 1fr) எழுத வேண்டும்?

சாதாரண 1fr track-க்கு அதன் content அடிப்படையில் automatic minimum இருக்கும். நீளமான, உடையாத word column-ஐ screen-ஐ விட அகலமாக்கலாம். minmax(0, 1fr) அந்த minimum-ஐ பூஜ்ஜியமாக அமைப்பதால் track சுருங்க முடியும்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • Grid இரு பரிமாணம். Container-ல் columns மற்றும் rows வரையறுக்கவும்.
  • fr free space-ஐ பங்கிடுகிறது. பாதுகாப்பான flexible tracks-க்கு minmax(0, 1fr) உடன் இணைக்கவும்.
  • Named areas layout-ஐ படிக்க எளிதாக்குகின்றன. ஒவ்வொரு item-ஐயும் மீண்டும் எழுதுவதற்குப் பதிலாக breakpoint-ல் map-ஐ மாற்றவும்.
