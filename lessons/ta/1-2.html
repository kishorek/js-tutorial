Links, images, and lists

ஒரு page எங்காவது point பண்ண முடிஞ்சா அது website ஆகும். Pages-ஐ connect பண்ணவும், யாரையும் exclude பண்ணாம images காட்டவும், அர்த்தமுள்ள lists-ஐ structure பண்ணவும் கத்துக்கோங்க.

Links connect pages

Anchor element text-ஐயோ image-ஐயோ link ஆக்கும். href attribute link எங்கே போகணும் என்பதை சொல்லும்.

  • Relative link: about-me.html same folder-ல இருக்கிற file-ஐ target பண்ணும்.
  • Parent folder: ../index.html ஒரு folder மேலே போகும்.
  • Absolute link: https:// உட்பட முழு URL.
  • Page anchor: #recipe id="recipe" இருக்கிற element-க்கு jump பண்ணும்.

விளக்கமான link text use பண்ணுங்கள். “Read the recipe” useful. “Click here” reader-க்கு எதுவும் சொல்லாது—குறிப்பா screen reader-ல links list-ஐ scan பண்ணுறவங்களுக்கு.

External links

target="_blank" மூலம் link புது tab-ல open ஆனா, rel="noopener"-ஐ add பண்ணுங்கள். புது tab உங்கள் page-ஐ access பண்ணாம இது protect பண்ணும்.

Images need alternative text

Image element ஒரு void element. அதுக்கு closing tag இல்லை. src attribute file-ஐ point பண்ணும்; alt image என்ன சொல்லுது என்பதை describe பண்ணும்.

  • Image information சொல்லுதுனா, அந்த information-ஐ describe பண்ணுங்கள்.
  • Image வெறும் decoration-னா, screen readers skip பண்ண alt="" use பண்ணுங்கள்.
  • “image of” அல்லது “picture of” என்று start பண்ணாதீங்க; screen readers ஏற்கனவே அதை announce பண்ணும்.
  • முடிஞ்சா width-உம் height-உம் set பண்ணுங்கள். அவை space-ஐ reserve பண்ணி, image load ஆகும்போது layout shift-ஐ குறைக்கும்.
Common mistake

alt attribute இல்லாததும் காலியா இருப்பதும் ஒன்று இல்லை. Value இல்லைனா browser guess பண்ணும்; alt="" image எந்த information-உம் add பண்ணல என்று assistive technology-க்கு நேரடியா சொல்லும்.

Lists organize information

Order முக்கியமில்லைனா <ul>, order முக்கியம்னா <ol> use பண்ணுங்கள். ஒவ்வொரு item-உம் <li>-க்கு உள்ளே போகணும்.

Lists-ஐ உள்ளே nest பண்ணலாம். Nested list-ஐ அது சேர்ந்த <li>-க்கு உள்ளே வையுங்கள், items-க்கு நடுவில இல்லை.

Check yourself

Why is alt="image of pasta" a weak description?

இந்த element ஒரு image என்று screen readers ஏற்கனவே announce பண்ணும். Description format-ஐ repeat பண்ணாம content-ஐ சொல்லணும். “Lemon pasta in a white bowl” தான் useful.

What is the difference between about.html and https://example.com/about.html?

முதல் ஒன்று current page-ல இருந்து resolve ஆகிற relative path. இரண்டாவது protocol-உம் domain-உம் இருக்கிற absolute URL.

Key things to remember

  • Links anchors. href destination-ஐ decide பண்ணும்; text அதை describe பண்ணணும்.
  • Images-க்கு alt text தேவை. Information-ஐ describe பண்ணுங்கள்; decoration-க்கு alt="" use பண்ணுங்கள்.
  • Lists meaning-ஐ தாங்கும். Groups-க்கு unordered, sequence-க்கு ordered.
