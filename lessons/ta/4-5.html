Objects group related values

Object named properties-ஐ store பண்ணும். தெரிந்த name-க்கு dot notation use பண்ணுங்க, name ஒரு variable-ல store ஆகியிருந்தா bracket notation use பண்ணுங்க. Objects-ஓட arrays-ல ஒவ்வொரு item-ம் ஒரு record-ஐ describe பண்ணும்.

  • find முதல் match-ஐ, இல்லனா undefined-ஐ return பண்ணும்.
  • filter ஒவ்வொரு match-ஐயும் உள்ள புது array-ஐ return பண்ணும்.
  • map ஒவ்வொரு item-க்கும் ஒரு transformed value return பண்ணும்.
  • reduce list-ஐ ஒரே value-ஆ combine பண்ணும்.

Check yourself

Why keep calculate separate from the button handler?

அவற்றைப் பிரிப்பதால் arithmetic-ஐ நேரடியா test பண்ணலாம், reuse பண்ணலாம், logic-ஐ மீண்டும் எழுதாம interface-ஐ change பண்ணலாம். Handler input-ஐ மட்டும் collect பண்ணி output-ஐ காட்டும்.

Why does dividing by zero show Error instead of Infinity?

calculate function zero divisor-ஐ check பண்ணி ஒரு message return பண்ணும். இல்லனா JavaScript Infinity-ஐ produce பண்ணும்; அது கணிதப்படி valid, ஆனா calculator-க்கு useful இல்ல.
