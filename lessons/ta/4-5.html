தொகுதி 04 · JavaScript அடிப்படைகள்

திட்டம்: arrays, objects மற்றும் calculator

இந்தத் தொகுதி முழுவதையும் பயன்படுத்துங்கள். Objects கொண்டு தரவை வடிவமைத்து, array methods கொண்டு பட்டியல்களைத் தேடி, பிறகு அதன் logic buttons-லிருந்து தனியாக இருக்கும் ஒரு வேலை செய்யும் calculator-ஐ உருவாக்குங்கள்.

பாடம் 4.5 · திட்டம்2–3 மணி நேரம்தொகுதியின் மைல்கல்

வழங்க வேண்டியவை

  • நான்கு கணக்குகளுக்கான calculate(a, b, op) function.
  • Display, எண் button-கள், operators, clear மற்றும் equals.
  • பூஜ்ஜியத்தால் வகுத்தால் Error காட்டும் கையாளுதல்.

இறுதிச் சோதனை

  • பக்கம் இல்லாமலும் logic வேலை செய்கிறது.
  • ஒவ்வொரு button-ம் display-ஐச் சரியாக மாற்றுகிறது.
  • Clear முழுக் கணக்கையும் மீட்டமைக்கிறது.
  • Inline event handlers இல்லை.

Objects தொடர்புடைய மதிப்புகளைத் தொகுக்கின்றன

Object பெயரிடப்பட்ட properties-ஐச் சேமிக்கிறது. தெரிந்த பெயருக்கு dot notation-ஐயும், பெயர் ஒரு மாறியில் சேமிக்கப்பட்டிருந்தால் bracket notation-ஐயும் பயன்படுத்துங்கள். Objects கொண்ட arrays-ல் ஒவ்வொரு item-ம் ஒரு record-ஐ விவரிக்கும்.

  • find முதல் பொருத்தத்தை அல்லது undefined-ஐத் திருப்பித் தரும்.
  • filter ஒவ்வொரு பொருத்தத்தையும் உள்ள புதிய array-ஐத் திருப்பித் தரும்.
  • map ஒவ்வொரு item-க்கும் ஒரு மாற்றப்பட்ட மதிப்பைத் திருப்பித் தரும்.
  • reduce பட்டியலை ஒரே மதிப்பாக இணைக்கிறது.

Calculator-ஐ உருவாக்குங்கள்

எடிட்டரில் உள்ள shell-லிருந்து தொடங்குங்கள். கணக்கீட்டை ஒரு function-க்குள் வைத்திருங்கள்; buttons எண்களைச் சேகரித்து அதை call செய்யட்டும். Display output-ஐக் காட்டுகிறது; logic தனியாகச் சோதிக்கக்கூடியதாக இருக்க வேண்டும்.

இது DOM-ஐ முன்னோட்டமாகக் காட்டுகிறது

விடையில் document.querySelector மற்றும் addEventListener பயன்படுத்தப்படுகின்றன. அவற்றை இப்போதே முழுமையாகக் கற்றுக்கொள்ள வேண்டியதில்லை. தொகுதி 5 elements-ஐத் தேர்ந்தெடுப்பது, events-ஐ இணைப்பது, பக்கத்தைச் சரியாக update செய்வது ஆகியவற்றை விளக்குகிறது.

திட்டப் பணித்தளம் · 2–3 மணி நேரம்

உங்கள் calculator

calculator.html
நேரடி முன்னோட்டம்

முன்னோட்டம் ஏற்றப்பட்டது. Calculator-ஐ உருவாக்கி, பிறகு இயக்கு என்பதை அழுத்துங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு குறிப்பு விடை திறக்கும்.

மீள்பார்வைச் சரிபார்ப்புப் பட்டியல்

  • calculate(7, 8, "+") 15-ஐத் திருப்பித் தரும்; calculate(9, 3, "*") 27-ஐத் திருப்பித் தரும்.
  • 5 / 0 Infinity-ஐ அல்ல, Error-ஐக் காட்டும்.
  • 0.5 தட்டச்சு செய்வது வேலை செய்கிறது; ஒரு எண்ணில் ஒரே ஒரு decimal point மட்டும் இருக்கும்.
  • C display-ஐ, சேமிக்கப்பட்ட எண்ணை, operator-ஐ மீட்டமைக்கிறது.
  • 7 + 8 + 2 போன்ற தொடர் கணக்குகள் 17 தரும்.
  • ஒவ்வொரு button-ம் addEventListener பயன்படுத்துகிறது; onclick attributes இல்லை.
  • முழு வரிசைக்குப் பிறகு console-ல் errors எதுவும் தெரியாது.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

calculate-ஐ button handler-லிருந்து தனியாக வைப்பது ஏன்?

அவற்றைப் பிரிப்பதால் கணக்கீட்டை நேரடியாகச் சோதிக்கலாம், மீண்டும் பயன்படுத்தலாம், logic-ஐ மீண்டும் எழுதாமல் interface-ஐ மாற்றலாம். Handler input-ஐ மட்டும் சேகரித்து output-ஐக் காட்டுகிறது.

பூஜ்ஜியத்தால் வகுத்தால் Infinity-க்குப் பதிலாக Error ஏன் காட்டுகிறது?

calculate function பூஜ்ஜிய வகுப்பியைச் சரிபார்த்து ஒரு செய்தியைத் திருப்பித் தருகிறது. இல்லாவிட்டால் JavaScript Infinity-ஐ உருவாக்கும்; அது கணிதப்படி சரியானதே, ஆனால் calculator-க்குப் பயன்படாது.

தொகுதி 4 வினாடி வினா

01 எந்த keyword ஒரு மாறிக்கு மீண்டும் மதிப்பு வைப்பதைத் தடுக்கிறது?

02 === எதை ஒப்பிடுகிறது?

03 எந்த method ஒவ்வொரு array item-ஐயும் புதிய array ஆக மாற்றுகிறது?

04 return statement இல்லாத function என்ன திருப்பித் தருகிறது?

05 calculate log செய்வதற்குப் பதிலாக ஒரு மதிப்பை ஏன் return செய்ய வேண்டும்?

தொகுதி 4 நிறைவு

  • தரவுக்கு வடிவம் உண்டு. Objects தொடர்புடைய மதிப்புகளுக்குப் பெயரிடுகின்றன; arrays அவற்றை வரிசையாக வைத்திருக்கின்றன.
  • சிறிய functions இணைந்து வேலை செய்கின்றன. Pure calculate மற்றும் event wiring ஒரு பெரிய script-ஐவிடப் பிழைத்திருத்த எளிது.
  • நீங்கள் ஒரு interactive கருவியை உருவாக்கியுள்ளீர்கள். எண்கள் உள்ளே செல்கின்றன, logic இயங்குகிறது, display update ஆகிறது. தொகுதி 5 DOM layer-ஐ விரிவாக விளக்குகிறது.
