The brief

Accessibility and behavior

  • ஒவ்வொரு input-க்கும் label இருக்கணும்; icon மட்டும் இருக்கும் ஒவ்வொரு button-க்கும் accessible name இருக்கணும்.
  • Form-ஐ submit பண்ணக்கூடாத buttons-ல type="button" use பண்ணுங்கள்.
  • Focus visible-ஆ வையுங்கள்; item add பண்ணினப்புறம் focus-ஐ input-க்கு திருப்புங்கள்.
  • மீதி count-ஐ aria-live="polite" மூலமா announce பண்ணுங்கள்.
  • User text-ஐ innerHTML மூலமா எப்பவுமே insert பண்ணாதீங்க; textContent மூலம் set பண்ணுங்கள்.
  • Keyboard மட்டும் use பண்ணி test பண்ணுங்கள்: add, toggle, delete, filter, reset.

Common questions

Should the to-do list save after refresh?

இப்போதைக்கு இல்ல. Persistence Module 6-ல localStorage-ஓட வரும். இப்போ state-ஐ memory-ல வச்சு, starter array sample data-ஐ கொடுக்கட்டும்.

Why use a template string for the list markup?

Template-ல trusted structure-ம் numeric ids-ம் மட்டும் தான் இருக்கு. Visitor-ஓட text இன்னும் தனியா textContent மூலம் தான் insert ஆகுது; அதனால அது markup ஆக முடியாது.
