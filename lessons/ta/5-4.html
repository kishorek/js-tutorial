தொகுதி 05 · DOM & நிகழ்வுகள்

திட்டப்பணி: to-do பட்டியல் + வினாடி வினா app

தொகுதி மைல்கல்லை உருவாக்குங்கள்: ஒவ்வொரு control-um state-ஐ மாற்றி, திரை அதைப் பின்தொடரும் ஒரு app. to-do பட்டியலுடன் தொடங்கி, சிறிய வினாடி வினாவுக்கு அதே state-and-render முறையை மீண்டும் பயன்படுத்துங்கள்.

பாடம் 5.4 · திட்டப்பணி 2–3 மணி நேரம் தொகுதி மைல்கல்

வழங்க வேண்டியவை

  • சேர்க்க, toggle, நீக்க மற்றும் filter செய்யும் வசதிகொண்ட to-do பட்டியல்.
  • questions array, score மற்றும் reset கொண்ட வினாடி வினா.
  • Keyboard-ல் அணுகக்கூடிய controls மற்றும் காலி நிலை.

வெளியேறும் சரிபார்ப்பு

  • முதலில் state மாறும்; render அதைப் பின்தொடரும்.
  • பயனர் உரை ஒருபோதும் HTML string-ல் செல்லாது.
  • ஒவ்வொரு control-க்கும் அணுகக்கூடிய பெயர் இருக்கும்.

திட்ட விவரம்

இரண்டு app-களும் பாடம் 5.3-இல் உள்ள அதே loop-ஐப் பயன்படுத்துகின்றன: data-ஐ மாற்றுங்கள், render-ஐ அழையுங்கள், DOM அதைப் பின்தொடரட்டும். முதலில் to-do பட்டியலை உருவாக்குங்கள். வினாடி வினா, வேறு வடிவ state-உடன் அதே முறையை மீண்டும் செய்யும் இரண்டாவது பக்கம்.

அம்சம்தேவை
சேர்த்தல்உரையை trim செய்யுங்கள், காலி value-ஐப் புறக்கணியுங்கள், input-ஐக் காலி செய்யுங்கள், focus-ஐ அங்கேயே வையுங்கள்.
Toggleஒரு item-ஐ முடிந்ததாகக் குறியிட்டு, மீதமுள்ள எண்ணிக்கையைப் புதுப்பியுங்கள்.
நீக்குதல்தேர்ந்தெடுத்த item-ஐ மட்டும் நீக்குங்கள்; array-இன் மீதமுள்ளவற்றை அப்படியே வையுங்கள்.
Filterஅனைத்து, active அல்லது done items-ஐக் காட்டுங்கள்; தெளிவான காலி செய்தியுடன்.
வினாடி வினாQuestions-ஐ array-ல் சேமித்து, score-ஐக் கண்காணித்து, இரண்டையும் reset செய்யுங்கள்.

to-do app-ஐ உருவாக்குங்கள்

Starter-ல் markup மற்றும் சிறிது CSS ஏற்கனவே உள்ளன. உங்கள் வேலை state, render function மற்றும் listeners. Toggle மற்றும் delete-க்கு ஒரே delegated click listener-ஐயும், சேர்ப்பதற்கு ஒரு submit listener-ஐயும் பயன்படுத்துங்கள்.

நேரடி முன்னோட்டம்

முன்னோட்டம் ஏற்றப்பட்டது. ஒவ்வொரு மாற்றத்திற்குப் பிறகும் இயக்கு என்பதை அழுத்துங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு குறிப்பு விடை திறக்கும்.

வினாடி வினா திரையைச் சேர்க்கவும்

இரண்டாவது பக்கத்தில் <div id="quiz"></div> பயன்படுத்துங்கள். Questions-ஐ array-ல் வைத்து, தற்போதைய index மற்றும் score-ஐக் கண்காணித்து, ஒரு நேரத்தில் ஒரு question-ஐ render செய்யுங்கள். Reset button இரண்டு எண்களையும் பூஜ்ஜியத்திற்கு மீட்டமைக்கும்.

Accessibility மற்றும் நடத்தை

  • ஒவ்வொரு input-க்கும் label உள்ளது; icon மட்டும் உள்ள ஒவ்வொரு button-க்கும் அணுகக்கூடிய பெயர் உள்ளது.
  • Form-ஐ submit செய்யக் கூடாத buttons-ல் type="button" பயன்படுத்துங்கள்.
  • Focus தெரியும்படி வைத்திருந்து, item சேர்த்த பிறகு அதை input-க்குத் திருப்புங்கள்.
  • மீதமுள்ள எண்ணிக்கையை aria-live="polite" மூலம் அறிவிக்கவும்.
  • பயனர் உரையை ஒருபோதும் innerHTML மூலம் செருகாதீர்கள்; textContent மூலம் அமையுங்கள்.
  • Keyboard மட்டுமே பயன்படுத்திச் சோதியுங்கள்: add, toggle, delete, filter மற்றும் reset.

பொதுவான கேள்விகள்

Refresh செய்த பிறகு to-do பட்டியல் சேமிக்கப்பட வேண்டுமா?

இப்போதைக்கு இல்லை. தொகுதி 6-ல் localStorage-உடன் persistence வரும். இப்போதைக்கு state-ஐ memory-ல் வைத்திருங்கள்; starter array மாதிரி data-ஐ வழங்கட்டும்.

List markup-க்கு ஏன் template string பயன்படுத்த வேண்டும்?

Template-ல் நம்பகமான structure மற்றும் எண்ணிக்கையான ids மட்டுமே இருக்கின்றன. பார்வையாளரின் உரை தனியாக textContent மூலமே செருகப்படுகிறது; அதனால் அது markup ஆக முடியாது.

தொகுதி 5 வினாடி வினா

01 முதல் பொருந்தும் element-ஐத் திருப்பித் தரும் method எது?

02 Text field-ல் ஒவ்வொரு திருத்தத்திலும் எந்த event இயங்கும்?

03 பார்வையாளர் உள்ளீட்டுக்கு textContent-ஐ ஏன் பயன்படுத்த வேண்டும்?

04 State மாறிய உடனே என்ன நடக்க வேண்டும்?

05 Form-ல் event.preventDefault() எதை நிறுத்துகிறது?

தொகுதி 5 முடிந்தது

  • பாதுகாப்பாகத் தேர்ந்தெடுத்து மாற்றுங்கள். DOM-ஐ query செய்து, உரையை உரையாகவே வைத்து, புதிய nodes-ஐ வேண்டுமென்றே உருவாக்குங்கள்.
  • Events தான் app-ஐ இயக்குகின்றன. Input-ஐப் படித்து, தேவையற்ற defaults-ஐத் தடுத்து, திரும்பத் திரும்ப வரும் controls-ஐ delegate செய்யுங்கள்.
  • State, பிறகு render. ஒரு array, ஒரு render function, ஒவ்வொரு செயலுக்கும் ஒரே முன்னறிவிக்கக்கூடிய வழி.
