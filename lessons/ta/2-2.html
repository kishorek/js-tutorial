Box model மற்றும் spacing

பக்கத்தில் உள்ள ஒவ்வொரு element-ம் நான்கு அடுக்குகள் கொண்ட ஒரு செவ்வகப் பெட்டி. அந்த அடுக்குகளைப் பார்க்கத் தெரிந்தால், "இது ஏன் 20 pixel அதிக அகலமாக இருக்கிறது?" என்பது யூகம் அல்ல, ஒரு கணக்கீடாக மாறும்.

பாடம் 2.2 60–75 நிமிடம் தொடக்கநிலை

இதன் முடிவில், நீங்கள்

  • Box model-இன் நான்கு அடுக்குகளுக்குப் பெயர் சொல்ல முடியும்.
  • ஆச்சரியங்கள் இல்லாமல் box-sizing: border-box-ஐப் பயன்படுத்த முடியும்.
  • Shorthand-கள் மற்றும் ஒரே மாதிரியான scale கொண்டு spacing-ஐச் சரிசெய்ய முடியும்.

உங்களுக்குத் தேவை

  • பாடம் 2.1 முடிக்கப்பட்டிருக்க வேண்டும்.
  • இணைக்கப்பட்ட stylesheet கொண்டு style செய்யக்கூடிய ஒரு பக்கம்.
  • அந்தப் பக்கத்தில் DevTools திறந்திருக்க வேண்டும்.

ஒவ்வொரு element-ம் ஒரு பெட்டி

உள்ளிருந்து வெளியே: content என்பது text அல்லது image, padding என்பது border-க்கு உள்ளே உள்ள இடம், border என்பது தெரியும் விளிம்பு, margin என்பது border-க்கு வெளியே உள்ள இடம். Padding-ம் border-ம் element-க்குச் சொந்தம்; margin அதை அண்டை element-களிலிருந்து பிரிக்கிறது.

அடுக்குஎன்ன செய்கிறதுகிளிக் செய்யலாமா?
ContentText, image அல்லது உள்ளே உள்ள பெட்டிகளை வைத்திருக்கும்.ஆம்
PaddingContent-ஐ border-இலிருந்து தள்ளி வைக்கும்; background நிறத்தைப் பயன்படுத்தும்.ஆம்
BorderPadding-ஐயும் content-ஐயும் சுற்றி ஒரு விளிம்பு வரையும்.ஆம்
Marginஇந்தப் பெட்டிக்கும் மற்றவற்றுக்கும் இடையே காலி இடம்; எப்போதும் transparent.இல்லை

box-sizing கணக்கை மாற்றுகிறது

Default-ஆக CSS content-box-ஐப் பயன்படுத்தும். width: 300px உள்ள element-க்கு 20px padding-ம் 2px border-ம் இருந்தால், உண்மையில் 300 + 40 + 4 = 344px இடத்தை எடுக்கும். நீங்கள் நினைப்பது அரிதாகவே இதுவாக இருக்கும், குறிப்பாகக் குறுகிய layout-க்குள்.

border-box உடன், நீங்கள் சொல்லும் width-ே இறுதி வெளி அகலம். Content பகுதி பொருந்தும்படி சுருங்கும்: 300 - 40 - 4 = 256px. இந்த reset-ஐ ஒவ்வொரு project-இன் மேலேயும் வையுங்கள்; மனக்கணக்கு செய்வதை நிறுத்துங்கள்.

பெட்டியை ஆராயுங்கள்

DevTools-இல் ஒரு element-ஐத் தேர்ந்தெடுத்து Layout அல்லது Computed panel-ஐத் திறங்கள். Box diagram content, padding, border, margin-ஐ நேரடி எண்களுடன் காட்டும். ஒரு அடுக்கின் மேல் hover செய்தால் பக்கத்தில் அது highlight ஆகும். ஒரு declaration-இன் checkbox-ஐ toggle செய்தால் விளைவை உடனே பார்ப்பீர்கள்.

Shorthand மற்றும் longhand

Shorthand-கள் பல பக்கங்களை ஒரே நேரத்தில் அமைக்கும். Value-கள் மேலிருந்து கடிகார திசையில்: top, right, bottom, left. இரண்டு value-கள் என்றால் முதலில் vertical, பிறகு horizontal; ஒரு value நான்கு பக்கங்களுக்கும் பொருந்தும். ஒரு பக்கம் மட்டும் மாறினால் longhand பயன்படுத்துங்கள்.

Margin-கள் collapse ஆகும்

அண்டை element-களுக்கு இடையேயான vertical margin-கள் கூட்டப்படுவதில்லை. ஒரு paragraph-க்கு margin-bottom: 24px என்றும் அடுத்ததற்கு margin-top: 16px என்றும் இருந்தால், இடைவெளி இரண்டில் பெரியதான 24px. ஒரு child-இன் top margin அதன் parent வழியாகவும் collapse ஆகலாம்; உள்ளே இடம் உருவாக்குவதற்குப் பதிலாக முழு parent-ஐயும் கீழே தள்ளும்.

வழக்கமான தீர்வு

Parent-க்கு padding அல்லது border சேர்க்கவும், அல்லது parent-ஐ flex container ஆக்கவும். Flex, grid layout-களில் margin collapse ஆகாது; spacing-க்கு gap பயன்படுத்துகின்றன. Margin மறைந்தது போலத் தோன்றினால், தற்செயலான எண்களைச் சேர்ப்பதற்கு முன் parent-ஐ ஆராயுங்கள்.

Spacing scale பயன்படுத்துங்கள்

சிறிய அளவிலான value-களைத் தேர்ந்தெடுத்து மீண்டும் பயன்படுத்துங்கள். நான்கு pixel அடிப்படை பொதுவானது: 4, 8, 12, 16, 24, 32, 48, 64. ஒரே மாதிரியான படிகள் பக்கம் ஒன்று சேர்க்கப்பட்டதாக அல்ல, வடிவமைக்கப்பட்டதாகத் தோன்றச் செய்யும். அடுத்த பாடத்தில் இவற்றை custom property-களாகச் சேமிப்போம்.

Card-க்கு மூச்சுவிட இடம் கொடுங்கள்

இந்த card மிக நெருக்கமாக உள்ளது: text விளிம்பைத் தொடுகிறது, button மிகச் சிறிய target. Card-இன் 24px padding உட்பட அகலம் 320px ஆகவும், heading-க்குக் கீழே 8px ஆகவும், paragraph-க்குக் கீழே 16px-ம் 1.6 line-height-ம் ஆகவும், button-க்கு 12px 18px padding-ம் 44px குறைந்தபட்ச உயரமும் இருக்கும்படி CSS-ஐ மீண்டும் எழுதுங்கள். Global border-box reset-ஐச் சேர்க்கவும்.

முதலில் முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

width: 300px உடன் padding: 20px சேர்ந்தால் ஏன் 300px-ஐ விட அகலமாகத் தெரிகிறது?

Default content-box sizing, சொல்லப்பட்ட width-க்கு வெளியே padding-ஐயும் border-ஐயும் சேர்க்கிறது. box-sizing: border-box-ஐ global-ஆக அமைத்தால், சொல்லும் width இரண்டையும் உள்ளடக்கும்; content பகுதி பொருந்தும்படி சுருங்கும்.

இரண்டு paragraph-களுக்கும் margin: 16px உள்ளது, ஆனால் இடைவெளி 32px அல்ல, 16px. ஏன்?

அண்டை vertical margin-கள் collapse ஆகின்றன: browser அவற்றைக் கூட்டாமல் பெரிய margin-ஐப் பயன்படுத்துகிறது. இது சாதாரணம். சரியான, collapse ஆகாத spacing தேவைப்பட்டால் gap உள்ள flex container பயன்படுத்துங்கள்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • நான்கு அடுக்குகள்: content, padding, border, margin. எவை கிளிக் செய்யக்கூடியவை, எவை transparent என்பதைத் தெரிந்துகொள்ளுங்கள்.
  • எல்லா இடத்திலும் border-box பயன்படுத்துங்கள். அப்போது சொல்லும் width, பக்கத்தில் நீங்கள் பார்ப்பதற்குப் பொருந்தும்.
  • Spacing ஒரு முறை. ஒரே மாதிரியான சிறிய scale, தனித்தனி pixel value-களின் குவியலை விட மேல்.
