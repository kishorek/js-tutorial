The box model and spacing

Every element is a box

உள்ளே இருந்து வெளியே: content என்பது text அல்லது image, padding என்பது border-க்கு உள்ளே இருக்குற space, border என்பது தெரியுற edge, margin என்பது border-க்கு வெளியே இருக்குற space. Padding-ம் border-ம் element-க்கு சொந்தம்; margin அதை அண்டை elements-ல இருந்து separate பண்ணும்.

box-sizing changes the math

Default-ஆ CSS content-box-ஐ use பண்ணும். width: 300px உள்ள element-க்கு 20px padding-ம் 2px border-ம் இருந்தா, உண்மையில 300 + 40 + 4 = 344px எடுக்கும். நீங்கள் நினைக்குறது அரிதாகவே இதுவா இருக்கும், குறிப்பா narrow layout-க்குள்ள.

border-box-ஓட, நீங்கள் சொல்லுற width-தான் final outer width. Content area பொருந்துற அளவுக்கு shrink ஆகும்: 300 - 40 - 4 = 256px. இந்த reset-ஐ ஒவ்வொரு project-ஓட top-லயும் வையுங்கள்; மனக்கணக்கு செய்யுறதை நிறுத்துங்கள்.

Inspect the box

DevTools-ல ஒரு element-ஐ select பண்ணி Layout அல்லது Computed panel-ஐ open பண்ணுங்கள். Box diagram content, padding, border, margin-ஐ live numbers-உடன் காட்டும். ஒரு layer-மேல hover பண்ணினா page-ல அது highlight ஆகும். ஒரு declaration-ஓட checkbox-ஐ toggle பண்ணினா effect-ஐ உடனே பாக்கலாம்.

Shorthand and longhand

Shorthands ஒரே நேரத்துல பல sides-ஐ set பண்ணும். Values top-ல இருந்து clockwise-ஆ: top, right, bottom, left. இரண்டு values என்றா முதல்ல vertical, அப்புறம் horizontal; ஒரு value நாலு sides-க்கும் apply ஆகும். ஒரு side மட்டும் மாறினா longhand use பண்ணுங்கள்.

Margins collapse

Siblings-க்கு நடுவில vertical margins add ஆகாது. ஒரு paragraph-க்கு margin-bottom: 24px, அடுத்ததுக்கு margin-top: 16px இருந்தா gap 24px, அதாவது இரண்டுல பெரியது. ஒரு child-ஓட top margin parent வழியா collapse ஆகலாம்; உள்ளே space create பண்ணுறதுக்கு பதிலா parent முழுவதையும் கீழ தள்ளும்.

The usual fix

Parent-க்கு padding அல்லது border add பண்ணுங்கள், இல்லைனா parent-ஐ flex container ஆக்குங்கள். Flex, grid layouts-ல margins collapse ஆகாது; spacing-க்கு gap use பண்ணும். Margin மறைஞ்ச மாதிரி தோணினா, random numbers add பண்ணுறதுக்கு முன்னாடி parent-ஐ inspect பண்ணுங்கள்.

Use a spacing scale

சிறிய set of values-ஐ pick பண்ணி மீண்டும் use பண்ணுங்கள். Four-pixel base பொதுவா use ஆகும்: 4, 8, 12, 16, 24, 32, 48, 64. Consistent steps page-ஐ assembled-ஆ இல்லாம designed-ஆ feel பண்ண வைக்கும். அடுத்த lesson-ல இவற்றை custom properties-ஆ store பண்ணுவோம்.

Check yourself

Why does width: 300px plus padding: 20px render wider than 300px?

Default content-box sizing declared width-க்கு வெளியே padding-ஐயும் border-ஐயும் add பண்ணும். box-sizing: border-box-ஐ global-ஆ set பண்ணுங்கள்; அப்போ declared width இரண்டையும் include பண்ணும், content area பொருந்துற அளவுக்கு shrink ஆகும்.

Both paragraphs have margin: 16px, yet the gap is 16px, not 32px. Why?

அண்டை vertical margins collapse ஆகும்: browser அவற்றை add பண்ணாம பெரிய margin-ஐ use பண்ணும். இது normal. Exact-ஆ, collapse ஆகாத spacing வேண்டும்னா gap உள்ள flex container use பண்ணுங்கள்.

Key things to remember

  • நாலு layers: content, padding, border, margin. எவை clickable, எவை transparent என்று தெரிஞ்சுக்கோங்க.
  • எல்லா இடத்திலும் border-box use பண்ணுங்கள். அப்போ declared widths page-ல நீங்கள் பாக்குறதுக்கு match ஆகும்.
  • Spacing ஒரு system. சின்ன scale, ஒவ்வொண்ணா pixel values குவியலை விட better.
