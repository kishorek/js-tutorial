Type starts with a system

Font stack என்பது உங்களுக்கு வேண்டிய fonts-ஐ best-ல இருந்து list பண்ணி, கடைசில ஒரு generic family-ஓட முடிக்கும். Fast-ஆ, native-ஆ தெரியுற text-க்கு system stack use பண்ணுங்கள். Body size-ஐ rem-ல set பண்ணுங்கள், line-height-ஐ unitless-ஆ வையுங்கள், புது size-க்கு போகுறதுக்கு முன்னாடி hierarchy create பண்ண weight-ஐ use பண்ணுங்கள்.

  • rem root font size-ஐ relative. User-ஓட browser preference respect ஆகுறதுக்கு page-level sizes-க்கு இதை use பண்ணுங்கள்.
  • em current element-ஓட font size-ஐ relative. ஒரு component முழுவதும் scale ஆகணும்னா இதை use பண்ணுங்கள்.
  • Unitless line-height (1.6 போல) pixels-ல lock ஆகாம font-உடன் scale ஆகும். Body text பொதுவா 1.4-க்கும் 1.7-க்கும் நடுவுல; headings 1.05-க்கும் 1.3-க்கும் நடுவுல.
  • Weight quick hierarchy tool: body-க்கு 400, headings-க்கு 600 அல்லது 700. சின்ன text-க்கு light weight use பண்ணாதீங்க.

Type scale என்பது consistent ratio-ல உள்ள சின்ன sizes list. நாலு அல்லது அஞ்சு steps pick பண்ணி நிறுத்துங்கள். Sizes குறைவா இருந்தா page calm-ஆ, code change பண்ண easy-ஆ இருக்கும்.

Color needs contrast, not just taste

Low vision உள்ளவங்க, பகல்ல phone-ல பாக்குறவங்க, cheap monitor-ல பாக்குறவங்க — எல்லாருக்கும் text readable-ஆ இருக்கணும். Normal text-க்கு குறைந்தது 4.5:1, large text-க்கு (சுமார் 24px, அல்லது bold 18.66px) 3:1 contrast ratio என்று WCAG சொல்லுது. Muted text-ம் pass ஆகணும்; "soft gray" ஒரு excuse இல்ல.

Do not rely on color alone

Error red-ஆ இருந்தா, ஒரு message அல்லது icon-ஐயும் add பண்ணுங்கள். Link green-ஆ இருந்தா, hover-லயும் focus-லயும் அதுக்கு underline கொடுங்கள். Color ஒரு reinforcement, ஒரே signal இல்ல. Ship பண்ணுறதுக்கு முன்னாடி ஒவ்வொரு pair-ஐயும் contrast tool கொண்டு check பண்ணுங்கள்.

Palette-ஐ சின்னதா வையுங்கள்: text-க்கு ஒரு ink, secondary text-க்கு muted ink, ஒரு page background, ஒரு card background, ஒரு accent, ஒரு rule color. Restrained palette ஒரே accent-ஐ வேண்டும்னே choose பண்ணது போல feel வைக்கும்.

Tokens create visual rhythm

CSS custom properties (variables) ஒரு decision-ஐ ஒருமுறை store பண்ணி மீண்டும் use பண்ணும். முழு page-ம் inherit ஆகுறதுக்கு அவற்றை :root-ல define பண்ணி, var() கொண்டு reference பண்ணுங்கள். Token-ஐ மாத்துங்கள், ஒவ்வொரு component-ம் follow ஆகும்.

Custom property names case-sensitive; மற்ற properties போலவே inherit ஆகும். Token missing-ஆ இருந்தாலும் component use ஆகுறதுக்கு var(--accent, #14532d) போன்ற fallback உதவும். Depth-க்கு ஒரு thin border-ம் ஒரு soft shadow-ம் போதும்; பெரிய shadows-ஐ overlays-க்கு வைச்சுக்கோங்கள். எப்போதும் தெரியுற :focus-visible outline-ஐ வையுங்கள்.

Check yourself

When should I use rem instead of em?

Page-ஓட type scale-க்கும் global spacing-க்கும் rem use பண்ணுங்கள்; அப்போ அது root size-ஐயும் user preferences-ஐயும் follow பண்ணும். ஒரு component-க்கு உள்ளே padding அல்லது nested size அந்த component-ஓட font size-உடன் scale ஆகணும்னா em use பண்ணுங்கள்.

Is gray text on a white background always a contrast problem?

எப்போதும் இல்ல, ஆனா பல நேரம் ஆம். Color name இல்ல, ratio-தான் important. Exact pair-ஐ check பண்ணுங்கள்: normal text-க்கு 4.5:1 தேவை. #f7f2e7-ல #5d574d போன்ற medium gray pass ஆகலாம்; pale gray fail ஆகும்.

Key things to remember

  • Type ஒரு scale. சில rem sizes-ம் unitless line-heights-ம் one-off values குவியலை விட better.
  • Contrast ஒரு requirement. Text pairs-ஐ check பண்ணுங்கள்; color-ஐ மட்டும் signal-ஆ use பண்ணாதீங்க.
  • Tokens rhythm-ஐ repeat பண்ண வைக்கும். Color, type, spacing decisions-ஐ :root-ல ஒருமுறை store பண்ணுங்கள்.
