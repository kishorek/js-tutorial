தொகுதி 02 · CSS: வெளித்தோற்றம்

Type, color, visual rhythm

நல்ல styling என்பது பெரும்பாலும் சில முடிவுகளைத் தொடர்ந்து ஒரே மாதிரியாகச் செய்வதுதான்: படிக்கக்கூடிய type scale, போதுமான contrast உள்ள சிறிய palette, ஒரே முறையிலிருந்து வரும் spacing. இந்தப் பாடம் அந்த முடிவுகளை மீண்டும் பயன்படுத்தக்கூடிய token-களாக மாற்றுகிறது.

பாடம் 2.3 60–75 நிமிடம் தொடக்கநிலை

இதன் முடிவில், நீங்கள்

  • rem-இல் font stack-ம் type scale-ம் உருவாக்க முடியும்.
  • Color contrast-ஐச் சரிபார்த்து, நிறம் மட்டுமே பொருள் தருவதைத் தவிர்க்க முடியும்.
  • Color, type, spacing-க்கு custom property-களை வரையறுக்க முடியும்.

உங்களுக்குத் தேவை

  • பாடங்கள் 2.1, 2.2 முடிக்கப்பட்டிருக்க வேண்டும்.
  • உண்மையான heading-களும் paragraph-களும் உள்ள ஒரு பக்கம்.
  • ஒரு browser-ம் contrast checker-ம்.

Type ஒரு முறையிலிருந்து தொடங்குகிறது

Font stack என்பது உங்களுக்கு வேண்டிய font-களைச் சிறந்ததிலிருந்து வரிசைப்படுத்தி, கடைசியில் ஒரு generic family-யுடன் முடிப்பது. வேகமான, native-ஆகத் தெரியும் text-க்கு system stack பயன்படுத்துங்கள். Body அளவை rem-இல் அமையுங்கள், line-height-ஐ unitless-ஆக வையுங்கள், புதிய size-க்குப் போவதற்கு முன் hierarchy உருவாக்க weight-ஐப் பயன்படுத்துங்கள்.

  • rem root font size-ஐச் சார்ந்தது. பயனரின் browser விருப்பம் மதிக்கப்படும்படி page-level அளவுகளுக்குப் பயன்படுத்துங்கள்.
  • em தற்போதைய element-இன் font size-ஐச் சார்ந்தது. ஒரு component முழுவதுமாக scale ஆக வேண்டியிருக்கும்போது பயன்படுத்துங்கள்.
  • Unitless line-height 1.6 போன்றது pixel-இல் பூட்டப்படாமல் font-உடன் scale ஆகும். Body text பொதுவாக 1.4-க்கும் 1.7-க்கும் இடையில்; heading-கள் 1.05-க்கும் 1.3-க்கும் இடையில்.
  • Weight விரைவான hierarchy கருவி: body-க்கு 400, heading-களுக்கு 600 அல்லது 700. சிறிய text-க்கு light weight பயன்படுத்த வேண்டாம்.

Type scale என்பது ஒரே விகிதத்தில் அமைந்த சிறிய அளவுப் பட்டியல். நான்கு அல்லது ஐந்து படிகளைத் தேர்ந்தெடுத்து நிறுத்துங்கள். குறைவான அளவுகள் பக்கத்தை அமைதியாகவும் code-ஐ மாற்ற எளிதாகவும் ஆக்கும்.

Color-க்கு contrast தேவை, ரசனை மட்டும் போதாது

பார்வைக் குறைபாடு உள்ளவர்களுக்கும், பகல் வெளிச்சத்தில் phone-இல் பார்ப்பவர்களுக்கும், மலிவான monitor-இல் பார்ப்பவர்களுக்கும் text படிக்கக்கூடியதாக இருக்க வேண்டும். சாதாரண text-க்குக் குறைந்தது 4.5:1, பெரிய text-க்கு (சுமார் 24px, அல்லது bold-ஆன 18.66px) 3:1 contrast ratio என்று WCAG கேட்கிறது. Muted text-ம் தேர்ச்சி பெற வேண்டும்; "soft gray" ஒரு சாக்கு அல்ல.

நிறத்தை மட்டும் நம்ப வேண்டாம்

Error சிவப்பு என்றால், ஒரு message அல்லது icon-ஐயும் சேர்க்கவும். Link பச்சை என்றால், hover-இலும் focus-இலும் அதற்கு underline கொடுங்கள். நிறம் ஒரு வலுப்படுத்தல், ஒரே signal அல்ல. வெளியிடுவதற்கு முன் ஒவ்வொரு இணையையும் contrast tool கொண்டு சரிபாருங்கள்.

Palette-ஐ சிறியதாக வையுங்கள்: text-க்கு ஒரு ink, இரண்டாம் நிலை text-க்கு muted ink, ஒரு page background, ஒரு card background, ஒரு accent, ஒரு rule color. அடக்கமான palette ஒரே accent-ஐ வேண்டுமென்று தேர்ந்தெடுத்தது போலத் தோன்றச் செய்யும்.

Token-கள் visual rhythm-ஐ உருவாக்குகின்றன

CSS custom property-கள் (variable-கள்) ஒரு முடிவை ஒருமுறை சேமித்து மீண்டும் பயன்படுத்துகின்றன. முழு பக்கமும் inherit ஆகும்படி அவற்றை :root-இல் வரையறுத்து, var() கொண்டு பயன்படுத்துங்கள். Token-ஐ மாற்றினால் ஒவ்வொரு component-ம் பின்பற்றும்.

Custom property பெயர்கள் case-sensitive; மற்ற property-களைப் போலவே inherit ஆகும். Token இல்லாதபோதும் component வேலை செய்ய var(--accent, #14532d) போன்ற fallback உதவும். ஆழத்திற்கு ஒரு மெல்லிய border-ம் ஒரு soft shadow-ம் போதும்; பெரிய shadow-ஐ overlay-களுக்கு வைத்திருங்கள். எப்போதும் தெரியும் :focus-visible outline-ஐ வையுங்கள்.

பயிற்சி · 25 நிமிடம்

Token-களைக் கொண்டு article-ஐ style செய்யுங்கள்

கீழே உள்ள token block-ஐயும் இந்த HTML-ஐயும் பயன்படுத்துங்கள். Color, spacing-க்கு மட்டும் token-களைப் பயன்படுத்தி article-ஐ style செய்யுங்கள்: --paper-இல் --ink body text, --card-இல் --rule border-ம் --radius-ம் கொண்ட 60ch card, 0.875rem uppercase-இல் --muted meta text, 2rem-இல் line-height 1.1 உடன் --accent title, 1.125rem-இல் lede. படிக்கக்கூடிய system font stack-ஐயும் 1.6 body line-height-ஐயும் சேர்க்கவும்.

முதலில் முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

em-க்குப் பதிலாக rem-ஐ எப்போது பயன்படுத்த வேண்டும்?

பக்கத்தின் type scale-க்கும் global spacing-க்கும் rem பயன்படுத்துங்கள்; அப்போது அது root size-ஐயும் பயனர் விருப்பங்களையும் பின்பற்றும். ஒரு component-க்குள் padding அல்லது nested size அந்த component-இன் சொந்த font size-உடன் scale ஆக வேண்டியிருக்கும்போது em பயன்படுத்துங்கள்.

வெள்ளை background-இல் சாம்பல் text எப்போதும் contrast பிரச்சினையா?

எப்போதும் இல்லை, ஆனால் பல நேரங்களில் ஆம். நிறத்தின் பெயர் அல்ல, ratio முக்கியம். சரியான இணையைச் சரிபாருங்கள்: சாதாரண text-க்கு 4.5:1 தேவை. #f7f2e7-இல் #5d574d போன்ற நடுத்தர சாம்பல் தேர்ச்சி பெறலாம்; வெளிர் சாம்பல் தோல்வியடையும்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • Type ஒரு scale. சில rem அளவுகளும் unitless line-height-களும் தனித்தனி value-களின் குவியலை விட மேல்.
  • Contrast ஒரு தேவை. Text இணைகளைச் சரிபாருங்கள்; நிறத்தை மட்டும் signal ஆகப் பயன்படுத்த வேண்டாம்.
  • Token-கள் rhythm-ஐ மீண்டும் மீண்டும் பயன்படுத்தக்கூடியதாக்குகின்றன. Color, type, spacing முடிவுகளை :root-இல் ஒருமுறை சேமியுங்கள்.
