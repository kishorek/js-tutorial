தொகுதி 01 · HTML: பக்கத்தின் எலும்புக்கூடு

உங்கள் முதல் பக்கம்

பூஜ்யத்திலிருந்து ஒரு முழு இணையப் பக்கத்தை எழுதுங்கள், அதை உலாவியில் திறந்து பாருங்கள், ஆய்வு செய்யுங்கள், ஒவ்வொரு வரியையும் விளக்குங்கள். முந்தைய கோட் அனுபவம் தேவையில்லை, காப்பி-பேஸ்ட் இல்லை.

பாடம் 1.1 75–90 நிமிடம் தொடக்கநிலை முன்தேவை இல்லை

இறுதியில் நீங்கள் செய்யக்கூடியவை

  • HTML, CSS, JavaScript ஒவ்வொன்றும் என்ன செய்கிறது என்பதை விளக்குங்கள்.
  • நினைவில் இருந்து சரியான HTML5 எலும்புக்கூட்டை எழுதுங்கள்.
  • தலைப்புகள், பத்திகள், strong, மற்றும் emphasis ஆகியவற்றைப் பயன்படுத்தி உரையைக் கட்டமைக்கவும்.
  • ஒரு சிறிய “என்னைப் பற்றி” பக்கத்தை உருவாக்கி ஆய்வு செய்யுங்கள்.

உங்களுக்குத் தேவை

  • ஒரு உலாவி மற்றும் ஒரு உரை எடிட்டர்.
  • உங்கள் கோப்புகளுக்கு ஒரு கோப்புறை.
  • ஊகங்களை எழுத ஒரு பேனா மற்றும் காகிதம்.
  • தட்டச்சு செய்யவும் தவறுகள் செய்யவும் தயாராக இருக்க வேண்டும்.

மூன்று மொழிகள், ஒரு பக்கம்

ஒரு வீட்டை நினைத்துப் பாருங்கள். சட்டகம், சுவர்கள், அறைகளின் பெயர்கள் என்ன இருக்க வேண்டும், எங்கே இருக்க வேண்டும் என்பதை முடிவு செய்கின்றன. வண்ணப்பூச்சும் தளவாடங்களும் அது எப்படித் தோன்றும் என்பதை முடிவு செய்கின்றன. மின் இணைப்பு, சுவிட்சை இயக்கும்போது என்ன பதிலளிக்கும் என்பதை முடிவு செய்கிறது.

ஒரு இணையப் பக்கத்திலும் இதே மூன்று அடுக்குகள் உள்ளன:

மொழிஅதன் வேலைஅது இல்லாவிட்டால்
HTMLகட்டமைப்பும் பொருளும்: ஒவ்வொரு உள்ளடக்கமும் என்ன என்பதைத் தெரிவிக்கிறது.வரிசைப்படுத்தப்படாத, வடிவமைப்பில்லாத உரைக் குவியல்.
CSSதோற்றம்: நிறம், எழுத்துரு, இடைவெளி, அமைப்பு, அனிமேஷன்.படிக்கக்கூடியதாக இருக்கும், ஆனால் 1995-ஆம் ஆண்டு ஆவணம் போலத் தோன்றும்.
JavaScriptநடத்தை: கிளிக்குகளுக்குப் பதிலளிப்பது, உள்ளீட்டைச் சரிபார்ப்பது, தரவை எடுப்பது, பக்கத்தைப் புதுப்பிப்பது.படிக்கவும் பார்க்கவும் நன்றாக இருக்கும், ஆனால் நிலையானது.

நாங்கள் வேண்டுமென்றே HTML-இல் தொடங்குகிறோம். அழுகிய சட்டகத்தின் மேல் கட்டிய அழகான வீடும் அழுகிய வீடுதான். கட்டமைப்பு சரியாகிவிட்டால், CSS எளிதாக இருக்கும்; JavaScript-க்கு மாற்றுவதற்கு உறுதியான ஒன்று இருக்கும்.

பொருள் சார்ந்த HTML

உறுப்புகளை அவற்றின் இயல்பான தோற்றத்திற்காக அல்ல, பொருளுக்காகத் தேர்ந்தெடுங்கள். ஒரு தலைப்பு பெரியதாக இருப்பதால் அல்ல, ஒரு பகுதியைத் தொடங்குவதால் தலைப்பு ஆகிறது. திரை வாசிப்பான்கள், தேடுபொறிகள், எதிர்காலத்தில் நீங்களே—எல்லாரும் அந்தப் பொருளையே நம்பியிருக்கிறார்கள்.

ஒவ்வொரு பக்கத்திற்கும் தேவையான எலும்புக்கூடு

ஒவ்வொரு HTML5 பக்கமும் ஒரே வெளிப்புற ஓட்டுடன் தொடங்குகிறது. இது விரல்களுக்குப் பழக்கமாகும் வரை இதைத் தட்டச்சு செய்யுங்கள்.

பகுதிஅது என்ன செய்கிறதுஏன் முக்கியம்
<!DOCTYPE html>நவீன தரநிலை முறையைப் பயன்படுத்துமாறு உலாவிக்குச் சொல்கிறது.இது இல்லாவிட்டால், உலாவிகள் பக்கத்தை 1999-இல் இருப்பது போலக் காட்டலாம்.
<html lang="en">மூல உறுப்பு மற்றும் பக்கத்தின் மொழி.திரை வாசிப்பான்கள் உள்ளடக்கத்தைச் சரியாக உச்சரிக்கும்.
<head>பக்கத்தைப் பற்றிய தகவல்.head-இல் உள்ள எதுவும் பக்கத்தின் body-இல் தெரியாது.
<meta charset="UTF-8">எழுத்து குறியாக்கம்.உச்சரிப்புக் குறிகளும் சின்னங்களும் குப்பையாக மாறுவதைத் தடுக்கிறது.
<meta name="viewport" …>மொபைல் பக்க அளவீடு.இது இல்லாவிட்டால், போன்களில் பக்கம் மிகச் சிறியதாகத் தெரியும்.
<title>உலாவி தாவல் உரை.தாவல்கள், புக்மார்க்குகள், தேடல் முடிவுகளில் பயன்படுகிறது.
<body>பார்வையாளர் பார்க்கக்கூடிய அனைத்தும்.தலைப்புகள், படங்கள், பொத்தான்கள், footer-கள் இங்கே இருக்கும்.
நினைவு உதவி

Head = மேடைக்குப் பின்னால். Body = மேடை. பார்வையாளர் பார்க்க வேண்டியது body-இல் போடுங்கள். உலாவிக்கான தகவலாக இருந்தால் head-இல் போடுங்கள்.

டேக்குகள், எலிமெண்ட்கள், அட்டிரிபியூட்டுகள்

பெரும்பாலான எலிமெண்ட்களுக்கு மூன்று பகுதிகள் உண்டு: தொடக்க டேக், உள்ளடக்கம், முடிவு டேக்.

  • தொடக்க டேக்: <p class="intro"> எலிமெண்ட்டைத் தொடங்குகிறது.
  • அட்டிரிபியூட்: class="intro" தொடக்க டேக்கின் உள்ளிருந்து எலிமெண்ட்டை அமைக்கிறது.
  • உள்ளடக்கம்: Hello, world! என்பது பத்தியில் உள்ளது.
  • முடிவு டேக்: </p> எலிமெண்ட்டை முடிக்கிறது.

டேக்குகளை உள்ளிருந்து வெளியே மூடுங்கள். கடைசியாகத் திறந்த டேக்தான் முதலில் மூடப்பட வேண்டும். <p><strong>Hi</strong></p> சரி. <p><strong>Hi</p></strong> தவறு.

சில எலிமெண்ட்களுக்கு உள்ளடக்கமும் இல்லை, முடிவு டேக்கும் இல்லை: <meta>, <img>, <br>. இவற்றை வாயிட் எலிமெண்ட்கள் என்கிறார்கள்.

தலைப்புகளும் பத்திகளும்

தலைப்புகள் ஒரு அவுட்லைன்; எழுத்துரு அளவுகளின் பட்டியல் அல்ல. பக்கத்தின் முக்கிய தலைப்புக்கு <h1>-ஐ ஒருமுறை மட்டும் பயன்படுத்துங்கள்; பெரிய பகுதிகளுக்கு <h2>, துணைப்பகுதிகளுக்கு <h3>.

<strong> முக்கியத்துவத்தை குறிக்கிறது. <em> வலியுறுத்தலைக் குறிக்கிறது—பேசும்போது அழுத்திச் சொல்லும் வார்த்தை போல. இரண்டும் இயல்பாகத் தோற்றத்தை மாற்றினாலும், அவற்றின் உண்மையான மதிப்பு பொருள்தான். உரையை தடிமனாகவோ சாய்வாகவோ மாற்ற மட்டும் இவற்றைப் பயன்படுத்த வேண்டாம்; அது CSS-இன் வேலை.

பொதுவான தவறு

உலாவிகள் ஒரு அளவு வரை விட்டுவிடும். முடிவு டேக் தவறினால், பாதி பக்கம் மறைந்துவிடலாம் அல்லது தவறான எலிமெண்ட்டுக்குள் அடங்கிவிடலாம். உலாவி ஊகிக்கும்; அந்த ஊகம் பெரும்பாலும் நீங்கள் நினைத்ததாக இருக்காது.

நீங்களே முயற்சி செய்யுங்கள்

கீழே உள்ள பக்கத்தைத் திருத்தி, இயக்கு பொத்தானை அழுத்துங்கள். இயக்குவதற்கு முன் ஒவ்வொரு மாற்றமும் என்ன செய்யும் என்று ஊகியுங்கள்.

நேரடி முன்னோட்டம்

முன்னோட்டம் ஏற்றப்பட்டது. கோடைத் திருத்தி, பிறகு இயக்கு பொத்தானை அழுத்துங்கள்.

  1. h1-ஐ உங்கள் பெயராக மாற்றுங்கள்.
  2. பத்தியை உங்களைப் பற்றிய உண்மையான ஒன்றால் மாற்றுங்கள்.
  3. ஒரு h2 சேர்த்து, அது நான் இதை ஏன் கற்கிறேன் என்று சொல்லட்டும்; அதன் பிறகு புதிய p ஒன்றைச் சேர்க்கவும்.
  4. ஒரு வார்த்தையை <strong>-க்குள்ளும் மற்றொன்றை <em>-க்குள்ளும் வைக்கவும்.
  5. title-ஐ மாற்றி, முன்னோட்டத்தில் தாவல் லேபிள் எப்படி மாறுகிறது என்று பாருங்கள்.

உருவாக்குங்கள்: என்னைப் பற்றி

ஒரு h1, strong மற்றும் em உள்ள அறிமுகப் பத்தி, h2 ஒன்று நான் என்ன கற்கிறேன் என்று சொல்லட்டும், இரண்டாவது பத்தி, மற்றும் footer ஒன்று வாரம் 1-இல் உருவாக்கப்பட்டது என்று சொல்லட்டும்—இவற்றுடன் சரியான பக்கத்தை உருவாக்குங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சரிபாருங்கள்

title ஏன் body-இல் அல்லாமல் head-இல் இருக்க வேண்டும்?

title முழுப் பக்கத்தையும் உலாவிக்கும், புக்மார்க்குகளுக்கும், தேடல் முடிவுகளுக்கும் விவரிக்கிறது. அது மெட்டாடேட்டா; பக்கத்தில் தெரியும் உள்ளடக்கம் அல்ல. தெரியும் உள்ளடக்கம் body-இல் இருக்க வேண்டும்.

எலிமெண்ட் மற்றும் டேக்—இரண்டுக்கும் என்ன வித்தியாசம்?

ஒரு டேக் என்பது கோண அடைப்புக்குறிக்குள் இருக்கும் ஒரு லேபிள். ஒரு எலிமெண்ட் என்பது முழு அலகு: தொடக்க டேக், உள்ளடக்கம், முடிவு டேக். அட்டிரிபியூட்டுகள் தொடக்க டேக்கின் உள்ளே இருக்கும் அமைப்புகள்.

01 எந்த எலிமெண்ட் பார்வையாளருக்குத் தெரியும் பக்க உள்ளடக்கத்தைக் கொண்டுள்ளது?

02 உலாவி தாவல் உரையை அமைப்பது எந்த எலிமெண்ட்?

03 எந்தத் துண்டில் எலிமெண்ட்கள் சரியாக அடுக்கப்பட்டுள்ளன?

நினைவில் வைக்க வேண்டியவை

  • HTML என்பது கட்டமைப்பும் பொருளும். CSS தோற்றம். JavaScript நடத்தை.
  • எலும்புக்கூடு: doctype → html → head + body.
  • டேக்குகளை உள்ளிருந்து வெளியே மூடுங்கள். கடைசியாகத் திறந்தது முதலில் மூடப்படும்.
  • ஒரு பக்கத்திற்கு ஒரு h1. தலைப்புகள் அவுட்லைன்; CSS தோற்ற அளவுக்கானது.
  • Head மேடைக்குப் பின்னால்; body மேடை.
