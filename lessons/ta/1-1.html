Three languages, one page

ஒரு வீட்டை நினைச்சு பாருங்கள். Frame, walls, room labels எல்லாம் என்ன இருக்கணும், எங்கே இருக்கணும் என்பதை decide பண்ணும். Paint-உம் furniture-உம் வீடு எப்படி look ஆகணும் என்பதை decide பண்ணும். Wiring, switch-ஐ flip பண்ணும்போது என்ன respond பண்ணணும் என்பதை decide பண்ணும்.

Semantic HTML

Elements-ஐ அவங்க default appearance-க்காக அல்ல, meaning-க்காக choose பண்ணுங்கள். ஒரு heading பெரியதா இருக்கிறதால அல்ல, ஒரு section-ஐ start பண்ணுறதால heading. Screen readers, search engines, future-ல நீங்களும் அந்த meaning-ஐத்தான் depend பண்ணுவீங்க.

Memory hook

Head = மேடைக்கு பின்னாடி. Body = மேடை. Visitor பார்க்கணும்னா body-ல போடுங்கள். Browser-க்கான information-னா head-ல போடுங்கள்.

Tags, elements, attributes

பெரும்பாலான elements-க்கு மூன்று parts இருக்கு: opening tag, content, closing tag.

  • Opening tag: <p class="intro"> element-ஐ start பண்ணும்.
  • Attribute: class="intro" opening tag-க்கு உள்ளே இருந்து element-ஐ configure பண்ணும்.
  • Content: Hello, world! தான் paragraph-ல இருக்கிறது.
  • Closing tag: </p> element-ஐ end பண்ணும்.

Tags-ஐ உள்ளே இருந்து வெளியே close பண்ணுங்கள். கடைசியா open பண்ண tag தான் முதல்ல close ஆகணும். <p><strong>Hi</strong></p> correct. <p><strong>Hi</p></strong> இல்லை.

சில elements-க்கு content-உம் இல்லை, closing tag-உம் இல்லை: <meta>, <img>, <br>. இவற்றை void elements என்கிறார்கள்.

Headings and paragraphs

Headings ஒரு outline; font-size menu இல்லை. Page-ஓட main topic-க்கு <h1>-ஐ ஒரே ஒரு முறை use பண்ணுங்கள், பெரிய sections-க்கு <h2>, subsections-க்கு <h3>.

<strong> importance-ஐ குறிக்கும். <em> emphasis-ஐ குறிக்கும்—பேசும்போது அழுத்தி சொல்லுற வார்த்தை போல. இரண்டும் default-ஆ appearance-ஐ மாத்தும், ஆனா இவற்றோட real value meaning தான். Text-ஐ bold அல்லது italic ஆக்க மட்டும் இவற்றை use பண்ணாதீங்க; அது CSS வேலை.

Common mistake

Browsers ஒரு அளவு வரை forgive பண்ணும். Closing tag miss ஆனா, பாதி page மறைஞ்சு போகலாம் அல்லது wrong element-க்கு உள்ளே nest ஆகலாம். Browser guess பண்ணும்; அந்த guess பெரும்பாலும் நீங்கள் நினைத்தது போல இருக்காது.

Check yourself

Why does the title go in the head instead of the body?

Title முழு page-ஐயும் browser-க்கு, bookmarks-க்கு, search results-க்கு describe பண்ணும். அது metadata; page-ல தெரியிற content இல்லை. தெரியிற content body-ல தான் இருக்கணும்.

What is the difference between an element and a tag?

Tag-னா angle brackets-க்கு உள்ளே இருக்கிற ஒரு label. Element-னா முழு unit: opening tag, content, closing tag. Attributes-னா opening tag-க்கு உள்ளே இருக்கிற settings.

Key things to remember

  • HTML structure-உம் meaning-உம். CSS presentation. JavaScript behavior.
  • Skeleton: doctype → html → head + body.
  • Tags-ஐ உள்ளே இருந்து வெளியே close பண்ணுங்கள். கடைசியா open பண்ணது முதல்ல close.
  • ஒரு page-க்கு ஒரு h1. Headings ஒரு outline; CSS visual size-க்கு.
  • Head மேடைக்கு பின்னாடி, body மேடை.
