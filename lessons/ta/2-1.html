Selector-கள், cascade, specificity

CSS என்பது rule-களின் பட்டியல். Selector ஒரு element-ஐ தேர்ந்தெடுக்கும், declaration மாற்றத்தை விவரிக்கும், இரண்டு rule-கள் முரண்படும்போது எது வெல்லும் என்பதை cascade முடிவு செய்யும். இந்த வரிசையை ஒருமுறை புரிந்துகொண்டால், CSS தற்செயலானது போலத் தோன்றுவது நின்றுவிடும்.

பாடம் 2.1 60–75 நிமிடம் தொடக்கநிலை

இதன் முடிவில், நீங்கள்

  • Stylesheet-ஐ இணைத்து ஒரு rule எழுத முடியும்.
  • Element, class, id, descendant, pseudo-class selector-களைப் பயன்படுத்த முடியும்.
  • எந்த declaration வெல்லும் என்பதை முன்கூட்டியே சொல்லி, ஏன் என்று விளக்க முடியும்.

உங்களுக்குத் தேவை

  • உங்கள் தொகுதி 1 பக்கங்கள், குறிப்பாக about-me.html.
  • DevTools உள்ள browser.
  • உங்கள் HTML-க்கு அருகில் ஒரு CSS file.

Stylesheet-ஐ இணைப்பது

CSS தனி file-இல் இருக்கும், அதை <head>-இல் இருந்து இணைப்போம். href என்பது நீங்கள் ஏற்கனவே எழுதிய link-களைப் போலவே ஒரு relative path. ஒரு rule-இல் braces-க்கு முன் selector, உள்ளே declaration-கள் இருக்கும். ஒவ்வொரு declaration-ம் property, ஒரு colon, ஒரு value, ஒரு semicolon.

ஒரு யோசனைக்கு ஒரு rule என்று எழுதுங்கள்; file-ஐ நல்ல வரிசையில் வையுங்கள்: reset, base element-கள், layout, component-கள், utility-கள். Browser rule-களை மேலிருந்து கீழாகப் படிக்கும்.

Selector-கள் element-களைத் தேர்ந்தெடுக்கின்றன

வேலையைச் செய்யும் மிகக் குறைந்த வலிமை கொண்ட selector-ஐ முதலில் பயன்படுத்துங்கள். Class-கள் மீண்டும் பயன்படுத்தக்கூடியவை, அதனால் component-களுக்கு அவையே சரியான default. Id ஒரு பக்கத்தில் ஒரே element-க்கு மட்டும்; anchor-களுக்கும் JavaScript hook-களுக்கும் அவற்றை வைத்திருங்கள்.

  • Element: பொருந்தும் ஒவ்வொரு tag-ம், எல்லா இடத்திலும். Base style-களுக்குப் பயனுள்ளது.
  • Class: .card என்று எழுதி class="card"-உடன் match ஆகும். மீண்டும் பயன்படுத்தலாம்; பெரும்பாலான வேலைக்குப் போதுமான specificity உள்ளது.
  • Id: #intro என்று எழுதி id="intro"-உடன் match ஆகும். ஒரு பக்கத்திற்கு ஒன்று; பிறகு override செய்வது கடினம்.
  • Descendant: .card p என்றால் card-க்குள் எந்த ஆழத்திலும் உள்ள எந்த paragraph-ஐயும் குறிக்கும்.
  • Pseudo-class: :hover, :focus-visible, அல்லது :first-child போன்ற ஒரு நிலை.

Selector-களை ஆழமற்றதாக வையுங்கள். main .card div h3-ஐ விட .card__title படிக்கவும் override செய்யவும் எளிது; markup மாறினாலும் அது வேலை செய்யும்.

Cascade, சமநிலையை வரிசையால் முறிக்கிறது

ஒரே element-இல் ஒரே property-ஐ இரண்டு rule-கள் அமைத்தால், selector-களின் எடை சமமாக இருந்தால் பிறகு வரும் rule வெல்லும். கீழே உள்ள நிறத்தை scroll செய்வதற்கு முன் யூகியுங்கள்.

Paragraph பச்சை நிறம். இரண்டு selector-களுக்கும் ஒரே specificity, அதனால் source order முடிவு செய்கிறது: இரண்டாவது declaration முதலாவதை மாற்றுகிறது. அதனால்தான் உங்கள் stylesheet-இன் வரிசை முக்கியம்.

Specificity-க்கு எடைகள் உண்டு

Specificity என்பது நான்கு பகுதிகள் கொண்ட மதிப்பெண். இடமிருந்து வலமாக ஒப்பிடுங்கள்; ஒரு id எத்தனை class-களையும் வெல்லும். Inline style தனி, வலிமையான வகை; !important சாதாரண declaration-களுக்கு மேலே உள்ளது.

Selectorமதிப்பெண்எடுத்துக்காட்டு
Inline style1-0-0-0style="color: red"
Id0-1-0-0#intro
Class, attribute, pseudo-class0-0-1-0.note, a:hover
Element, pseudo-element0-0-0-1p, p::first-line
Universal (எல்லா element-களும்)0-0-0-0*

இப்போது இரண்டு paragraph-களையும் யூகியுங்கள். முதலாவதில் id உள்ளது; இரண்டாவதில் ஒரே selector-இல் class-ம் element-ம் உள்ளன.

முதல் paragraph சிவப்பு: #intro 0-1-0-0 எடுத்து எல்லா class rule-ஐயும் வெல்கிறது. இரண்டாவது சாம்பல்: p.note 0-0-1-1 எடுத்து, 0-0-1-0 உள்ள .note-ஐ வெல்கிறது. முதலில் class-களை எண்ணுங்கள், பிறகு element-களை; column-களைக் கூட்ட வேண்டாம்.

ஒரு card, style செய்யப்பட்டது

சிறிய, யூகிக்கக்கூடிய component-இல் பெட்டிக்கு ஒரு class, ஒவ்வொரு பகுதிக்கும் ஒரு class: .card, .card__title, .card__text. ஒவ்வொரு selector-ம் 0-0-1-0 எடுக்கும், அதனால் கடைசியாக match ஆகும் rule வெல்லும்; எந்த id-உடனும் போட்டி இல்லை.

Inheritance மற்றும் கடைசி வழி

color, font-family, line-height போன்ற சில property-கள் parent element-இலிருந்து inherit ஆகும். margin, padding, border போன்றவை ஆகாது. Inherit ஆகும் property-களை body-இல் ஒருமுறை அமைத்தால் முழு பக்கமும் பின்பற்றும்.

!important-ஐ தவிர்க்கவும்

!important சாதாரண cascade-ஐ override செய்கிறது. உங்களுடையதை வெல்ல அடுத்தவர் இன்னொரு !important சேர்க்க வேண்டியிருக்கும்; file ஒரு சண்டையாகிவிடும். third-party CSS-ஐ வேண்டுமென்றே, பதிவு செய்து override செய்யும்போது மட்டும் பயன்படுத்துங்கள். உங்கள் style-களுக்கு, selector-ஐ அல்லது வரிசையைச் சரிசெய்யுங்கள்.

Class-களைக் கொண்டு card-ஐ style செய்யுங்கள்

இந்த HTML-ஐப் பயன்படுத்துங்கள். பக்க text #1c1a16 ஆகவும், card-க்கு வெள்ளை background, 1px solid #d8d0c0 border, 6px radius ஆகவும் இருக்கும்படி CSS எழுதுங்கள். Title 1.25rem அளவில் #14532d ஆகவும்; paragraph #555 ஆகவும் இருக்க வேண்டும். ஒவ்வொரு card rule-க்கும் class selector பயன்படுத்துங்கள்; !important வேண்டாம்.

முதலில் முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

ஒரு id எப்படி பல class-களை வெல்கிறது?

Specificity வகைகளை மொத்த எண்ணிக்கையால் அல்ல, இடமிருந்து வலமாக ஒப்பிடுகிறது. Id இரண்டாவது column-க்கு எடை சேர்க்கிறது; class-கள் மூன்றாவது column-க்கு. எத்தனை class பெயர்கள் சேர்ந்தாலும் 0-1-0-0 என்பது 0-0-9-0-ஐ வெல்லும்.

!important எப்போதாவது சரியான தேர்வா?

அரிதாகவே. உங்கள் கட்டுப்பாட்டில் இல்லாத, selector-ஐ மாற்ற முடியாத CSS-ஐ override செய்ய வேண்டியிருக்கும்போது (உதாரணமாக vendor widget) அது நியாயப்படுத்தக்கூடியது. உங்கள் சொந்த code-க்கு, வேண்டுமென்றே specificity-ஐ உயர்த்துங்கள் அல்லது rule-ஐ பிறகு நகர்த்துங்கள். எந்த விதிவிலக்கையும் பதிவு செய்யுங்கள்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • Class-களே default கருவி. மீண்டும் பயன்படுத்தலாம், படிக்க எளிது, override செய்வதும் எளிது.
  • Specificity column வாரியாக ஒப்பிடப்படுகிறது. Inline id-ஐ வெல்லும், id class-ஐ வெல்லும், class element-ஐ வெல்லும்.
  • சமநிலையை வரிசை தீர்மானிக்கிறது. எடை சமமாக இருந்தால், பிறகு வரும் declaration வெல்லும்; உங்கள் stylesheet-ஐ ஒழுங்காக வையுங்கள்.
