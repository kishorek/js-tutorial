Flexbox in one minute

display: flex ஒரு container-ஐ flex container-ஆவும், அதோட direct children-ஐ flex items-ஆவும் மாற்றும். Items main axis-ல அமையும், default-ஆ horizontal; cross axis எதிர் direction-ல போகும். justify-content main axis-ல space-ஐ distribute பண்ணும், align-items cross axis-ல items-ஐ align பண்ணும், gap margins collapse ஆகாம items-க்கு space தரும்.

  • justify-content flex-start, center, space-between-ஐ எடுக்கும்; align-items stretch, flex-start, center, baseline-ஐ எடுக்கும்.
  • flex-wrap: wrap items-ஐ எப்போதும் shrink ஆகாம new line-க்கு move ஆக விடும்.
  • flex: 1 1 240px என்றா grow, shrink, 240px basis-ல இருந்து start பண்ணு. Text அதிகம் உள்ள item shrink ஆக min-width: 0 add பண்ணுங்கள்.

560px-க்கு கீழ header column-ஆ மாறும்; brand-ம் links-ம் squeeze ஆகாம ஒண்ணுக்கு கீழ ஒண்ணா stack ஆகும்.

Check yourself

Why does flex-wrap: wrap matter for the project row?

Wrap இல்லாம, flex items ஒரே line-ல பொருந்த shrink ஆகும், cards படிக்க முடியாம போகும். 240px basis பொருந்தாதபோது wrapping ஒரு card-ஐ அடுத்த row-க்கு move பண்ணும்.

Why not use justify-content: space-between on the project row?

Space-between first, last card-ஐ edges-ல pin பண்ணி, உள்ளே uneven gaps விடும். gap ஒவ்வொரு card-க்கும் same space தரும்; space-between-ஐ இரண்டு ends உள்ள header-க்கு வைச்சுக்கோங்கள்.

Module 2 complete

  • Flexbox ஒரு one-dimensional layout. ஒரு main axis-ஐ choose பண்ணுங்கள், அப்புறம் distribute-ம் align-ம் பண்ணுங்கள்.
  • Shrink பண்ணுறதுக்கு முன்னாடி wrap பண்ணுங்கள். flex: 1 1 240px உள்ள wrapping row பெரும்பாலான card layouts-ஐ handle பண்ணும்.
