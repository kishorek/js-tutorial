Flexbox + portfolio v1

Flexbox item-களை ஒரு திசையில் அமைத்து, மீதமுள்ள இடத்தைப் பகிர்கிறது. ஒரு header, ஒரு hero, ஒரு வரிசை project card-களுக்கு அது போதும். தொகுதி project-ஐ முடியுங்கள்: முழுமையான responsive ஒரு பக்க portfolio.

  • Header, nav, hero, projects, footer உள்ள ஒரு index.html.

வெளியேறும் சோதனை

  • 360px-இல் பக்கவாட்டு scroll இல்லை.
  • Main axis, cross axis வேறுபாட்டை விளக்க முடியும்.

ஒரு நிமிடத்தில் Flexbox

display: flex ஒரு container-ஐ flex container-ஆகவும், அதன் நேரடி child-களை flex item-களாகவும் மாற்றும். Item-கள் main axis-இல் அமையும், default-ஆக horizontal; cross axis எதிர் திசையில் செல்லும். justify-content main axis-இல் இடத்தைப் பகிர்கிறது, align-items cross axis-இல் item-களைச் சீரமைக்கிறது, gap margin collapse இல்லாமல் இடைவெளி தருகிறது.

  • justify-content flex-start, center, space-between-ஐ எடுக்கும்; align-items stretch, flex-start, center, baseline-ஐ எடுக்கும்.
  • flex-wrap: wrap item-கள் முடிவில்லாமல் சுருங்குவதற்குப் பதிலாகப் புதிய வரிக்கு நகர அனுமதிக்கிறது.
  • flex: 1 1 240px என்றால் grow, shrink, 240px basis-இலிருந்து தொடங்கு. Text அதிகம் உள்ள item சுருங்க min-width: 0 சேர்க்கவும்.

560px-க்குக் கீழே header column ஆக மாறும்; brand-ம் link-களும் நெருக்கிப் போடாமல் ஒன்றின் கீழ் ஒன்றாக அமையும்.

  • 360px-இல் page-level horizontal scroll இல்லை; ஒவ்வொரு link-க்கும் தெரியும் focus state.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

Project வரிசைக்கு flex-wrap: wrap ஏன் முக்கியம்?

Wrap இல்லாமல், flex item-கள் ஒரே வரியில் பொருந்தச் சுருங்கும், card-கள் படிக்க முடியாமல் போகும். 240px basis பொருந்தாதபோது wrap ஒரு card-ஐ அடுத்த வரிக்கு நகர்த்தும்.

Project வரிசையில் justify-content: space-between ஏன் பயன்படுத்தக் கூடாது?

Space-between முதல், கடைசி card-ஐ விளிம்புகளில் பொருத்தி, உள்ளே சீரற்ற இடைவெளிகளை விடும். gap ஒவ்வொரு card-க்கும் ஒரே இடைவெளி தரும்; space-between-ஐ இரு முனைகள் உள்ள header-க்கு வைத்திருங்கள்.

தொகுதி 2 முடிந்தது

  • Flexbox ஒரு பரிமாணம். ஒரு main axis-ஐத் தேர்ந்தெடுத்து, பிறகு பகிர்ந்து சீரமைக்கவும்.
  • சுருங்குவதற்கு முன் wrap செய்யுங்கள். flex: 1 1 240px உள்ள wrap ஆகும் வரிசை பெரும்பாலான card layout-களைக் கையாளும்.
