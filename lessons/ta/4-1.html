Module 04 · JavaScript foundations

Values, variables, and types

JavaScript சிறிய data pieces-லிருந்தும், அவற்றுக்கு நாம் கொடுக்கும் names-லிருந்தும் தொடங்குகிறது. Values எப்படி store ஆகின்றன, அவற்றுக்கு என்ன type, ஆச்சரியம் இல்லாமல் அவற்றை எப்படி compare பண்றது என்பதைக் கற்றுக்கொள்ளுங்கள்.

Where JavaScript goes

HTML page-க்கு structure தருகிறது. CSS அதை style பண்ணுகிறது. JavaScript behaviour add பண்ணுகிறது. நீங்கள் அதை <script> element-ஓட add பண்றீங்க; பொதுவா <body> முடிவுல add பண்ணுங்க, அப்போ script run ஆவதுக்கு முன்னாடி page content ready-ஆ இருக்கும்.

console.log() ஒரு value-ஐ console-ல print பண்ணும். பெரும்பாலான browsers-ல F12 அழுத்துங்க அல்லது page-ல right-click பண்ணி Inspect தேர்ந்தெடுங்க; பிறகு Console tab-ஐ திறங்க. Page-ல எதுவும் தெரியாது; அந்த message உங்களுக்குத்தான்.

Debug habit

Code ஏன் fail ஆகுது என்று guess பண்ணுவதுக்கு முன்னாடி, உங்களுக்கு doubt-ஆ இருக்கிற value-ஐ log பண்ணுங்க. Console message ஒரு evidence. Guess evidence இல்ல.

Variables name values

Variable என்பது memory-ல store ஆன ஒரு value-க்கு கொடுக்குற label. அது மாறப் போகுது என்றால் let-ஓட declare பண்ணுங்க, மாறப் போவதில்லை என்றால் const-ஓட. Reassign பண்ண வேண்டிய காரணம் வரும் வரை const-ஐ prefer பண்ணுங்க.

  • Names case-sensitive: firstName மற்றும் firstname வேற வேற.
  • சாதாரண variables-க்கு camelCase use பண்ணுங்க.
  • ஒரு name number-ல start பண்ண முடியாது, spaces-ம் இருக்கக் கூடாது.
  • let, const, return போன்ற reserved words-ஐ names-ஆ use பண்ணாதீங்க.

Strings and template literals

Strings-ல single quotes, double quotes அல்லது backticks use பண்ணலாம். Backticks ஒரு template literal-ஐ உருவாக்கும்: ${...} கொண்டு values-ஐ insert பண்ணலாம், பல lines-ல எழுதலாம்.

Text-ஐயும் values-ஐயும் mix பண்றப்போ template literals-ஐ prefer பண்ணுங்க. Plus signs chains-ஐ விட read பண்ண எளிது, break ஆவதும் கஷ்டம்.

Strings-க்கு useful properties மற்றும் methods உண்டு. .length characters-ஐ count பண்ணும், .toUpperCase() புது uppercase string-ஐ return பண்ணும், .includes() ஒரு substring இருக்கா என்று check பண்ணும்.

Coercion and strict equality

JavaScript சில நேரம் ஒரு value-ஐ இன்னொரு type-ஆ தானா convert பண்ணும். இதை type coercion என்கிறாங்க. Confusing ஆகும் வரை இது convenient.

Use three equals

== coercion நடந்த பிறகு compare பண்ணும். === value-ஐயும் மற்றும் type-ஐயும் compare பண்ணும். Specific காரணம் இல்லாத வரை எல்லா இடத்திலும் === மற்றும் !== use பண்ணுங்க.

வேண்டுமென்றே convert பண்ண Number("5"), String(5) அல்லது Boolean(value) use பண்ணுங்க. Explicit-ஆ எழுதுவது அடுத்து read பண்றவரை — பெரும்பாலும் future உங்களை — trouble-லிருந்து காப்பாற்றும்.

Move values around

இந்த நாலு moves beginner debugging-ல பெரும்பகுதியை cover பண்ணும். ஒவ்வொன்றையும் console-ல run பண்ணி, values-ஐ மாற்றிப் பாருங்க.

  1. Log it. console.log(value) current value-ஐ காட்டும்.
  2. Check its type. Number எதிர்பார்த்த இடத்துல text இருந்தா console.log(typeof value) அதை catch பண்ணும்.
  3. Compare strictly. ==-ஐ === ஆக மாத்தி, branch இன்னும் run ஆகுதா என்று பாருங்க.
  4. Copy it into a new name. ஒரு value எதிர்பாராத விதமா மாறினா, அதை second variable-க்கு assign பண்ணி இரண்டையும் log பண்ணுங்க.

Check yourself

When should I use let instead of const?

Variable-க்கு மீண்டும் value assign பண்ணும்போது மட்டும் let use பண்ணுங்க; counter அல்லது ஓடிக்கொண்டிருக்கும் total போல. Name எப்பவும் ஒரே value-ஐ point பண்ணும் என்றால் const use பண்ணுங்க. const object-ஓட properties-ஐ இன்னும் change பண்ணலாம்; name மட்டும் வேற object-ஐ point பண்ண முடியாது.

Why is 5 == "5" true but 5 === "5" false?

Double equals compare பண்ணுவதுக்கு முன்னாடி string-ஐ number-ஆ convert பண்ணும், அதனால இரண்டு பக்கமும் 5 ஆகும். Triple equals type-ஐயும் check பண்ணும். Number-க்கும் string-க்கும் type வேற, அதனால result false.

Key things to remember

  • Values-க்கு types உண்டு. Strings, numbers, booleans, null, undefined ஆகியவை beginner வேலையின் பெரும்பகுதியை cover பண்ணும்.
  • Names explain பண்ணணும். const-ஐ prefer பண்ணுங்க; உண்மையா reassign தேவைப்பட்டா let use பண்ணுங்க.
  • Strict equality surprises-ஐ தவிர்க்கும். === மற்றும் !== use பண்ணுங்க, doubt இருந்தா values-ஐ log பண்ணுங்க.
