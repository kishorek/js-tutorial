தொகுதி 04 · JavaScript அடிப்படைகள்

மதிப்புகள், மாறிகள் மற்றும் வகைகள்

JavaScript சிறிய தரவுத் துண்டுகளிலிருந்தும், அவற்றுக்கு நாம் கொடுக்கும் பெயர்களிலிருந்தும் தொடங்குகிறது. மதிப்புகள் எப்படிச் சேமிக்கப்படுகின்றன, அவற்றின் வகை என்ன, ஆச்சரியங்கள் இல்லாமல் அவற்றை எப்படி ஒப்பிடுவது என்பதைக் கற்றுக்கொள்ளுங்கள்.

பாடம் 4.1 60–75 நிமிடங்கள் தொடக்கநிலை

இறுதியில் நீங்கள் செய்யக்கூடியவை

  • ஒரு பக்கத்தில் JavaScript-ஐச் சேர்த்து console-ஐப் படிக்க முடியும்.
  • let மற்றும் const கொண்டு மதிப்புகளை அறிவிக்க முடியும்.
  • தொடக்கநிலைக்கான ஐந்து வகைகளுக்குப் பெயர் சொல்லி, typeof கொண்டு அவற்றைச் சரிபார்க்க முடியும்.
  • Template literals மற்றும் strict equality-ஐ நம்பிக்கையுடன் பயன்படுத்த முடியும்.

உங்களுக்குத் தேவையானவை

  • DevTools உள்ள browser.
  • தொகுதி 1-இல் பயன்படுத்திய உங்கள் எடிட்டர்.
  • சிறிய typo பிழைகளுக்குப் பொறுமை.

JavaScript எங்கே இடம்பெறுகிறது

HTML பக்கத்திற்குக் கட்டமைப்பைத் தருகிறது. CSS அதற்கு வடிவம் தருகிறது. JavaScript செயல்பாட்டைச் சேர்க்கிறது. நீங்கள் அதை <script> element மூலம் சேர்க்கிறீர்கள்; பொதுவாக <body> முடிவில் சேர்க்கிறீர்கள், அப்போது script இயங்குவதற்கு முன் பக்கத்தின் உள்ளடக்கம் தயாராக இருக்கும்.

console.log() ஒரு மதிப்பை console-ல் அச்சிடுகிறது. பெரும்பாலான browsers-ல் F12 அழுத்துங்கள் அல்லது பக்கத்தில் right-click செய்து Inspect-ஐத் தேர்ந்தெடுங்கள்; பிறகு Console tab-ஐத் திறவுங்கள். பக்கத்தில் எதுவும் தெரியாது; அந்தச் செய்தி உங்களுக்கானது.

பிழைத்திருத்தப் பழக்கம்

உங்கள் code ஏன் வேலை செய்யவில்லை என்று ஊகிப்பதற்கு முன், உறுதியில்லாத மதிப்பை log செய்யுங்கள். Console செய்தி ஆதாரம். ஊகம் ஆதாரம் அல்ல.

மாறிகள் மதிப்புகளுக்குப் பெயரிடுகின்றன

மாறி (variable) என்பது memory-ல் சேமிக்கப்பட்ட ஒரு மதிப்புக்கான பெயர். அது மாறப்போகிறது என்றால் let கொண்டும், மாறப்போவதில்லை என்றால் const கொண்டும் அறிவிக்கவும். மீண்டும் மதிப்பு வைக்க வேண்டிய காரணம் வரும் வரை const-ஐ விரும்புங்கள்.

  • பெயர்கள் case-sensitive: firstName மற்றும் firstname வேறுபட்டவை.
  • சாதாரண மாறிகளுக்கு camelCase பயன்படுத்துங்கள்.
  • ஒரு பெயர் எண்ணில் தொடங்கக்கூடாது; இடைவெளிகளும் இருக்கக்கூடாது.
  • let, const அல்லது return போன்ற reserved words-ஐ பெயர்களாகப் பயன்படுத்த வேண்டாம்.

அடிப்படை வகைகள்

ஒவ்வொரு மதிப்புக்கும் ஒரு வகை உண்டு. தொடக்கநிலையில் ஐந்து வகைகளை அடிக்கடி சந்திப்பீர்கள்.

வகைஎடுத்துக்காட்டுஎதற்குப் பயன்படும்
String"hello"உரை; நீங்கள் கணக்கிடப் பயன்படுத்தாத இலக்கங்கள் உட்பட.
Number42, 3.14எந்த எண் மதிப்பும், முழு எண்ணோ தசமமோ.
Booleantrue, falseஆம்/இல்லை முடிவுகள்.
Nullnullவேண்டுமென்றே வைக்கப்படும் காலி மதிப்பு.
Undefinedundefinedஇன்னும் அமைக்கப்படாத மதிப்பு.

typeof ஒரு மதிப்பின் வகையைச் சொல்கிறது. நீங்கள் நினைத்ததை அல்ல, உண்மையில் இருப்பதை விரைவாகச் சரிபார்க்க இது ஒரு வழி.

Strings மற்றும் template literals

Strings-ல் single quotes, double quotes அல்லது backticks பயன்படுத்தலாம். Backticks ஒரு template literal-ஐ உருவாக்குகின்றன: ${...} கொண்டு மதிப்புகளைச் செருகலாம், பல வரிகளில் எழுதலாம்.

உரையையும் மதிப்புகளையும் கலக்கும்போது template literals-ஐ விரும்புங்கள். Plus குறியீடுகளின் சங்கிலிகளைவிட அவை படிக்க எளிது, உடையவும் கடினம்.

Strings-க்கு பயனுள்ள properties மற்றும் methods உண்டு. .length எழுத்துகளை எண்ணும், .toUpperCase() புதிய uppercase string-ஐத் திருப்பித் தரும், .includes() ஒரு substring இருக்கிறதா என்று பார்க்கும்.

Type coercion மற்றும் strict equality

JavaScript சில நேரங்களில் ஒரு மதிப்பை மற்றொரு வகையாகத் தானாக மாற்றுகிறது. இதை type coercion என்கிறார்கள். குழப்பம் வரும் வரை இது வசதியாக இருக்கும்.

மூன்று சமக்குறிகளைப் பயன்படுத்துங்கள்

== coercion நடந்த பிறகு ஒப்பிடுகிறது. === மதிப்பையும் மற்றும் வகையையும் ஒப்பிடுகிறது. குறிப்பிட்ட காரணம் இல்லாத வரை எல்லா இடங்களிலும் === மற்றும் !== பயன்படுத்துங்கள்.

வேண்டுமென்றே மாற்ற Number("5"), String(5) அல்லது Boolean(value) பயன்படுத்துங்கள். தெளிவாக எழுதுவது அடுத்து படிப்பவரை — பெரும்பாலும் எதிர்கால உங்களை — சிக்கலில் இருந்து காப்பாற்றும்.

மதிப்புகளை நகர்த்திப் பாருங்கள்

இந்த நான்கு நடவடிக்கைகள் தொடக்கநிலை பிழைத்திருத்தத்தின் பெரும்பகுதியைக் கவர்கின்றன. ஒவ்வொன்றையும் console-ல் இயக்கி, மதிப்புகளை மாற்றிப் பாருங்கள்.

  1. Log செய்யுங்கள். console.log(value) தற்போதைய மதிப்பைக் காட்டும்.
  2. அதன் வகையைச் சரிபார்க்கவும். எண்ணை எதிர்பார்த்த இடத்தில் உரை இருந்தால் console.log(typeof value) அதைக் கண்டுபிடிக்கும்.
  3. கண்டிப்பாக ஒப்பிடுங்கள். ==-ஐ === ஆக மாற்றி, branch இன்னும் இயங்குகிறதா என்று பாருங்கள்.
  4. அதைப் புதிய பெயரில் நகலெடுங்கள். ஒரு மதிப்பு எதிர்பாராத விதமாக மாறினால், அதை இரண்டாவது மாறிக்கு ஒப்படைத்து இரண்டையும் log செய்யுங்கள்.

Console-ல் உங்களை அறிமுகப்படுத்துங்கள்

உங்கள் பெயருக்கு ஒரு const, வயதுக்கு ஒரு let, JavaScript பிடிக்குமா என்பதற்கு ஒரு const boolean அறிவிக்கவும். Template literal கொண்டு ஒரு வாக்கியத்தை log செய்யுங்கள். பிறகு வயதை ஒன்று அதிகரித்து இரண்டாவது வாக்கியத்தை log செய்யுங்கள். மூன்று மதிப்புகளின் வகையையும் log செய்து முடிக்கவும்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சோதித்துக் கொள்ளுங்கள்

எப்போது const-க்குப் பதிலாக let பயன்படுத்த வேண்டும்?

மாறிக்கு மீண்டும் மதிப்பு வைக்கப்படும் போது மட்டும் let பயன்படுத்துங்கள்; எடுத்துக்காட்டாக ஒரு counter அல்லது தொடர்ந்து கூட்டப்படும் total. பெயர் எப்போதும் ஒரே மதிப்பையே குறிக்கும் என்றால் const பயன்படுத்துங்கள். const object-ன் properties-ஐ இன்னும் மாற்றலாம்; பெயர் மட்டும் வேறு object-ஐ குறிக்க முடியாது.

5 == "5" ஏன் true, ஆனால் 5 === "5" ஏன் false?

Double equals ஒப்பிடுவதற்கு முன் string-ஐ number ஆக மாற்றுகிறது; அதனால் இரு பக்கமும் 5 ஆகிறது. Triple equals வகையையும் சரிபார்க்கிறது. Number-க்கும் string-க்கும் வகை வேறு; எனவே முடிவு false.

நினைவில் கொள்ள வேண்டிய முக்கிய விஷயங்கள்

  • மதிப்புகளுக்கு வகைகள் உண்டு. Strings, numbers, booleans, null மற்றும் undefined ஆகியவை தொடக்கநிலை வேலைகளின் பெரும்பகுதியைக் கவர்கின்றன.
  • பெயர்கள் விளக்கமாக இருக்க வேண்டும். const-ஐ விரும்புங்கள்; உண்மையில் மீண்டும் மதிப்பு வைப்பது தேவைப்பட்டால் let பயன்படுத்துங்கள்.
  • Strict equality ஆச்சரியங்களைத் தவிர்க்கிறது. === மற்றும் !== பயன்படுத்துங்கள்; சந்தேகம் இருந்தால் மதிப்புகளை log செய்யுங்கள்.
