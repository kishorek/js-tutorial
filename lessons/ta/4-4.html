Functions மற்றும் scope

Functions படிகளின் ஒரு தொகுப்பை, மீண்டும் பயன்படுத்தவும், சோதிக்கவும், பிற இடங்களுக்கு அனுப்பவும் முடிந்த பெயரிடப்பட்ட கருவியாக மாற்றுகின்றன. Parameters, return values, arrow syntax, scope, மேலும் pure function-க்கும் உங்கள் மற்ற code-உடன் மோதும் function-க்கும் உள்ள வித்தியாசத்தைக் கற்றுக்கொள்ளுங்கள்.

  • ஒரு function எந்த மாறிகளைப் பார்க்க முடியும் என்று கணிக்க முடியும்.
  • Callbacks பயன்படுத்தி, pure function-ஐ அடையாளம் காண முடியும்.

Functions மீண்டும் பயன்படுத்தக்கூடிய வேலைகளுக்குப் பெயரிடுகின்றன

Function declaration function keyword, ஒரு பெயர், parameter list மற்றும் body-யுடன் தொடங்குகிறது. அதை அறிவிப்பதால் அது இயங்காது. பெயரை parentheses-உடன் call செய்வதன் மூலம் இயக்குவீர்கள்.

Parentheses-க்குள் உள்ள name என்பது parameter; ஒரு மதிப்புக்கான இடத்தைக் குறிக்கும். Call செய்யும்போது அனுப்பும் "Maya" போன்ற மதிப்பு argument. Function-க்குள் parameter ஒரு சாதாரண மாறி போலவே செயல்படும்.

Parameters மற்றும் return values

return ஒரு மதிப்பை call செய்தவருக்குத் திருப்பி அனுப்பி, function-ஐ உடனே நிறுத்தும். Return statement இல்லாவிட்டால் function undefined திருப்பித் தரும்.

Log செய்வதும் return செய்வதும் வெவ்வேறு வேலைகள். Log செய்யும் function console-ஐப் பார்க்கும் மனிதருக்குப் பயனுள்ளது. Return செய்யும் function நிரலின் மற்ற பகுதிகளுக்குப் பயனுள்ளது; ஏனெனில் மற்றொரு function அந்த முடிவைப் பயன்படுத்தலாம்.

return-க்குப் பிறகு உள்ள code ஒருபோதும் இயங்காது. திரும்புவதற்கு முன் ஏதாவது கணக்கிட வேண்டுமானால், அந்த வேலையை முதலில் செய்யுங்கள்.

Function expressions மற்றும் arrow functions

Function expression ஒரு function-ஐ மாறியில் சேமிக்கிறது. அந்த function பெயரற்றதாக இருக்கலாம்; மற்றொரு method-க்கு அனுப்பும்போது இது பொதுவானது.

Arrow function சுருக்கமான expression syntax. ஒரு parameter இருந்தால் parentheses விருப்பமானது. ஒரே expression இருந்தால் braces-ம் return-ம் விருப்பமானவை.

சிறிய callbacks-க்கு arrow functions சிறந்தவை. this-ஐ அவை கையாளும் விதத்தில் சாதாரண functions-லிருந்து வேறுபடுகின்றன; ஆனால் தொகுதி 5-இல் objects மற்றும் events-உடன் வேலை செய்யும் வரை அந்த வித்தியாசம் தேவைப்படாது.

Default values மற்றும் scope

Caller ஒரு argument-ஐ விட்டுவிட்டால், default parameter ஒரு மதிப்பைத் தரும். Defaults function அறிவிக்கப்படும்போது அல்ல, அது இயங்கும்போது மதிப்பிடப்படும்.

Scope என்பது ஒரு code பகுதி பார்க்கக்கூடிய பெயர்களின் தொகுப்பு. Function-க்குள் அறிவிக்கப்பட்ட மாறி local: அது அந்த call-க்கு மட்டுமே இருக்கும். வெளியே அறிவிக்கப்பட்ட மாறி file-க்கு global; functions-க்குள் தெரியும்.

Loops மற்றும் if blocks-க்குள் உள்ள let மற்றும் const-க்கும் block scope பொருந்தும். Local மாறிகளை விரும்புங்கள்: அவற்றைப் புரிந்துகொள்வது எளிது; தொடர்பில்லாத code அவற்றை மாற்ற முடியாது.

தற்செயலான globals-ஐத் தவிர்க்கவும்

அறிவிக்கப்படாத பெயருக்கு மதிப்பு வைத்தால், non-strict code-ல் ஒரு global உருவாகும். எப்போதும் const அல்லது let கொண்டு அறிவியுங்கள்; அப்போது typo ஒரு மறைவான மாறியாக இல்லாமல் error ஆகும்.

Pure functions மற்றும் callbacks

Pure function அதே input-க்கு அதே output-ஐத் திருப்பித் தரும்; தனக்கு வெளியே எதையும் மாற்றாது. Side effects இல்லாமல் மீண்டும் மீண்டும் call செய்ய முடியும் என்பதால் pure functions சோதிக்க எளிது.

Impure functions தடைசெய்யப்படவில்லை. தரவைச் சேமிக்க, பக்கத்தை update செய்ய அல்லது log செய்ய அவை அவசியம். கணக்கீட்டை pure ஆக வைத்து, side effects-ஐ நிரலின் விளிம்புகளுக்குத் தள்ளுவதே வளர்க்க வேண்டிய பழக்கம்.

Callback என்பது மற்றொரு function-க்கு அனுப்பப்படும் function; பிறகு அது call செய்யப்படலாம். பாடம் 4.3-இன் array methods callbacks-ஐப் பயன்படுத்துகின்றன. நீங்களும் சொந்தமாக எழுதலாம்.

Function-ஐ ஒரு மதிப்பாக அனுப்புவதே callbacks-ஐ சாத்தியமாக்குகிறது. action parentheses-உடன் call செய்யப்படுகிறது என்பதைக் கவனியுங்கள்; அதற்குப் பதிலாக action() அனுப்பினால் அது உடனே call ஆகி, அதன் முடிவு அனுப்பப்படும்.

Function-ல் return statement இல்லாவிட்டால் என்ன ஆகும்?

அது undefined திருப்பித் தரும். Function இன்னும் இயங்கும்; உள்ளே log செய்தால் அச்சிடப்படும்; ஆனால் call செய்தவருக்குப் பயனுள்ள மதிப்பு கிடைக்காது. முடிவு வேறு இடத்தில் தேவைப்பட்டால் அதை return செய்யுங்கள்.

ஒரு function taxRate-ஐப் பார்க்க முடிகிறது, ஆனால் மற்றொரு function-க்குள் அறிவிக்கப்பட்ட மாறியைப் பார்க்க முடியாதது ஏன்?

Scope வெளிநோக்கிப் பார்க்கும், பக்கவாட்டில் அல்ல. ஒரு function சுற்றியுள்ள file-இன் பெயர்களைப் படிக்கலாம்; ஆனால் local மாறி அதை உருவாக்கிய call-க்கு மட்டுமே சொந்தம். ஒவ்வொரு function-ன் உள்ளே இருக்கும் பெயர்கள் தனிப்பட்டவையாகவே இருக்கும்.

நினைவில் கொள்ள வேண்டிய முக்கிய விஷயங்கள்

  • Functions என்பவை inputs-ம் output-ம் கொண்ட பெயரிடப்பட்ட படிகள். Parameters arguments-ஐப் பெறுகின்றன; return முடிவைத் திருப்பி அனுப்புகிறது.
  • Scope பெயர்களை local ஆக வைத்திருக்கிறது. const அல்லது let கொண்டு அறிவியுங்கள்; தேவைப்படும் இடத்தில் மட்டும் வாழும் மாறிகளை விரும்புங்கள்.
  • Pure functions கணிக்கக்கூடியவை. கணக்கீடுகளை pure ஆக வைத்திருங்கள், மீண்டும் பயன்படுத்தக்கூடிய நடத்தைக்கு callbacks பயன்படுத்துங்கள், side effects-ஐ விளிம்புகளில் நடக்க விடுங்கள்.
