Functions name reusable work

Function declaration function keyword-ஓட, ஒரு name-ஓட, parameter list-ஓட, ஒரு body-ஓட start ஆகும். Declare பண்ணினா அது run ஆகாது. Name-ஐ parentheses-ஓட call பண்ணினா run ஆகும்.

Parentheses-க்கு உள்ளே இருக்கிற name என்பது ஒரு parameter, ஒரு value-க்கான placeholder. Call பண்ணும்போது pass பண்ற value, உதாரணமா "Maya", ஒரு argument. Function-க்கு உள்ளே parameter ஒரு சாதாரண variable-ஆ behave பண்ணும்.

Parameters and return values

return ஒரு value-ஐ caller-க்கு திருப்பி அனுப்பி function-ஐ உடனே நிறுத்தும். Return statement இல்லாம function undefined-ஐ return பண்ணும்.

Logging-ம் returning-ம் வேற வேற வேலை. Log பண்ற function console-ஐ பாக்கிற மனிதனுக்கு useful. Return பண்ற function மீதி program-க்கு useful, ஏனெனில் இன்னொரு function அந்த result-ஐ use பண்ணலாம்.

return-க்குப் பிறகு வரும் code எப்பவும் run ஆகாது. Return பண்ணுவதுக்கு முன்னாடி ஏதாவது compute பண்ண வேண்டும்னா, அந்த வேலையை முதல்ல செய்யுங்க.

Expressions and arrow functions

Function expression ஒரு function-ஐ variable-ல store பண்ணும். Function anonymous-ஆ இருக்கலாம், இது இன்னொரு method-க்கு pass பண்ணும்போது பொதுவானது.

Arrow function ஒரு சின்ன expression syntax. ஒரு parameter இருந்தா parentheses optional. ஒரே expression இருந்தா braces-ம் return-ம் optional.

Arrow functions சின்ன callbacks-க்கு excellent. this-ஐ எப்படி handle பண்ணுது என்பதில் சாதாரண functions-லிருந்து வேறுபடும், ஆனா Module 5-ல objects மற்றும் events-ஓட வேலை செய்யும் வரை அந்த difference உங்களுக்குத் தேவைப்படாது.

Defaults and scope

Default parameter caller argument-ஐ விட்டுட்டா ஒரு value-ஐ supply பண்ணும். Defaults function run ஆகும்போது evaluate ஆகும், declare ஆகும்போது இல்ல.

Scope என்பது ஒரு code piece பார்க்கக்கூடிய names-ஓட set. Function-க்கு உள்ளே declare பண்ண variable local: அது அந்த call-ல மட்டும் இருக்கும். வெளியே declare பண்ண variable file-க்கு global, functions-க்கு உள்ளே தெரியும்.

Block scope loops மற்றும் if blocks-க்கு உள்ளே let மற்றும் const-க்கும் apply ஆகும். Local variables-ஐ prefer பண்ணுங்க: அவற்றை reason பண்ண எளிது, சம்பந்தமில்லாத code அவற்றை change பண்ண முடியாது.

Avoid accidental globals

Declare பண்ணாத name-க்கு assign பண்ணினா non-strict code-ல global உருவாகும். எப்பவும் const அல்லது let கொண்டு declare பண்ணுங்க, அப்போ typo ஒரு hidden variable-ஆ இல்லாம error ஆகும்.

Pure functions and callbacks

Pure function அதே input-க்கு அதே output return பண்ணி, தன்னைத் தவிர எதையும் change பண்ணாது. Pure functions test பண்ண எளிது, ஏனெனில் side effects இல்லாமல் திரும்ப திரும்ப call பண்ணலாம்.

Impure functions தடைசெய்யப்பட்டவை இல்ல. Data save பண்ண, page update பண்ண, log பண்ண அவை தேவை. Build பண்ண வேண்டிய habit: calculation-ஐ pure-ஆ வைத்து, side effects-ஐ program-ஓட edges-க்குத் தள்ளுங்க.

Callback என்பது இன்னொரு function-க்கு pass பண்ணப்படும் function, பிறகு அது call ஆக முடியும். Lesson 4.3-லிருந்து array methods callbacks use பண்ணும். நீங்களும் உங்கள் சொந்த callbacks எழுதலாம்.

ஒரு function-ஐ value-ஆ pass பண்ணுவதுதான் callbacks-ஐ சாத்தியமாக்குது. action parentheses-ஓட call ஆகுது என்பதை கவனிங்க; action() pass பண்ணினா அது உடனே call ஆகி அதன் result pass ஆகும்.

Check yourself

What happens if a function has no return statement?

அது undefined-ஐ return பண்ணும். Function இன்னும் run ஆகும், அதனால உள்ளே log பண்ணினா இன்னும் print ஆகும், ஆனா caller-க்கு useful value கிடைக்காது. Result வேற எங்கயாவது தேவைப்பட்டா அதை return பண்ணுங்க.

Why can a function see taxRate but not a variable declared inside another function?

Scope வெளிப்புறம் பார்க்கும், பக்கவாட்டில் இல்ல. ஒரு function சுற்றியிருக்கிற file-லிருந்து names read பண்ணும், ஆனா local variable அதை உருவாக்கின call-க்கு மட்டுமே சொந்தம். ஒவ்வொரு function-ஓட inner names private-ஆ இருக்கும்.

Key things to remember

  • Functions என்பவை inputs-ம் ஒரு output-ம் உள்ள named steps. Parameters arguments-ஐ receive பண்ணும்; return result-ஐ திருப்பி அனுப்பும்.
  • Scope names-ஐ local-ஆ வைத்திருக்கும். const அல்லது let கொண்டு declare பண்ணுங்க, தேவைப்படுகிற இடத்துல மட்டும் வாழ்கிற variables-ஐ prefer பண்ணுங்க.
  • Pure functions predictable. Calculations-ஐ pure-ஆ வைத்திருங்க, reusable behaviour-க்கு callbacks use பண்ணுங்க, side effects edges-ல நடக்கட்டும்.
