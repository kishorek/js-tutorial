Tables, forms, and semantic structure

Tables data-க்கு, forms input-க்கு, landmarks page-க்கு assistive technology navigate பண்ணக்கூடிய shape-ஐ கொடுக்கும். இங்கே தான் HTML, tags list-ஆ இல்லாம language-ஆ feel ஆக ஆரம்பிக்கும்.

Tables are for tabular data

Information-க்கு ஒன்றுக்கொன்று தொடர்புடைய rows-உம் columns-உம் இருந்தா table use பண்ணுங்கள். Page layout position பண்ண table use பண்ணாதீங்க; CSS Grid அந்த வேலையை நல்லா செய்யும்.

  • <caption> table-க்கு பேர் கொடுக்கும். Opening tag-க்கு உடனே அப்புறம் வையுங்கள்.
  • <thead>-உம் <tbody>-உம் header rows-ஐயும் body rows-ஐயும் group பண்ணும்.
  • <th scope="col"> ஒரு column-ஐ label பண்ணும்; scope="row" ஒரு row-ஐ label பண்ணும்.
  • ஒரு cell-க்கு ஒரு idea வையுங்கள்; numbers-ஐ easy-ஆ scan பண்ண வையுங்கள்.

Forms collect input

ஒவ்வொரு field-க்கும் ஒரு label, பொருத்தமான input type, ஒரு button—இவை form-க்கு தேவை. Labels decoration இல்லை: label-ஐ click பண்ணா அது அதோட field-ஐ focus பண்ணணும்; screen readers அதை field-ஓட name-ஆ use பண்ணும்.

  • ஒவ்வொரு for-ஐயும் input-ஓட id-க்கு match பண்ணுங்கள்.
  • பொருந்தினா type="email", type="number", அல்லது type="date" use பண்ணுங்கள்; mobile keyboards அதுக்கு ஏத்த மாறும்.
  • required submit பண்ணுறதுக்கு முன்னாடி field-ஐ கட்டாயம் ஆக்கும்.
  • fieldset-உம் legend-உம் related controls-ஐ group பண்ணும்.
  • Backend இல்லாத form-உம் browser-ல validate ஆகும். JavaScript-ஐ அதோட பிறகு connect பண்ணுவோம்.
Do not use a placeholder as a label

யாராவது type பண்ண உடனே placeholders மறைஞ்சு போகும்; அவை reliable accessible name இல்லை. ஒரு real label-ஐ வையுங்கள்; placeholder text-ஐ example-க்கு மட்டும் use பண்ணுங்கள்.

Give the page landmarks

Semantic elements ஒவ்வொரு region-உம் என்ன செய்யுது என்று browser-க்கு சொல்லும். Visitor header-ஐ பார்க்கலாம்; screen reader main அல்லது nav-க்கு நேரடியா jump பண்ணலாம்.

ஒரு page-க்கு ஒரே ஒரு main தான். Themed content group-க்கு section, தனியா stand பண்ணக்கூடிய ஒன்றுக்கு—blog post அல்லது project card போல—article use பண்ணுங்கள்.

Check yourself

Why should a table have a caption?

Screen reader rows-ஐயும் columns-ஐயும் படிக்க ஆரம்பிக்குறதுக்கு முன்னாடி caption table-க்கு பேருன்னு context-ஐயும் கொடுக்கும். பார்க்கக்கூடியவங்களும் என்ன பார்க்கிறாங்க என்று புரிஞ்சுக்க இது help பண்ணும்.

What is the difference between section and article?

Section related content-ஐ ஒரு heading-க்கு கீழ group பண்ணும். Article தனியா இருக்கக்கூடிய, வேற எங்கயும் reuse பண்ணக்கூடிய content—post அல்லது project card போல.

Key things to remember

  • Tables data-க்கு, layout-க்கு இல்லை. Caption-உம் header labels-உம் கொடுங்கள்.
  • ஒவ்வொரு form field-க்கும் label தேவை. for-ஐயும் id-ஐயும் match பண்ணுங்கள்.
  • Landmarks page-ஐ navigate பண்ண வைக்கும். Header, nav, main, aside, footer.
