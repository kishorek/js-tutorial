Module 05 · DOM & events

Events, input, and forms

Page ஒரு விஷயத்தை listen பண்ண ஆரம்பிச்சா அது interactive ஆகும். Events எப்படி travel ஆகுது, visitor type பண்ணினதை எப்படி read பண்ணுறது, form-ஐ page reload-க்கு போக விடாம எப்படி handle பண்ணுறதுன்னு கத்துக்கலாம்.

An event is a message

ஏதாவது நடக்கும்போது browser ஒரு event object-ஐ create பண்ணி அதை element-க்கு அனுப்பும். addEventListener(type, handler) மூலமா நீங்கள் listen பண்ணுவீங்க.

Handler-க்கு event கிடைக்கும். event.target என்ன element fire பண்ணிச்சோ அது; event.currentTarget என்ன element-ல listener attach ஆகியிருக்கோ அது. Simple button-ல ரெண்டும் ஒன்னு தான்; ஆனா parent தன் children-க்காக listen பண்ணும்போது வித்தியாசம் இருக்கும்.

onclick attribute-க்கு பதிலா addEventListener-ஐ use பண்ணுங்கள். Behavior JavaScript-லயே இருக்கும், ஒன்னுக்கு மேல listener add பண்ணலாம், பிறகு removeEventListener மூலம் remove பண்ணவும் easy.

Read the value as it changes

Value change ஆகும் ஒவ்வொரு தடவையும் input event fire ஆகும். Text-க்கு input.value, checkbox-க்கு input.checked, drop-down-க்கு select.value read பண்ணுங்கள்.

input ஒவ்வொரு keystroke-லயும், paste-லயும் fire ஆகும். change field focus-ஐ விட்டு போனப்புறமோ choice commit ஆனப்புறமோ தான் fire ஆகும். Live counter அல்லது preview-க்கு input-ஐ select பண்ணுங்கள்.

Values are strings

input.value எப்பவுமே string; number field-க்கும் அப்படித்தான். Maths பண்ணும் முன்னாடி Number(input.value) use பண்ணி convert பண்ணுங்கள்; முதல்ல empty string-ஆ இருக்கான்னு check பண்ணுங்கள்.

Submit a form without reloading

Form default-ஆ submit ஆகும்: browser data-ஐ அனுப்பி புது page-ஐ load பண்ணும். JavaScript-ல handle பண்ண, submit-க்கு listen பண்ணி event.preventDefault()-ஐ call பண்ணுங்கள்.

FormData fields-ஐ அவங்க ids-ல இல்லாம, name attributes மூலமா read பண்ணும். Assistive technology use பண்றவங்களுக்கு ஒவ்வொரு field-க்கும் id-ஓட connect ஆன label தேவை. required, type="email" போன்ற built-in rules submit-க்கு முன்னாடியே run ஆகும்; ஆனா server-side validation இன்னும் தேவை.

Keyboard events and delegation

Keyboard use பண்றவங்களுக்கும் mouse use பண்றவங்களுக்கும் ஒரே actions தேவை. keydown-க்கு listen பண்ணி event.key-ஐ "Enter", "Escape" போன்ற பேரோட compare பண்ணுங்கள். Numeric keyCode values-ஐ compare பண்ணாதீங்க.

ரெண்டாவது listener தான் event delegation. Parent-ல இருக்கும் ஒரு listener match ஆகும் ஒவ்வொரு child-ஐயும் handle பண்ணும்; அப்புறம் add ஆகிற children-ஐயும் handle பண்ணும். closest click ஆன element-ல இருந்து மேல நடந்து button-ஐ find பண்ணும்; அதனால button-ஓட text-ஐ click பண்ணினாலும் வேலை செய்யும்.

Check yourself

What is the difference between input and change?

input ஒவ்வொரு edit-லயும் fire ஆகும்; ஒவ்வொரு keystroke-ம் அடங்கும். change edit commit ஆனப்புறம் தான் fire ஆகும்; பொதுவா blur ஆனப்போ அல்லது select value choose பண்ணினப்போ.

Why does the page reload when I submit a form?

அது browser-ஓட default behavior. உங்கள் submit handler முதல்ல run ஆகும்; event.preventDefault() navigation-ஐ stop பண்ணும், அதனால உங்கள் code page-ஐ update பண்ண முடியும்.

Key things to remember

  • Listen பண்ணி, பிறகு read பண்ணுங்கள். ஒரு listener attach பண்ணி, என்ன நடந்ததுன்னு தெரிய event object-ஐ use பண்ணுங்கள்.
  • நீங்க handle பண்ற விஷயத்துக்கு மட்டும் default-ஐ prevent பண்ணுங்கள். preventDefault-ஐ மறந்த submit handler page-ஐ இழக்கும்.
  • ஒரு parent நிறைய children-ஐ handle பண்ணலாம். closest-ஓட delegation புது rows வந்தாலும் வேலை செய்யும்.
