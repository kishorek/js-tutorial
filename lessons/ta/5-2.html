தொகுதி 05 · DOM & நிகழ்வுகள்

நிகழ்வுகள், input மற்றும் forms

ஒரு பக்கம் கேட்கத் தொடங்கும்போது அது interactive ஆகிறது. நிகழ்வுகள் எப்படிப் பயணிக்கின்றன, பார்வையாளர் தட்டச்சு செய்ததை எப்படிப் படிப்பது, page reload-ல் அவர்களின் வேலையை இழக்காமல் ஒரு form-ஐ எப்படிக் கையாள்வது என்பதைக் கற்றுக்கொள்ளுங்கள்.

பாடம் 5.2 60–75 நிமிடம் தொடக்கநிலை

பாடத்தின் முடிவில், உங்களால் முடியும்

  • Clicks, input, submit மற்றும் keys-க்கு listeners இணைக்கலாம்.
  • Inputs, checkboxes மற்றும் selects-ல் இருந்து values-ஐப் படிக்கலாம்.
  • Form reload-ஐத் தடுத்து, பல children-இடமிருந்து வரும் events-ஐக் கையாளலாம்.

உங்களுக்குத் தேவை

  • பாடம் 5.1: nodes-ஐத் தேர்ந்தெடுப்பதும் மாற்றுவதும்.
  • தொகுதி 1-ல் உருவாக்கிய labels கொண்ட form.
  • ஒரு button மற்றும் ஒரு text input கொண்ட பக்கம்.

Event என்பது ஒரு செய்தி

ஏதாவது நடக்கும்போது browser ஒரு event object-ஐ உருவாக்கி அதை element-க்கு அனுப்புகிறது. addEventListener(type, handler) மூலம் நீங்கள் அதைக் கேட்கிறீர்கள்.

Handler அந்த event-ஐப் பெறும். event.target என்பது event-ஐ உருவாக்கிய element; event.currentTarget என்பது listener இணைக்கப்பட்ட element. எளிய button-ல் இரண்டும் ஒன்றே; ஆனால் ஒரு parent தன் children-க்காகக் கேட்கும்போது வேறுபடும்.

addEventListener தான் onclick attribute-க்குப் பதிலான வழி; அதைப் பயன்படுத்துங்கள். இது behaviour-ஐ JavaScript-ல் வைத்திருக்கும், ஒன்றுக்கு மேற்பட்ட listener-களை அனுமதிக்கும், பிறகு removeEventListener மூலம் நீக்குவது எளிது.

மாறும்போதே value-ஐப் படியுங்கள்

Value மாறும் ஒவ்வொரு முறையும் input event இயங்கும். உரைக்கு input.value, checkbox-க்கு input.checked, drop-down-க்கு select.value ஆகியவற்றைப் படியுங்கள்.

input ஒவ்வொரு keystroke அல்லது paste-லும் இயங்கும். Field focus-ஐ இழக்கும் வரை அல்லது தேர்வு உறுதியாகும் வரை change காத்திருக்கும். நேரடி counter அல்லது preview-க்கு input-ஐத் தேர்ந்தெடுங்கள்.

Values strings தான்

input.value எப்போதும் string தான்; number field ஆனாலும். கணக்கு செய்வதற்கு முன் Number(input.value) மூலம் மாற்றுங்கள்; முதலில் காலி string-ஐச் சரிபார்க்கவும்.

Reload ஆகாமல் form-ஐ submit செய்வது

Form இயல்பாகவே submit ஆகும்: browser data-ஐ அனுப்பி புதிய பக்கத்தை ஏற்றும். JavaScript-ல் அதைக் கையாள submit-க்கு listener வைத்து event.preventDefault() அழைக்கவும்.

FormData, fields-ஐ அவற்றின் name attributes மூலம் படிக்கிறது; ids மூலம் அல்ல. Assistive technology பயன்படுத்துபவர்களுக்காக ஒவ்வொரு field-க்கும் ஒரு label, id-உடன் இணைக்கப்பட்டதாகத் தேவை. required மற்றும் type="email" போன்ற உள்ளமைந்த விதிகள் submit-க்கு முன் இயங்கும்; server-side validation இன்னும் தேவை.

Keyboard events மற்றும் delegation

Keyboard பயன்படுத்துபவர்களுக்கும் mouse பயன்படுத்துபவர்களுக்கான அதே செயல்கள் தேவை. keydown-க்குக் கேட்டு, event.key-ஐ "Enter" அல்லது "Escape" போன்ற பெயருடன் ஒப்பிடுங்கள். எண்ணிக்கையான keyCode values-ஐ ஒப்பிட வேண்டாம்.

இரண்டாவது listener தான் event delegation. Parent-ல் உள்ள ஒரே listener, பொருந்தும் ஒவ்வொரு child-ஐயும் கையாளும்; பிறகு சேர்க்கப்படும் children-ஐயும் சேர்த்து. Clicked element-இலிருந்து மேல்நோக்கி closest சென்று button-ஐக் கண்டுபிடிக்கிறது; அதனால் button-இன் உரையைக் கிளிக் செய்தாலும் வேலை செய்யும்.

பயிற்சி · 25 நிமிடம்

எழுத்து எண்ணிக்கை மற்றும் சுருக்கத்தை உருவாக்குங்கள்

பக்கத்தில் <textarea id="bio">, <p id="count">, id="profile" மற்றும் name, email என்ற பெயரிடப்பட்ட fields கொண்ட form, மேலும் <p id="summary"> உள்ளது என வைத்துக்கொள்ளுங்கள். தட்டச்சு செய்யும்போதே எழுத்து எண்ணிக்கையைப் புதுப்பித்து, 120 எழுத்துகளுக்கு மேல் ஆனால் is-over என்ற class-ஐச் சேர்க்கவும்; பிறகு submission-ஐத் தடுத்து, summary-ல் "பெயர் · மின்னஞ்சல்" வடிவில் காட்டுங்கள்.

முதலில் ஒரு முயற்சி செய்யுங்கள். பிறகு மாதிரி விடை திறக்கும்.

உங்களைச் சரிபார்க்கவும்

input மற்றும் change-க்கு இடையே உள்ள வேறுபாடு என்ன?

input ஒவ்வொரு திருத்தத்திலும், ஒவ்வொரு keystroke-லும் இயங்கும். திருத்தம் உறுதியாகும்போது, பொதுவாக blur ஆகும்போது அல்லது select value தேர்ந்தெடுக்கப்படும்போது change இயங்கும்.

Form-ஐ submit செய்யும்போது பக்கம் ஏன் reload ஆகிறது?

அது browser-இன் இயல்பான நடத்தை. உங்கள் submit handler முதலில் இயங்கும்; event.preventDefault() navigation-ஐ நிறுத்துவதால், அதற்குப் பதிலாக உங்கள் code பக்கத்தைப் புதுப்பிக்க முடியும்.

நினைவில் வைக்க வேண்டிய முக்கிய விஷயங்கள்

  • கேளுங்கள், பிறகு படியுங்கள். Listener-ஐ இணைத்து, என்ன நடந்தது எனத் தெரிந்துகொள்ள event object-ஐப் பயன்படுத்துங்கள்.
  • நீங்கள் கையாளும்போது மட்டுமே default-ஐத் தடுங்கள். preventDefault-ஐ மறக்கும் submit handler பக்கத்தை இழக்கும்.
  • ஒரு parent பல children-ஐக் கையாள முடியும். closest கொண்ட delegation புதிய rows வந்தாலும் வேலை செய்யும்.
