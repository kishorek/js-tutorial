Flexbox in one minute

display: flex turns a container into a flex container and its direct children into flex items. Items sit along the main axis, horizontal by default; the cross axis runs the other way. justify-content distributes space on the main axis, align-items aligns items on the cross axis, and gap spaces them without collapsing margins.

  • justify-content takes flex-start, center, space-between; align-items takes stretch, flex-start, center, baseline.
  • flex-wrap: wrap lets items move to a new line instead of shrinking forever.
  • flex: 1 1 240px means grow, shrink, and start from a 240px basis. Add min-width: 0 to a text-heavy item so it can shrink.

Below 560px the header switches to a column so the brand and links stack instead of squeezing.

Check yourself

Why does flex-wrap: wrap matter for the project row?

Without wrapping, flex items shrink to fit one line and the cards become unreadable. Wrapping moves a card to the next row when its 240px basis no longer fits.

Why not use justify-content: space-between on the project row?

Space-between pins the first and last card to the edges and leaves uneven internal gaps. gap gives every card the same space; save space-between for a header with two ends.

Module 2 complete

  • Flexbox is one-dimensional. Choose a main axis, then distribute and align.
  • Wrap before you shrink. A wrapping row with flex: 1 1 240px handles most card layouts.
