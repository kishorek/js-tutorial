The brief

You are building a small personal site: an About Me page and a recipe page. The two pages link to each other. The content is yours; the structure is the exercise.

Check yourself

Why should the About Me page link back to the recipe page?

A website is a set of connected pages. The navigation gives the reader a way back and proves that your relative paths work in both directions.

What should you check first if a relative link opens a 404 page?

Check the filename, the extension, and the folder relationship. A link to recipe.html only works when both files are in the same folder.
