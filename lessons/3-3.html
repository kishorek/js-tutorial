Module 03 · Layout & responsive design

Accessibility + landing page

Accessibility is not a final pass. It is the same structure and layout decisions, checked from the perspective of someone using a keyboard, a screen reader, or a small screen in bright sunlight.

Lesson 3.3 · Project2–3 hoursModule milestone

Deliverables

  • A responsive landing page in the live editor.
  • Semantic landmarks, labeled controls, useful alt text.

Exit check

  • Keyboard access and visible focus.
  • No sideways scroll at 320px.

Landmarks give the page a map

Semantic elements create regions that assistive technology can list and jump between. The skip link comes first so a keyboard user can bypass repeated navigation.

  • One h1, then h2 for sections and h3 inside them; never skip levels for visual size.
  • One main holds the primary content; header, nav, and footer frame it.
  • The skip link must appear on focus; display: none removes it from the keyboard.

Names, alternatives, and focus

A control without a name is a mystery. Every input needs a label whose for matches its id. Every meaningful image needs alt text; decoration uses alt="".

Never write outline: none without replacing it. Aim for 4.5:1 contrast on body text and 3:1 on large text, icons, and focus rings.

Contrast is not a style preference

Light gray text on white looks elegant in a mockup and disappears in daylight. Check the color values, not the screenshot.

Keyboard access and motion

Tab through the page. Focus order should match reading order. Use real a and button elements, not clickable divs.

This query respects an operating-system preference without removing content. Do not hide essential information behind motion.

Check yourself

Why must a skip link become visible on focus?

A keyboard user needs to see where focus is before pressing Enter. Hiding it permanently makes it unusable.

When is alt="" correct?

When the image is decorative and adds no information beyond the surrounding text.

Module 3 complete

  • Grid builds the structure. Named areas and minmax(0, 1fr) make layouts predictable.
