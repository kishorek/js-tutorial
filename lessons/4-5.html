Objects group related values

An object stores named properties. Use dot notation for a known name and bracket notation when the name is stored in a variable. Arrays of objects let each item describe one record.

  • find returns the first match, or undefined.
  • filter returns a new array of every match.
  • map returns one transformed value per item.
  • reduce combines the list into a single value.

  • The console shows no errors after a full sequence.

Check yourself

Why keep calculate separate from the button handler?

Separating them lets you test the arithmetic directly, reuse it, and change the interface without rewriting the logic. The handler only collects input and shows output.

Why does dividing by zero show Error instead of Infinity?

The calculate function checks for a zero divisor and returns a message. JavaScript would otherwise produce Infinity, which is mathematically valid but not useful in a calculator.
