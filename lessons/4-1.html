Module 04 · JavaScript foundations

Values, variables, and types

JavaScript begins with small pieces of data and the names we give them. Learn how values are stored, what type they have, and how to compare them without surprises.

Lesson 4.1 60–75 min Beginner

By the end, you can

  • Add JavaScript to a page and read the console.
  • Declare values with let and const.
  • Name the five beginner types and check them with typeof.
  • Use template literals and strict equality with confidence.

You need

  • A browser with DevTools.
  • Your editor from Module 1.
  • Patience for tiny typo errors.

Where JavaScript goes

HTML gives the page structure. CSS styles it. JavaScript adds behavior. You add it with a <script> element, usually at the end of <body> so the page content exists before the script runs.

console.log() prints a value to the console. In most browsers, press F12 or right-click the page and choose Inspect, then open the Console tab. Nothing appears on the page itself; the message is for you.

Debug habit

Before guessing why code fails, log the value you are unsure about. A console message is evidence. Guessing is not.

Variables name values

A variable is a label for a value stored in memory. Declare it with let when it will change, and const when it will not. Prefer const until you have a reason to reassign.

  • Names are case-sensitive: firstName and firstname are different.
  • Use camelCase for ordinary variables.
  • A name cannot start with a number or contain spaces.
  • Do not use reserved words such as let, const, or return as names.

The basic types

Every value has a type. Beginners meet five of them constantly.

typeof tells you the type of a value. It is a quick way to check what you actually have instead of what you assumed.

Strings and template literals

Strings can use single quotes, double quotes, or backticks. Backticks create a template literal: you can insert values with ${...} and write across lines.

Prefer template literals when you mix text and values. They are easier to read and harder to break than chains of plus signs.

Strings have useful properties and methods. .length counts characters, .toUpperCase() returns a new uppercase string, and .includes() checks for a substring.

Coercion and strict equality

JavaScript sometimes converts a value to another type automatically. This is called type coercion. It is convenient until it is confusing.

Use three equals

== compares after coercion. === compares value and type. Use === and !== everywhere unless you have a specific reason not to.

To convert deliberately, use Number("5"), String(5), or Boolean(value). Being explicit keeps the next reader — often future you — out of trouble.

Move values around

These four moves cover most beginner debugging. Run each one in the console and change the values.

  1. Log it. console.log(value) shows the current value.
  2. Check its type. console.log(typeof value) catches text where you expected a number.
  3. Compare strictly. Replace == with === and see whether the branch still runs.
  4. Copy it into a new name. If a value changes unexpectedly, assign it to a second variable and log both.
Exercise · 20 minutes

Introduce yourself in the console

Declare a const for your name, a let for your age, and a const boolean for whether you like JavaScript. Log one sentence with a template literal. Then increase your age by one and log a second sentence. Finish by logging the type of all three values.

Make an attempt first. Then the model answer unlocks.

Check yourself

When should I use let instead of const?

Use let only when the variable will be reassigned, such as a counter or a running total. If the name will always point to the same value, use const. A const object can still have its properties changed; the name simply cannot point to a different object.

Why is 5 == "5" true but 5 === "5" false?

The double equals converts the string to a number before comparing, so both sides become 5. The triple equals also checks the type. A number and a string are different types, so the result is false.

Key things to remember

  • Values have types. Strings, numbers, booleans, null, and undefined cover most beginner work.
  • Names should explain. Prefer const; use let when reassignment is real.
  • Strict equality avoids surprises. Use === and !==, and log values when you are unsure.
