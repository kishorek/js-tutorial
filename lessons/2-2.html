The box model and spacing

Every element on a page is a rectangular box with four layers. Once you can see those layers, "why is this 20 pixels too wide?" becomes a calculation instead of a guess.

Every element is a box

From the inside out: the content is the text or image, padding is space inside the border, the border is the visible edge, and margin is space outside the border. Padding and border belong to the element; margin separates it from its neighbours.

LayerWhat it doesClickable?
ContentHolds the text, image, or child boxes.Yes
PaddingPushes content away from the border; uses the background color.Yes
BorderDraws an edge around padding and content.Yes
MarginEmpty space between this box and others; always transparent.No

box-sizing changes the math

By default, CSS uses content-box. A width: 300px element with 20px padding and a 2px border actually occupies 300 + 40 + 4 = 344px. That is rarely what you mean, especially inside a narrow layout.

With border-box, the declared width is the final outer width. The content area shrinks to fit: 300 - 40 - 4 = 256px. Put that reset at the top of every project and stop doing mental arithmetic.

Inspect the box

In DevTools, select an element and open the Layout or Computed panel. The box diagram shows content, padding, border, and margin with live numbers. Hover a layer to highlight it on the page. Toggle a declaration's checkbox to see the effect immediately.

Shorthand and longhand

Shorthands set several sides at once. Values run clockwise from the top: top, right, bottom, left. Two values mean vertical then horizontal; one value applies to all four sides. Use longhand when only one side changes.

Margins collapse

Vertical margins between siblings do not add up. If one paragraph has margin-bottom: 24px and the next has margin-top: 16px, the gap is 24px, the larger of the two. A child's top margin can also collapse through its parent, pushing the whole parent down instead of creating space inside it.

The usual fix

Add padding or a border to the parent, or make the parent a flex container. Flex and grid layouts do not collapse margins; they use gap for spacing. If a margin seems to vanish, inspect the parent before adding random numbers.

Use a spacing scale

Pick a small set of values and reuse them. A four-pixel base is common: 4, 8, 12, 16, 24, 32, 48, 64. Consistent steps make a page feel designed rather than assembled. In the next lesson we will store these as custom properties.

Check yourself

Why does width: 300px plus padding: 20px render wider than 300px?

The default content-box sizing adds padding and border outside the declared width. Set box-sizing: border-box globally so the declared width includes both, and the content area shrinks to fit.

Both paragraphs have margin: 16px, yet the gap is 16px, not 32px. Why?

Adjacent vertical margins collapse: the browser uses the larger margin instead of adding them. This is normal. Use a flex container with gap when you need exact, non-collapsing spacing.

Key things to remember

  • Four layers: content, padding, border, margin. Know which ones are clickable and which are transparent.
  • Use border-box everywhere. Declared widths then match what you see on the page.
  • Spacing is a system. A small scale beats a pile of one-off pixel values.
