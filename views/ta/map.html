The path

ஒவ்வொரு module-க்கும் ஒரு goal, ஒரு project, ஒரு exit check இருக்கும். Calendar-ஐ பார்த்து next-க்கு போக வேண்டாம். Exit check pass ஆனா மட்டும் அடுத்தது.

Left-ல இருக்குற section menu எல்லா lesson-ஐயும் list பண்ணும். உங்க progress இந்த browser-ல save ஆகும்.

Every lesson is a loop

Understanding-ஐ விட recall முக்கியம். ஒவ்வொரு lesson-லயும் ஒரு concept-ஐ introduce பண்ணி, code-ல காட்டி, output-ஐ நீங்க guess பண்ணி, அதை use பண்ணி ஒரு small thing build பண்ணுவீங்க.

  1. Run பண்ணுவதுக்கு முன் guess பண்ணுங்க. Wrong guess உங்க mental model எங்க break ஆகுது என்பதை exact-ஆ காட்டும்.
  2. Type பண்ணுங்க, paste பண்ணாதீங்க. Type பண்ணும்போது brackets, quotes, closing tags-ஐ கவனிக்க வேண்டியதா இருக்கும்.
  3. வேண்டும்னே break பண்ணுங்க. ஒரு tag-ஐ remove பண்ணுங்க, ஒரு name-ஐ மாத்துங்க, output-ஐ பாருங்க, பிறகு fix பண்ணுங்க.
  4. Simple-ஆ explain பண்ணுங்க. ஒரு minute-ல explain பண்ண முடியலன்னா, அது இன்னும் உங்க control-ல இல்ல.

How you'll be assessed

  • ஒவ்வொரு lesson-லயும்: ஒரு quick check-உம் ஒரு small build-உம். Code-ஐ identify பண்றது மட்டும் இல்ல, நீங்களே build பண்ணுவீங்க.
  • ஒவ்வொரு module-லயும்: checklist-க்கு எதிரா review பண்ணப்படும் ஒரு project-உம் ஒரு small quiz-உம். Exit check தான் gate.
  • ஒவ்வொரு project-லயும்: முதல்ல demo பண்ணுவீங்க, பிறகு live-ஆ ஒரு change பண்ணுவீங்க. Change பண்ண முடிஞ்சா, நீங்க அதை understand பண்ணிட்டீங்க.
When something doesn't click

Difficulty என்பது data, failure இல்ல. ஒரு lesson exit check-ஐ விட குறைவா score பண்ணினா, அதை மீண்டும் படிச்சு, blank file-லிருந்து practice-ஐ மீண்டும் build பண்ணி, ஒரு new variation try பண்ணுங்க. Section menu-உம் progress tracker-உம் திரும்ப வர easy-ஆக்கும்.

Before you start

  • ஒரு browser. Chrome, Firefox, Safari அல்லது Edge. DevTools-ஐ நிறைய use பண்ணுவீங்க.
  • ஒரு text editor. VS Code usual choice, ஆனா எந்த simple text editor-உம் work ஆகும்.
  • ஒரு course folder. அதுக்கு web-builder என்று name கொடுங்க. ஒவ்வொரு exercise-ஐயும் அதுக்குள்ள வைங்க.
  • Interest, confidence இல்ல. இன்னும் தெரியலன்னா அது problem இல்ல.
